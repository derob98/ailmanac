# 지원 중단 및 마이그레이션 워치

> Source: https://derob98.github.io/ailmanac/ko/docs/whats-new/deprecations · AILmanac (CC BY 4.0) · last verified 2026-10-25

종료된 모델, 이름이 변경된 플래그, 마이그레이션 노트가 포함된 호환성을 깨는 변경 사항.

<LevelBadge level="intermediate" />

<VerifyNote lastVerified="2026-10-25" source="https://platform.claude.com/docs/en/about-claude/model-deprecations">
지원 중단 일정과 마이그레이션 세부 정보는 Anthropic에서 제공하며 변경됩니다 — 마이그레이션하기 전에 항상 공식 문서에서 날짜와 대체 항목을 확인하세요.
</VerifyNote>

모델은 종료되고, 파라미터는 이름이 바뀌며, 동작은 달라집니다. 이 페이지는 업그레이드가 갑작스러운 일이 되지 않도록 **호환성을 깨는 변경 사항**을 추적합니다. API 위에서 빌드한다면 주기적으로 훑어보세요.

## 이것이 중요한 이유

고정된 모델 ID는 결국 **지원이 중단**되고 그다음 **제거**됩니다. 이를 하드코딩한 코드는 망가집니다. 약간의 위생 관리가 새벽 2시의 사고를 방지합니다.

## 생존 규칙

- **모델 ID는 설정에서 읽으세요.** 코드베이스 곳곳에 리터럴을 흩뿌리지 마세요 — 그러면 마이그레이션이 한 줄 변경으로 끝납니다.
- 지원 중단 날짜와 권장 대체 항목을 위해 **공지를 주시하세요.**
- 모델을 바꿀 때는 **[평가(evals)](/docs/foundations/evals)를 다시 실행하세요** — "더 새롭고 더 좋은" 모델에서도 동작이 달라질 수 있습니다.
- 제거 이후가 아니라 **마감 기한 전에 테스트하세요.**

## 흔한 변경 유형

| 변경 | 예시 | 해야 할 일 |
|---|---|---|
| 모델 종료 | 오래된 모델 ID가 작동을 멈춤 | 권장 후속 모델로 이동, 재평가 |
| 파라미터 대체 | 추론/예산 노브가 `effort`로 대체됨 | 호출을 업데이트, [사고 및 노력(Thinking & Effort)](/docs/api/thinking-and-effort) 참고 |
| 기본값 변경 | 새 기본 모델/동작 | 의도적으로 고정, 프롬프트가 여전히 작동하는지 검증 |
| 엔드포인트/SDK 업데이트 | 새 SDK 메이저 버전 | 마이그레이션 가이드를 읽고 신중하게 버전 업 |

## 현재 워치

권위 있는 일정은 [공식 모델 지원 중단 페이지](https://platform.claude.com/docs/en/about-claude/model-deprecations)에 있습니다 — 마이그레이션하기 전에 그곳에서 날짜를 확인하세요. Anthropic은 공개 출시된 모델을 종료하기 전에 최소 60일의 사전 공지를 제공합니다.

### 지원 중단된 모델

공개 출시된 Claude 모델 하나가 "지원 중단되었으나 아직 종료되지 않은" 구간에 있습니다(2026년 10월 25일 확인): **`claude-sonnet-4-5-20250929`(Sonnet 4.5)는 2026년 9월 30일에 지원 중단되었고 2026년 11월 30일에 종료됩니다.** Anthropic이 권장하는 대체 모델은 `claude-sonnet-5-5`입니다. 호출은 종료일까지 계속 작동하다가 그 이후에는 실패합니다. 이 ID를 아직 고정해 쓰고 있다면 이것이 여러분의 마이그레이션이며, 남은 기간은 이제 약 5주입니다.

지원 중단된 모델이 하나 더 있습니다. 초대 전용인 `claude-mythos-preview`(2026년 6월 9일 지원 중단, 종료일은 추후 공지)로, 현재의 검증 기반 모델인 `claude-mythos-5-1`로 옮기세요. (`claude-mythos-5`는 아직 Active이지만 5.1을 가리키는 자체 마이그레이션 가이드가 있으므로 두 번 마이그레이션하는 것은 헛수고입니다.)

`claude-haiku-4-5-20251001`은 다음으로 지켜봐야 할 ID이며, 이제 라인업에서 가장 이른 종료 가능일을 **넘긴** 유일한 모델입니다. 그 하한은 **2026년 10월 15일**이었고 이미 지났습니다(다음은 2026년 11월 24일의 Opus 4.5입니다). 모델 개요에서는 **레거시 모델**로도 분류되어 있으며, 직접적인 후속 모델은 `claude-haiku-5-5`(2026년 10월 7일 출시)입니다. 2026년 10월 25일 기준 공식 상태 표는 여전히 이 모델을 **Active**로 표시하고 지원 중단 공지는 없으므로, 두 해석은 충돌하지 않습니다. Anthropic의 수명 주기 용어에서 "레거시"는 *더 이상 업데이트를 받지 않으며 앞으로 지원 중단될 수 있음*을 뜻하며, "지원 중단"의 한 단계 전입니다. "이 날짜 이전에는 안 됨"이라는 날짜가 도래하는 것은 계획을 세우라는 신호이지 장애가 아닙니다. Anthropic은 최소 60일 전 공지를 약속하며, 그 카운트다운은 하한 날짜가 지났을 때가 아니라 공지가 나갈 때 시작됩니다. Sonnet 4.5가 실제 사례입니다. 하한은 2026년 9월 29일이었고, 지원 중단 공지는 9월 30일에 나왔으며, 실제 종료는 그로부터 두 달 뒤입니다. 이 ID를 고정해 쓴다면 이제 지켜보기보다 마이그레이션 일정을 잡을 때이며, 단순한 ID 교체도 아닙니다. 400을 반환하는 변경 5가지와 200을 반환하는 변경 6가지는 [Claude Haiku 5.5: 100K 가격 절벽](/docs/models/haiku-5-5-the-100k-price-cliff)을 참고하세요. 마이그레이션하기 전에 [공식 모델 상태 표](https://platform.claude.com/docs/en/about-claude/model-deprecations#model-status)에서 확인하세요.

### 최근 종료됨

- `claude-opus-4-1-20250805` (Opus 4.1)은 **2026년 8월 5일에 종료되었습니다** — `claude-opus-4-8`(또는 곧바로 `claude-opus-5`)로 이동하세요.
- `claude-opus-4-20250514` (Opus 4)과 `claude-sonnet-4-20250514` (Sonnet 4)은 **2026년 6월 15일에 종료되었습니다** — Anthropic이 제시한 대체 모델은 각각 `claude-opus-4-8`과 `claude-sonnet-4-6`입니다(또는 곧바로 `claude-opus-5` / `claude-sonnet-5`로).

종료된 ID로의 호출은 이제 API 오류를 반환합니다. 코드가 아직 그중 하나를 고정해 두었다면, 그것이 가장 먼저 고쳐야 할 부분입니다.

### 파라미터 지원 중단

샘플링 노브인 `temperature`, `top_p`, `top_k`는 단계적으로 사라지는 중이며, **이제 어떤 API 버전을 보내느냐에 따라 두 가지 규칙이 적용됩니다.**

- **`anthropic-version: 2023-06-01`에서**(2026년 10월 21일 이전에 출시된 모든 SDK 메이저 버전이 보내는 값): **Claude 4.7 세대 이후 모델**(Opus 4.7, Opus 4.8, Opus 5, Opus 5.5, Sonnet 5, Sonnet 5.5, Haiku 5.5, Fable 5, Fable 5.1, Mythos 5, Mythos 5.1) **및 Claude Mythos Preview**에서는 이 중 하나라도 **기본값이 아닌** 값으로 설정하면 **400 오류**를 반환합니다. 기본값은 허용되며, 더 오래된 모델은 기본값이 아닌 값도 여전히 허용합니다. 이름보다 버전 번호를 보세요. **Haiku 5.5는 기본값이 아닌 샘플링 값을 거부**하지만, 더 오래된 **Haiku 4.5는 여전히 허용**하며 Opus 4.6과 Sonnet 4.6도 마찬가지입니다.
- **`anthropic-version: 2026-10-21`에서**: 세 파라미터가 **제거**됩니다. 하나라도 보내면 **모든 모델에서, 파라미터의 기본값이라도 400**을 반환합니다. 최신 SDK 메이저 버전과 `ant` CLI는 요청 타입과 플래그에서 이를 삭제했습니다.

어느 쪽이든 해결책은 같습니다. 세 가지를 모두 생략하고 대신 [프롬프팅](/docs/prompting/prompting-claude)과 [사고 및 노력(Thinking & Effort)](/docs/api/thinking-and-effort)으로 동작을 조정하세요. 대체 수단이 없는 유일한 경우는 값을 여전히 따르는 구형 모델에서 *의도적으로 낮춘* temperature를 쓰는 경우이며, Anthropic이 문서화한 선택지는 파라미터 전송을 중단하거나 해당 요청을 `2023-06-01`에 유지하는 것입니다. 어떤 버전을 쓰고 있는지, 그에 따라 달리 무엇이 바뀌는지에 대한 전체 설명은 [API Version 2026-10-21 — 3년 만의 첫 호환성 파괴 버전](/docs/api/api-version-2026-10-21)을 참고하세요.

[현재 모델 및 가격](/docs/whats-new/models-and-pricing) 표와 대조하여 모델 ID를 항상 확인하세요. 오래된 ID를 사용 중이라면 마이그레이션을 계획하세요.
