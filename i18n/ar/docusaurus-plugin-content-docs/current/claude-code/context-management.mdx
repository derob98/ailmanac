## الفكرة الكبرى

لكل جلسة [نافذة سياق](/docs/foundations/tokens-and-context) محدودة. ومع امتلائها يُضغَط المحتوى الأقدم وقد يبدأ Claude بـ«الانحراف». إدارة السياق بوعي هي ما يُبقي الجلسات الطويلة حادّة.

## الأمران الأساسيان

أمران يغطيان تقريبًا كل حالة. الحيلة هي مطابقة الأمر مع نيّتك.

<Flashcards cards={[{front: "/clear", back: "يمسح المحادثة ويبدأ من جديد. استخدمه عند الانتقال إلى مهمة غير مرتبطة. أرخص طريقة لاستعادة سياق نظيف ومركّز. الأسماء البديلة: ‎/reset و/new."}, {front: "/compact", back: "يلخّص المحادثة حتى الآن في صيغة مضغوطة — يحتفظ بالجوهر ويحرّر المساحة. استخدمه عندما تريد متابعة المهمة نفسها لكن النافذة تمتلئ. يقبل تعليمات تركيز اختيارية."}]} />

احسم بسؤال واحد: هل هي مهمة جديدة أم المهمة نفسها؟

```mermaid
flowchart TD
  A{New task or same task?} -->|New / unrelated| B[/clear]
  A -->|Same task, context full| C[/compact]
```

تفصيلان يسهل تفويتهما:

- **`/compact` يقبل تعليمات.** الأمر `/compact focus on the auth bug fix` يحتفظ بما *تختاره أنت* بدل ما يخمّن المسار التلقائي أنه مهم. شغّله عن قصد قبل بدء مهمة جديدة طويلة بدل انتظار أن تُجبرك النافذة على ذلك.
- **`/clear` ليس نقطة اللاعودة.** مرّر اسمًا (`/clear auth refactor`) لوسم المحادثة المغادِرة في منتقي `/resume`، وفي عملية Claude Code نفسها ما زالت قائمة الرجوع تعرض إدخال `/resume <session-id> (previous session)` — راجع [نقاط الحفظ والرجوع](/docs/claude-code/checkpoints-and-rewind).

## الضغط التلقائي — وكيف تحرّك عتبته

عندما يقترب السياق من الحد، يقوم Claude Code بـ**الضغط التلقائي** حتى يستمر العمل دون توقف مفاجئ. على النماذج ذات نافذة السياق 1M يحدث ذلك افتراضيًا عند نحو 967K رمز؛ أما النماذج الأقدم فتضغط عند حدّ نافذة سياقها. ويمكن لـ Claude Code أيضًا ضغط محادثة تتركها خاملة.

العتبة بيدك. الأمر `/autocompact 500k` يضغط أبكر — مفيد عندما تفضّل التلخيص بشروطك بدل الانتظار حتى امتلاء 96% — و`/autocompact auto` يعيد النافذة المضبوطة لنموذجك.

## ما ينجو من الضغط

الضغط يلخّص *المحادثة*. أما كل ما يحمّله إعدادك من القرص فيُعالَج على حدة — ولهذا تظل الجلسة المضغوطة تعرف أعراف مشروعك.

تشير هذه إلى الوثائق الحية: [الوكلاء الفرعيون](/docs/claude-code/subagents) و[CLAUDE.md](/docs/claude-code/claude-md) و[شريط الحالة](/docs/claude-code/statusline).

:::tip[العَرَض ← الحل]
إذا بدأ Claude ينسى تعليمة سابقة أو يكرّر نفسه، فالأرجح أن النافذة ممتلئة. عادةً يحلّ `/compact` (المهمة نفسها) أو `/clear` (مهمة جديدة) المشكلة فورًا. شغّل `/context` للتأكد — فعندما تتجاوز المحادثة النافذة فعلًا، يذكر ناتجه بكم تجاوزتها وأي أمر يحرّر المساحة. المزيد في [لماذا فعل Claude ذلك؟](/docs/contribute/troubleshooting).

أما إذا ظهرت لك `Autocompact is thrashing`، فالضغط يعمل لكن شيئًا ضخمًا يملأ النافذة من جديد باستمرار — راجع [استكشاف أخطاء Claude Code](/docs/claude-code/troubleshooting).
:::
