AIは、*あなたが指示すれば*素晴らしいライティングのパートナーです。目標はボタンを押して公開することではありません — 白紙のページから強力なドラフトへのループを圧縮し、あなた自身の判断で磨き上げることです。このページはそのワークフロー、プロンプト、そして落とし穴です。

## うまくいくワークフロー

6ステップ。どれか1つでも飛ばすと品質は急激に落ちます。

<Steps items={[
  {title: "ブリーフを与える — 目標、読者、形式、トーン", body: "1段落で。「初めての創業者向けの600語のブログ序文、励ます調子で、甘くはならず、スタートアップの専門用語は使わない。最初の文でフックを。」ブリーフの曖昧さは、ドラフトの一般的なAIボイスになる。"},
  {title: "まずアウトライン — 構造を承認する", body: "数段落より長いものは何でも、散文の前に箇条書きのアウトラインを求める。弱いセクションはアウトライン段階で潰す — 書き直しは数秒で済むが、フルドラフトは数分と勢いを失う。"},
  {title: "ドラフト — 1回のクリーンなパス、口を出しすぎない", body: "ブリーフとアウトラインでドラフト全体を書かせる。生成中に修正で中断しない。それは継ぎ接ぎで支離滅裂な文章を生む。"},
  {title: "目的を1つに絞った段階的な編集", body: "1パスにつき目標は1つ。「400語まで引き締める」、次に「抽象的な主張を具体的な例に置き換える」、次に「もったいぶった書き出しを削る」。曖昧な「もっと良くして」は別の凡庸なドラフトを返すだけ。"},
  {title: "あなたの声に合わせる — 最大のレバー", body: "あなたが自分で書いた300〜500語を貼り付ける。「この声で書き直して — 同じ文のリズム、同じ語彙、同じ抑制で。」この1つの動きが、良いAIライティングと見分けのつくAI風の駄文を分ける。"},
  {title: "事実を検証し、それから公開", body: "すべての統計、引用、名前、出典の主張の文末に [verify] を付けさせる。各項目を一次資料と照合する。飛ばしてはいけない。下の落とし穴を参照。"}
]} />

## うまくいくプロンプト

### ブリーフと声のスターター

<PromptCard title="声のサンプル付きの初回ドラフトブリーフ">
```text
Write a {FORMAT} of {LENGTH} for {AUDIENCE}.
Purpose: {ONE-SENTENCE GOAL}.
Tone: {THREE ADJECTIVES}. Avoid: {LIST}.

Here are 300 words I wrote — match this voice. Same sentence rhythm,
same vocabulary, same restraint. Do not "improve" it toward a
generic professional voice.

<voice_sample>
{PASTE A PARAGRAPH OR TWO YOU WROTE}
</voice_sample>

Mark every factual claim, statistic, quote, or attributed source
with [verify] at the end of the sentence, so I can check it before
publishing.
```
</PromptCard>

### 目的を1つに絞った編集

<PromptCard title="変更差分を可視化する編集パス">
```text
Edit this text for {ONE GOAL — pick one: clarity, concision, concreteness, rhythm, cutting jargon}.
Do not change the meaning or reorder arguments.
After the edited version, list every change as a bullet: "removed X",
"replaced Y with Z", "cut sentence about W".

<text>
{PASTE}
</text>
```
</PromptCard>

変更リストを求めましょう。それはモデルに自分の好みで黙って書き換えるのではなく、意図的な編集を強制します — そしてあなたが同意できない変更を拒否できます。

### 長文向けのアウトラインファースト

<PromptCard title="散文の前にアウトライン">
```text
I'm writing a {2000-word essay} on {topic} for {audience}.
The argument is {one-sentence thesis}.

Before drafting, give me an outline as bullets: section headings,
one line of substance per section, plus the transition between
sections. No prose yet. Aim for {N} sections.

I'll approve or edit the outline; then you draft.
```
</PromptCard>

### 転用チェーン

<PromptCard title="1つの作品から5つの形式へ — 平板化なしで">
```text
Here's a published piece: <source>{PASTE}</source>.

Repurpose it into:
1. A LinkedIn post (~150 words) — one specific insight, not a summary.
2. A Twitter/X thread (5–7 tweets) — start with the strongest hook, one idea per tweet.
3. A newsletter blurb (~80 words) — the "why this matters" angle for busy readers.
4. Three email subject lines that would make me open it.

Rules:
- Do NOT summarize. Each format should stand alone.
- Preserve my voice (match the source's rhythm and vocabulary).
- Different hook for each — no reused sentences.
```
</PromptCard>

## 声を合わせる — メカニクス

「私の声に合わせて」はサンプルなしでは無価値です。実際に機能するのは:

- **説明ではなく実際の作品を貼る。** 「自信ありげでカジュアル」は曖昧。400語のあなたの文章はそうではない。
- **対象タスクに近いサンプルを選ぶ。** 声は形式によって変わる — ニュースレターの声はLinkedInの声ではない。
- **平板化を明示的に拒否する。** 追加: *「これを一般的なプロフェッショナルな声に均さないで。断片、余談、変わった語彙選択を残して。」*
- **トーンのつまみで反復する。** 初稿の後: *「もう半歩直接的に。ヘッジを減らす。文のリズムは保つ。」*

これでもモデルがAIボイスで書くなら、サンプルが短すぎるか、リクエストが一般的すぎるか、平均に寄せて調整されたモデルを使っている — デフォルトのGPTファミリー系より声の模倣が得意な [Fable 5 か Sonnet 5](/docs/models/sonnet-5-field-guide) を試してください。

## ライターがAIを拒否する落とし穴

<PromptCard title="落とし穴1 — もっともらしく提供されるでっち上げの事実">
モデルは統計、引用、出典名、書名、さらにはURLをでっち上げます。自信満々に。すべて。

**対策:** すべての事実の主張に `[verify]` マーカーを強制する。未検証の統計や引用は絶対に公開しない。4つのレベルとそれぞれの検出方法は [ハルシネーション](/docs/foundations/hallucinations) を参照。
</PromptCard>

<PromptCard title="落とし穴2 — 一般的なAIボイス">
バランスの取れた文。「〜だけでなく…も」。「特筆すべきは…」。「今日の急速に変化する世界において」。見ればすぐわかります。

**対策:** 声のサンプル + 均しの明示的な拒否。ドラフト途中で戻ってしまったら、該当の段落を貼り直して「この段落だけ、私が渡した声のサンプルで書き直して」と言う。
</PromptCard>

<PromptCard title="落とし穴3 — 編集しすぎて骨抜き">
「もっと良くして」の小さなパスを10回続けると、モデルの学習データの平均に向けて作品が平板化されます。特徴のあるドラフトで始めて、まともだが記憶に残らないものに終わる。

**対策:** 目的を1つに絞ったパスのみ。迷ったら編集をやめる。
</PromptCard>

<PromptCard title="落とし穴4 — エムダッシュ/箇条書きの兆候">
過剰なエムダッシュ、主張のたびに続く3項目の箇条書き、対比する文の間の「しかし」。読者は今やこれを瞬時に見抜き、作品を割り引きます。

**対策:** 明示的な文体制約 — 「セクションあたりエムダッシュは最大2つ」、「この作品は散文のみ、箇条書きなし」。あるいは枠組みとなる文は自分で書き、真ん中だけモデルに頼む。
</PromptCard>

<PromptCard title="落とし穴5 — 「書き直して」ループ">
「もっと強くして」を求め続けても、「強く」の意味を伝えていないので、モデルは異なる凡庸なドラフトを生むだけです。これを繰り返して何時間も無駄になります。

**対策:** 具体的な弱点を名指しする。「3段落目が抽象的すぎる — 実在の2020年代スタートアップから具体例を出して。」「書き出しがもったいぶっている — 結論から始めて。」
</PromptCard>

<PromptCard title="落とし穴6 — 人による編集なしで公開">
モデルが「まあまあ」なドラフトを書いた。あなたはざっと目を通して公開した。2週間後、ぎこちない転換、誤用された単語、何も言っていない段落に気付く。

**対策:** 公開前に印刷するか声に出して読む。AIはあなたのようにリズムを聞き取れません。
</PromptCard>

## ライティングタスクのモデル選び(2026年)

| タスク | ベストデフォルト | 理由 |
|---|---|---|
| 長文エッセイ、声に合わせたもの | Claude Sonnet 5 または [Fable 5](/docs/models/fable-5-mythos-5-flagship) | リズム、抑制、声の模倣が最も強い |
| 速いブログ下書き、実用的な散文 | Claude Sonnet 5 または GPT-5 | 速い、まとも、安い |
| 詩、物語小説、特徴的な文体 | Fable 5、その後手直し | 変わった声のターゲットが得意 |
| キーワードターゲットのあるSEO/マーケコピー | 任意のフロンティアモデル + 明示的な制約 | ほぼ同等。ブリーフの方がモデルより重要 |
| 既存の散文の編集 | Sonnet 5 または Opus 4 | 目的を1つに絞った外科的な編集が最も得意 |
| 翻訳/ローカライズ | [モデル間でのプロンプト移植](/docs/models/porting-prompts-across-models) を参照 | 言語をまたぐ声の保持は別のスキル |

プロバイダー横断比較: [Claude ユーザー向け ChatGPT](/docs/models/chatgpt-for-claude-users) と [Claude ユーザー向け Gemini](/docs/models/gemini-for-claude-users)。

## 倫理と開示

- **あなたが編集者です。** 判断、趣味、責任はあなたに残ります。
- **重要な場合はAIの支援を開示しましょう** — ジャーナリズム、アカデミア、開示条項のある請負仕事。今や読者はあらゆることにAIが関与していると想定します。あなたが持ち込んだものを明確にすることが信頼を築きます。
- **でっち上げの引用や統計を調査済みとして通用させないでください。** これは2024〜2025年にすでにキャリアを終わらせています。
