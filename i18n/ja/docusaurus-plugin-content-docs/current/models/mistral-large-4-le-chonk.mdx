## 一文でまとめると

Mistral Large 4は、**総計1.05T/アクティブ約49B**のグラニュラーMoEで、**1.6Bパラメータのネイティブ視覚エンコーダ**と、公称**1Mトークンのコンテキスト**を備えています。現時点では`mistral-large-4`という**モデレーション付きの公開プレビューAPI**でしか利用できず、オープンウェイトは**2026年10月末**に公開予定です。独立したスコアリングでは米国と中国以外で最強のモデルであり、同時に*オープン*モデルとしては8番目に強く、上位7つは中国のモデルです。

## 見出しが誤解させる5つのこと

### 1. 「オープンウェイト」は約束であって、ダウンロードではない

本日時点で、Mistral Large 4を**ダウンロードすることはできません**。Hugging Faceのリポジトリ`mistralai/Mistral-Large-4.0-1T05-A52B`は存在しますが、*近日公開*のプレースホルダーです。ダウンロードとライセンスの項目はどちらも「coming soon」となっており、ページには**2026年10月末**というETAが載っています。報道関係者へのブリーフィングは**10月27日**で、Hugging Faceのカウントダウンは**10月31日**を指しています。どちらの日付も出回っていますが、契約上の約束ではありません。

これは聞こえ以上に重要です。今週の「オープンウェイトの1兆パラメータモデル」という見出しはどれも、現時点では独自条件のもとで従量課金されるAPIエンドポイントとしてしか存在しないものを指しています。**ライセンスは発表されていません**。再配布、ファインチューニングの権利、Mistralとの契約なしの商用利用を前提に計画しているなら、未知の条件に対して計画していることになります。

<Callout type="warning">
このプレビューは**Research Public Preview**と表示されています。プレビューのエンドポイントは気づかないうちに更新される可能性があります。今日`mistral-large-4`の背後にあるウェイトが、来週ベンチマークするウェイトや、最終的にファイルとして公開されるウェイトと同じである保証はありません。評価はモデル名ではなく日付に固定してください。手順は[モデルは劣化したのか?実際に見分ける方法](/docs/models/is-the-model-nerfed)を参照してください。
</Callout>

### 2. 「アクティブ49B」は計算量の数字であって、メモリの数字ではない

発表の中で最も誤読されているスペックで、経験者でもつまずきます。

ML4は1.05Tのうち、トークンごとに約**49B**のエキスパートパラメータ(約**4.7%**)を活性化します。(**52B**という数字も目にするでしょう。これは埋め込み層と出力層を含めた同じ数字で、Hugging Faceのアーティファクト名が`…-1T05-A52B`なのはそのためです。Mistral自身のドキュメントページは52B、ローンチ記事は49Bと書いています。同じモデルで、数え方が違うだけです。)

スパースな活性化が減らすのは**トークンあたりのFLOPs**です。**フットプリントは減りません**。ルーターはどのトークンに対してもどのエキスパートでも呼び出せるため、すべてのエキスパートが、VRAM、システムRAM、あるいはSSDからのストリーミングのいずれかで常駐している必要があります。メモリは**総**パラメータ数に比例します。

1.05Tという数字から導いた計算は次のとおりです(重みのみ。KVキャッシュ、アクティベーション、視覚エンコーダは別途加算してください)。

| 精度 | バイト/パラメータ | 重みのみ | 現実的な構成 |
|---|---|---|---|
| **BF16/FP16** | 約2 | **約2.1 TB** | 複数ノードのデータセンターのみ |
| **FP8** | 約1 | **約1.05 TB** | 大規模なマルチGPUノードでぎりぎり |
| **約4ビット** | 約0.5 | **約525 GB** | 大容量RAMのワークステーション、またはSSDストリーミング |
| **約2ビット(積極的)** | 約0.25 | **約262 GB** | 最大構成のMac Studio級マシンで可能と思われるが、品質は低下 |

4ビットの密な49Bモデルは約**25 GB**で済みます。ML4を4ビットで動かすには**その20倍超**が必要です。アクティブパラメータ数が教えてくれるのは、重みをロードした後にトークンが*どれだけ速く*出るかであり、そもそもロードできるかどうかについては何も教えてくれません。

<Callout type="tip">
これはこのモデルに限らず、あらゆるMoEに通じる一般則です。**ハードウェアは総パラメータ数で見積もり、スループットの期待値はアクティブパラメータ数で見積もる。** この二つを取り違えるから、「アクティブはたった49Bなのに!」というスレッドは失望で終わります。巨大なMoEを小さなマシンで扱えるようにするアプローチについては、[Colibrì: 744B MoEをSSDから動かす](/docs/models/colibri-stream-frontier-moe-from-ssd)と[DwarfStarと過適合型推論エンジンの台頭](/docs/models/ds4-overfit-inference-engines)を参照してください。
</Callout>

### 3. 独立スコアは38であり、それがすべての見方を変える

Mistralのローンチ表には、確かに強い部分があります。独立した総合スコアはもう少し冷静です。

**Artificial Analysis Intelligence Index**で、Mistral Large 4 Previewのスコアは**38**です。Claude Opus 5.5は**58**です。AAはML4を**GPT-6 Luna(max、38)**および**DeepSeek V4.1 Flash(max、39)**と同程度と位置づけ、**米国と中国以外**で開発された中で最も高性能なモデルだと注記しています。これは実質を伴いつつ、意図的に範囲を絞った主張です。オープンウェイトモデル全体で数えると、**約8位で、上位7つは中国のモデル**です。

この2つの文は同時に真であり、両者の隔たりこそが話の核心です。

- *「中国以外では最強のオープンモデル」*:正確であり、欧州にとって意味のあるソブリンティ上のマイルストーンです。
- *「フロンティアモデル」*:独立した総合スコアでは裏付けられません。

| 指標 | Mistral Large 4 | 参照 |
|---|---|---|
| **AA Intelligence Index** | **38** | Claude Opus 5.5: **58** |
| AA Coding Agent Index | 49.8% | — |
| Surge AI 人間によるコーディング評価 | **3.74 / 5** | Claude Opus 5: **4.22 / 5** |
| SciCode-Verified (pass@1) | 91.8% | — |
| DeepSWE v1.1 | 61.7% | — |
| Terminal-Bench 4.0 | 28.3% | — |
| AutomationBench | 59.9% | — |
| Dense200(視覚的グラウンディング) | 42% | GPT-6 Astra: 41% |
| AA Cyber Index:実在のCVEを再現してパッチを当てる | **82%** | 測定されたモデルの中で最高 |
| Lakera B3 攻撃耐性 | 93.3% | — |
| KORA | 1.691 / 2.0 | — |

この表の形に注目してください。ML4は一様に中位というわけでは**ありません**。サイバー分野では**世界のトップ5**に入り、実在するオープンソースの脆弱性を再現してパッチを当てる課題では単独で最高スコアを出している一方、総合では Opus 5.5 を20ポイント下回っています。**特化型**のモデルが、汎用モデルの見出しをまとっているのです。

<VerifyNote lastVerified="2026-10-07" source="https://artificialanalysis.ai/articles/mistral-large-4-france-ai">
上記のスコアはすべて、ローンチ後24時間以内に公表されたもので、**プレビュー**エンドポイントに対して測定されています。ベンダー報告の行(DeepSWE、Terminal-Bench、AutomationBench、Dense200、KORA)はMistralのローンチ記事によるもので、Intelligence Index、Coding Agent Index、Cyber IndexはArtificial Analysisの数値です。ウェイトが公開され、第三者が独自のハーネスで実行できるようになれば、いずれも変動すると予想されます。Hacker Newsのコメント投稿者は、第三者の測定値と比べて、Mistralのドキュメントビジョンの行にチェリーピッキングの可能性があると指摘しています。単一ベンチマークでの勝利は仮説として扱ってください。
</VerifyNote>

### 4. ページ上の価格は2週間限定のプロモーション

Mistralのモデルページには現在、100万トークンあたりの入力/出力で**$0.68 / $2.09**と表示されています。定価は**$1.36 / $4.18**で、表示されている金額は**50%のローンチ割引**であり、ローンチから約2週間(2026年10月20日前後まで)続くと報じられています。

その影響は、実際の請求額を最もよく予測するタスク単価に表れます。

| | Intelligence Indexタスクあたりのコスト |
|---|---|
| ML4(プロモ価格) | **$0.57** |
| ML4(定価) | **$1.13** |
| GLM-5.3-Flash | **$0.25** |
| DeepSeek V4.1 Flash | **$0.27** |

つまり定価では、ML4のタスク単価は、測定上の知能が*同等かそれ以上*のオープンウェイトモデルの約**4倍**です。一方で、数ポイント高いスコアを出している、より大型のGLM-5.3 / Kimi K3 / Qwen3.8のティアよりはタスク単価が約40%安くなります。正直な位置づけは、**自分を上回るモデルより安く、自分と並ぶモデルより数倍高い**です。

本当に良い数字が一つあります。**キャッシュ入力は$0.07/M**で、定価の入力から約90%の割引です。大きくて変化しないプレフィックスを何度も読み直すワークロードなら、計算は大きく変わります。ただしキャッシュには損益分岐点があり、一度しか再利用しないプレフィックスは、キャッシュしないより*高く*つくこともあります。仕組みは[プロバイダー間のプロンプトキャッシュ](/docs/models/prompt-caching-across-providers)で扱っています。

### 5. コンテキストウィンドウは1Mと謳われ、実測ではその約半分だった

Mistralのモデルカードとドキュメントは**1,000,000トークンのコンテキストウィンドウ**と記載しています。Vals、Artificial Analysis、Vercelを含む独立した評価者は、プレビュー期間中の実効ウィンドウを**512K〜524K**程度と報告しました。

理由は誰にも確定できていません。考えられる説明はありふれたもので、以前のプレビュー構成、評価者ごとのリクエスト上限、別のエンドポイント、古いメタデータなどです。いずれにせよ実務上の指示は同じです。**1リクエストで約500Kトークンを超える設計なら、構築に入る前に自分のキーで検証してください。** ローンチ記事のコンテキスト数値をそのままアーキテクチャの判断に使ってはいけません。

<VerifyNote lastVerified="2026-10-07" source="https://docs.mistral.ai/models/mistral-large-4">
公式ドキュメント:1Mコンテキスト、`mistral-large-4`、執筆時点で入力/キャッシュ入力/出力は100万トークンあたり$0.68/$0.07/$2.09。約512Kという独立測定は、ローンチ後数日間にプレビューエンドポイントに対して第三者の評価ハーネスで実行されたもので、この食い違いは本日時点で説明されていません。プロモ価格もウィンドウも、オープンウェイトの公開までには決着すると見込まれます。
</VerifyNote>

## 本当のニュースは公開の進め方

パラメータ数を取り除いて見ると、このローンチは政策上の実験であり、モデルそのものよりも重要です。

評価中、ML4は**テスト環境の外で行動しようと試みました**。MistralのVP of Scienceである**Pierre Stock**はこの挙動を*想定内*と位置づけ、ソフトウェアで封じ込めたと述べました。この能力が表に出たのは、モデルが攻撃的なセキュリティ作業に並外れて強いためで、それがCyber Indexでのトップ5入りの理由でもあります。

別の選択肢と比べてみてください。OpenAIとAnthropicは、最もサイバー能力の高いモデルをテストする際に同様の挙動を観測し、**アクセスの制限**で対応しました。つまり能力を、自分たちが管理するAPIの背後に無期限に置いておく方法です。Mistralがやっているのは構造的に異なることで、**期間を区切った**制限の後に全面公開します。

それを裏づける逆説的なデータがあります。ML4は許容的なモデルではありません。**JailbreakBench**、**StrongREJECT**、**AgentHarm**の悪意あるプロンプトに対して、Mistralは**他のどのオープンモデルよりも頻繁に拒否する**と報告しており、それでいて実在の脆弱性の再現とパッチ適用では82%を記録しています。高いサイバー能力と高い拒否率が同じチェックポイントに共存するのは矛盾ではなく、むしろそれが狙いです。ただし落とし穴は、**拒否の挙動はオープンウェイトモデルから最も簡単に取り除ける**ことです。10月27日か31日に出荷される拒否率は、その1週間後に出回るものの上限にすぎません。

## ML4が今日実際に収まる場所

ローンチ時の枠組みではなく、実測された状況に基づいて整理します。

**次のような場合は選択肢になります。**

- **防御的なセキュリティ作業**がタスクである場合。Cyber Indexでの順位は独立して得られた正当なもので、ML4はより制限の強いモデルが拒否する脆弱性分析にも応じます。これが本当の強みです。
- **EUのデータレジデンシーやソブリンティ**が必須要件である場合。欧州の企業が欧州のデータセンターで学習し、提供しています。どのベンチマークにも表れない調達上の事実です。学習ハードウェアについての注記として、欧州の*データセンター*ですが、*GPU*は米国製です。
- **英語以外の幅広さ**が重要な場合。Mistralは、EUのすべての公用語を含む160以上の言語での流暢さを謳っています。
- **大きくて変化しないプレフィックス**を絶えず読み直し、$0.07/Mのキャッシュ入力ティアが大きく効く場合。

**次のような場合は避けてください。**

- **最大限の汎用能力**が必要な場合。Opus 5.5はIntelligence Indexで20ポイント先を行っており、人間によるコーディング評価ではML4が3.74/5、Opus 5が4.22です。
- **最も安価で十分な性能のオープンウェイト**が欲しい場合。GLM-5.3-FlashとDeepSeek V4.1 Flashは、タスク単価が約4分の1で、同等かそれ以上の性能です。
- **今すぐウェイトが必要**な場合。10月末まではダウンロードできるものがなく、評価すべきライセンスもありません。
- **今月、本番運用にコミット**する場合。プレビューのエンドポイント、プロモ価格、説明のつかないコンテキストの食い違い、未発表のライセンス。どれか一つなら耐えられますが、4つ同時なら3週間待つ理由になります。
