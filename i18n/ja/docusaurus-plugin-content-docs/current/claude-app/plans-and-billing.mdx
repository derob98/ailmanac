## 目的別のティア

| ティア | おおよその用途 |
|---|---|
| **Free** | Claude を試す、軽い個人利用 |
| **Pro** | 定期的な個人利用。より多い使用量、より多い機能 |
| **Max** | Pro の上限に達するヘビーな個人ユーザー |
| **Team** | 小規模チーム。共有ワークスペースと管理 |
| **Enterprise** | 管理、セキュリティ、規模、統制が必要な組織 |

（正確な名称や構成は変わることがあります。料金ページで確認してください。）

## 実際にプランで制限されているもの

ほとんどの場合、答えは*機能*ではなく*使用量*です。だから一つの機能のためにアップグレードするのは、たいてい誤った理由です。以下は 2026 年 10 月時点で知っておく価値のある例外です。

| 機能 | Free | Pro | Max | Team | Enterprise |
|---|---|---|---|---|---|
| アーティファクト、コード、チャート | ✅ | ✅ | ✅ | ✅ | ✅ |
| [ファイル作成](/docs/claude-app/generating-files)（docx/pptx/xlsx/pdf） | ✅ | ✅ | ✅ | ✅ | ✅ |
| [Docs、Slides、Design](/docs/claude-app/one-claude-docs-and-slides) | ✅ | ✅ | ✅ | ✅ | ✅ |
| [Dashboards](/docs/claude-app/dashboards-and-motion)（ベータ） | ❌ | ✅ | ✅ | ✅ | ✅ |
| [Motion](/docs/claude-app/dashboards-and-motion)（ベータ） | ❌ | ❌ | ❌ | ✅ | ✅ |
| 上記に対する組織全体の管理制御 | — | — | — | ✅ | ✅ |

## 「上限」はどう感じられるか

コンシューマー向けプランは、**ある期間にどれだけ使えるか**（時間とともにリセットされるメッセージと使用量）に上限を設け、上位のティアはその上限を引き上げます。上限に達すると、通常はリセットまで待つかアップグレードするよう求められます。**作業が失われるわけではなく、一時停止するだけです。**

より重いモデルや、より長い会話は、枠をより早く消費します。さらに[2026 年 9 月の統合](/docs/claude-app/one-claude-docs-and-slides)以降、もう一つ事実があります。**通常のチャットボックスでの何気ない言い回しのリクエストが、Web を検索し、コードを実行し、ファイルを書き込む長いエージェント的な実行を開始しうる**のです。コストの合図は入口からプロンプトへ移ったので、どちらの方向についても明示しておくのが得策です。

<PromptCard title="答えだけが欲しいときにリクエストを安く保つ">{`Answer from this conversation only. Do not search the web, do not
run code, and do not create any files or artifacts. Two paragraphs.`}</PromptCard>

アップグレードよりも多くの枠を取り戻せる 4 つの習慣があります。いずれも[コンテキスト管理](/docs/foundations/tokens-and-context)のバリエーションです。

## アプリと API 課金 — 別物

- **アプリのプラン** = 使用上限付きの定額サブスクリプション（このページ）。
- **API 課金** = 作ったものに対して[トークン](/docs/api/tokens-and-pricing)ごとに支払う。別のモデルで、別のページ。

残高も、上限も、請求書も共有しません。Max に支払っても API クレジットは得られず、API の支出がチャットの上限を引き上げることもありません。Claude Code は、認証の仕方によって、どちらからでも利用できます。
