Artifacts は **Free、Pro、Max、Team、Enterprise** で利用できます。3 つの*テンプレート* — **Claude Docs**、**Claude Slides**、**Claude Design** — は**有料プラン限定のベータ**です。Pro、Max、Team ではデフォルトで有効、Enterprise ではオーナーが個別に有効化するまでオフです。ここで扱う機能は速く変わります。現在の挙動はヘルプセンターで確認してください。
</VerifyNote>

**Artifacts** とは、Claude がチャットの隣の**サイドパネル**に描画する成果物です。ドキュメント、スライド、チャート、動くアプリなどを、会話のテキストとは別に、見て、使って、繰り返し改善できます。

[2026 年 9 月の統合](/docs/claude-app/one-claude-docs-and-slides)以降、このパネルは 3 つの**テンプレート**が置かれる場所でもあります。つまり「artifact」が入れ物であり、「テンプレート」が出発点となる形です。

## 作れるもの

| 出力 | 何であるか | プラン |
| --- | --- | --- |
| **ミニ Web アプリ＆ツール** | 電卓、クイズ、フォーム、小さなインタラクティブデモ | 全プラン |
| **チャート＆図** | ビジュアルとシンプルなデータダッシュボード | 全プラン |
| **コード** | 読んで実行できるもの | 全プラン |
| **Claude Docs** | Claude やチームと共同編集する、生きたマルチタブ文書 | 有料、ベータ |
| **Claude Slides** | メモや会話から組み立て、その場で発表できるデッキ | 有料、ベータ |
| **Claude Design** | 自分のデザインシステムに沿ったビジュアル、モックアップ、プロトタイプ、ランディングページ | 有料、ベータ |

エクスポート形式は種類によって異なります。Docs は **Word、PDF、Markdown、Google Docs** へ、Slides は **PowerPoint と PDF** へ、Designs は **.zip、PDF、PowerPoint、単体の HTML** として出力できます。

## 非開発者にとって強力な理由

「グループの食事会用にチップ計算機を作って」「この CSV からダッシュボードを作って」のように説明するだけで*使える*ものを作り、そこから会話形式で磨き込めます（「サービス料の欄を追加して」「ボタンを大きくして」）。**自分でコードを書かずに AI で作る**という考え方の、最もわかりやすい例です。

## ヒント

- 入力／出力と対象読者について**具体的に**しましょう。良い[プロンプティング](/docs/prompting/basics)と同じです。
- **少しずつ改善しましょう。** 一度に 1 つの変更のほうが正しく仕上げやすいです。
- 重要な用途では、artifact が計算する**ロジックや数値を必ず検証**してください（[ハルシネーション](/docs/foundations/hallucinations)）。
- **Doc 内のチャートは自動で更新されません。** データを変えても、Claude に作り直すよう頼むまでチャートは古い値のままです。
