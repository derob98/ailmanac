ブラウザ／コンピュータ操作の提供状況（ベータ段階、プラットフォーム、プラン）や正確な挙動は頻繁に変わります — 最新の詳細と制限は公式ドキュメントで確認してください。

Claudeは会話するだけではありません — **ソフトウェアを操作**できます。ブラウザでWebページを読み取って操作したり、コンピュータを制御して（カーソルを動かし、クリックし、入力して）アプリをまたぐタスクを完了したりします。強力ですが、ガードレールを理解しておく価値があります。

## 2つの関連機能

- **ChromeのClaude** — 現在のページを読み取り、あなたに代わってその中で操作（移動、クリック、フォーム入力）を行えるブラウザ側のエージェント。
- **Computer use** — デスクトップをより汎用的に制御（スクリーンショット＋マウス／キーボード）し、ネイティブアプリや複数アプリにまたがるワークフローを操作します。

面倒になりがちな作業に使いましょう：複数ページにわたる情報収集、繰り返しのフォーム入力、複数ステップのWebタスクなど。

:::tip[より範囲の狭い機能を選ぶ]
タスクがすべてWebページ内で完結するなら、デスクトップ全体の制御ではなくブラウザエージェントを使いましょう。届く範囲が狭いほど、うまくいかなくなる要素も減ります。
:::

## 安全モデル（まずここを読む）

AIにあなたの代わりにクリックや入力をさせることは、まさに[プロンプトインジェクション](/docs/security/prompt-injection)が危険になる場面です。悪意のあるWebページには、エージェントを乗っ取ろうとする指示が含まれていることがあります。

通常のチャットよりここで重要になる理由は単純です。チャットでは、乗っ取られたモデルは誤ったことを*言う*ことしかできません。マウスを持つエージェントは誤ったことを*する*ことができ、しかもすでにあなたのアカウントにログインしています。

:::

## 向いているタスクとリスクのあるタスク

| 向いている | 注意が必要 |
|---|---|
| 複数ページにわたる調査（読み取り専用） | お金を使うものすべて |
| 既知で無害なフォームへの入力 | 機密性の高いアカウントへのログイン |
| 監督のもとでの情報の抽出 | 見知らぬ相手からのメールやページに基づく行動 |
