<VerifyNote lastVerified="2026-08-02" source="https://www.anthropic.com">
サードパーティ製ツールの連携や提供状況は頻繁に変わり、プランや地域によっても異なります — 現在の選択肢はAnthropicおよび各ツールの提供元に確認してください。
</VerifyNote>

AIは、いつもこちらから*出向く*ものとは限りません — 最近は**すでに仕事をしているアプリの中**に現れるようになっています。Claudeが今いる場所で使えれば、コピー＆ペーストの手間がなくなり、AIを実際のワークフローに組み込めます。

## AIが現れる主な場所

- **生産性スイート** — ドキュメント、メール、スプレッドシート、スライドに組み込まれたアシスタント（Microsoft 365、Google Workspace）。ファイルを離れずに、下書き・要約・変換ができます。
- **チャット／コラボレーション** — Slackなどのツール内のアシスタントやボット。スレッドの要約、返信の下書き、ナレッジベースに基づく回答に使えます。
- **ブラウザ** — 現在のページを読み取り、操作します — [ChromeのClaudeとComputer Use](/docs/claude-app/chrome-and-computer-use)を参照。
- **自分のアプリ** — [コネクタ（MCP）](/docs/claude-app/connectors)と[API](/docs/api/first-call)経由。

## 「ツールにAIを持ち込む」2つの方法

1. **既存の連携を使う** — 公式のアプリ／アドイン／ボットがあれば、それをインストールします。最も早い方法です。
2. **MCPでつなぐ** — [コネクタ](/docs/claude-app/connectors)を使うと、オープンな[Model Context Protocol](/docs/claude-code/mcp)を通じてClaudeが外部のツールやデータに到達でき、あなたのシステム*と*連携して働けます。

:::tip[まずどちらを選ぶ？]
そのツールに公式の連携があるなら、そこから始めましょう — 今日から使えます。システムが自社製・ニッチ・社内向けの場合、またはClaudeに複数のシステムを1つのタスクで組み合わせさせたい場合に、[MCP](/docs/claude-code/mcp)を使います。
:::
