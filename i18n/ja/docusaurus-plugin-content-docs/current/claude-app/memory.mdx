<VerifyNote lastVerified="2026-08-02" source="https://www.anthropic.com">
チャット間メモリの動作と提供状況はプランによって異なり、また変更されます。最新の詳細はアプリ内またはヘルプセンターで確認してください。
</VerifyNote>

デフォルトでは、各会話は[白紙の状態](/docs/foundations/tokens-and-context)から始まります。**メモリ**機能を使うと、Claudeはあなたに関する有用な事実をチャットをまたいで持ち越せるため、毎回自己紹介をやり直す必要がなくなります。

## ここでいう「メモリ」とは

人が「メモリ」と呼ぶものには、いくつか異なる種類があります。混同しないようにしましょう。

| 種類 | 内容 |
|---|---|
| **コンテキストウィンドウ** | 一つのチャット*内*の作業用メモリ(終了すると忘れる)。[トークンとコンテキスト](/docs/foundations/tokens-and-context)を参照 |
| **チャット間メモリ** | Claudeが、あなたに関する事実を会話*をまたいで*覚えておくこと(このページの主題) |
| **[カスタム指示](/docs/claude-app/custom-instructions)** | *あなた*が明示的に設定する、常に有効な事実 |
| **[プロジェクト](/docs/claude-app/projects)** | ワークスペース単位で管理される知識 |

## チャット間メモリが役立つ場面

有効にすると、Claudeはあなたの好み、進行中のプロジェクト、共有した詳細などを思い出せるようになります。セッションのたびに初対面の相手と話すのではなく、継続して付き合えるアシスタントのように感じられます。提供状況と設定項目はプランによって異なります。

:::tip 暗黙より明示
役割、単位、厳守すべきルールなど、*必ず*適用させたい事実は、[カスタム指示](/docs/claude-app/custom-instructions)を設定するか、[プロジェクト](/docs/claude-app/projects)を使いましょう。メモリが思い出してくれることを期待するより確実です。
:::
