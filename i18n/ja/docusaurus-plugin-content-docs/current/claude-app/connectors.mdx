**コネクタ**を使うと、Claudeアプリは**チャットの外**、つまりあなたのツールやデータ(ドライブ、課題管理ツール、カレンダー、データベースなど)にアクセスできるようになり、Claudeは実際のシステムの情報をもとに回答したり、そのシステムに対して操作を行ったりできます。内部では、オープンな**[Model Context Protocol(MCP)](/docs/claude-code/mcp)**が動いています。

## できること

コネクタがなければ、Claudeが知っているのは会話の中にある内容だけです。コネクタがあれば、あなたの許可のもとで、接続したサービスから関連情報を取得し、回答に活用できます。たとえば、ドキュメントを探す、最近の課題を読む、カレンダーを確認する、といったことです。

```mermaid
flowchart LR
  C[Claude app] -->|via MCP| K[Connector]
  K --- S[(Drive / Tracker / Calendar / DB / SaaS)]
  K -->|data / actions| C
```

## どこでも同じ標準規格

コネクタは、MCPの**アプリ向け**の形です。まったく同じプロトコルが、[Claude CodeのMCP](/docs/claude-code/mcp)や[APIのMCP](/docs/api/mcp)も支えています。概念を一度学べば、すべての利用面に応用できます。

## 安全性

:::warning コネクタとは、アクセス権であり、(場合によっては)操作の権限でもある
- 信頼できるサービスとスコープだけを認可してください。
- 外部ソースから取得したコンテンツには、[プロンプトインジェクション](/docs/security/prompt-injection)が含まれている可能性があります。コネクタが信頼できない素材を読み込む場合は注意してください。
- サードパーティ製のコネクタを有効にする前に、そのコネクタに何ができるかを確認してください([サードパーティコードのレビュー](/docs/security/reviewing-third-party-code))。
:::
