Claudeはデスクトップのタブだけではありません。**iOSおよびAndroidアプリ**なら、ポケットの中にあります — アイデアの記録、ちょっとした質問、外出先での[音声](/docs/claude-app/voice-mode)に最適です。

## モバイルが得意なこと

- **移動中の記録。** エレベーターで浮かんだ考え、ホワイトボードの写真、さっと「これを要約して」 — モバイルは、放っておけば失われる入力に強みを発揮します。
- **音声が中心。** スマートフォンでは、入力するより話すほうが速いことがよくあります — [音声モード](/docs/claude-app/voice-mode)を参照。
- **写真とスクリーンショット。** メニュー、書類、エラーメッセージ、看板を撮って、それについて質問できます（マルチモーダル入力）。
- **連続性。** 会話と[プロジェクト](/docs/claude-app/projects)は同期されるので、モバイルで始めてデスクトップで仕上げられます。

## デスクトップのほうが向いていること

- 長文の**執筆と編集**。
- **大きなドキュメント**や大量のファイルの扱い。
- **[Artifacts](/docs/claude-app/artifacts)**や、画面の広さが役立つあらゆる作業。
- **開発**作業（[Claude Code](/docs/claude-code/what-is-claude-code)はデスクトップ／CLI）。

## モバイルの便利なワークフロー

**音声で記録 → 画面で仕上げ。** 歩きながら、まとまっていないアイデアを[音声](/docs/claude-app/voice-mode)で一気に吐き出し、後でClaudeに*「その書き起こしを整った構成案にして」*と頼みます。スマートフォンが素材を集め、仕上げはどこでもできます。

:::tip[共有シートを使う]
モバイルでは、他のアプリからテキスト・リンク・画像をそのままClaudeに共有できることがよくあります — コピー＆ペーストなしで「これを要約して」と頼める手早い方法です。
:::
