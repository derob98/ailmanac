## 基本の考え方

業者に家の鍵を渡すのと、まず現場を見て「何を変えるつもりか」を書き出してもらうのとでは違います。プランモードは後者の下見にあたります。

**プランモード**は、Claude に**変更せずに調べて提案する**よう指示します。ファイルを読み、調査のためにシェルコマンドを実行し、計画を書きますが、**ソースは編集しません**。計画を承認するまで、編集はブロックされたままです。

<Callout type="tip" items={["プランモードでは、Claude はソースを「調査」するが「変更」はしない。計画を作り、あなたの合図を待つ。"]} />

### 厳密な読み取り専用ではない

調べるにはコマンドが必要なこともあるため、プランモードは「実行しない」ではなく「編集しない」ためのものです。計画中のシェルコマンドがどう扱われるかはセッションによって決まり、最初に当てはまるケースが優先されます。

<Steps items={[{title: "bypass permissions が使えるインタラクティブなターミナルセッション", body: "プランモードのブロックは強制されません。Claude は編集せずに計画するよう指示されたままですが、計画中に試みた編集やコマンドは確認なしで実行されます。それ以外の環境（ヘッドレスの -p 実行、Agent SDK、VS Code 拡張のチャットパネル）ではプランモードのブロックが維持されます。"}, {title: "auto mode が利用可能で useAutoModeDuringPlan がオン（デフォルト）", body: "重要なパスの削除を除き、シェルコマンドは確認ダイアログではなく分類器（classifier）が審査します。承認されたコマンドは実行され、却下されたものはブロックされます。"}, {title: "auto mode が利用できない、または useAutoModeDuringPlan がオフ", body: "組み込みの読み取り専用セットに含まれないコマンドは、承認を求めるプロンプトが表示されます。"}]} />

<Callout type="warning" items={["--allow-dangerously-skip-permissions で起動した場合、プランモードは強固な指示にすぎず、厳格なガードレールではありません。サンドボックスではなく、計画のための取り決めとして扱ってください。"]} />

## 最も安全な出発点である理由

大規模・高リスク・不慣れな作業では、Claude がリポジトリに触れる前に「何をするつもりか」を確認したいものです。プランモードは**考えること**と**実行すること**を切り離します。

```mermaid
flowchart LR
  A[Goal] --> B[Claude investigates<br/>no source edits]
  B --> C[Presents a plan]
  C --> D{You approve?}
  D -->|edit/refine| C
  D -->|approve| E[Claude executes the plan]
```

得られるものは、誤った前提が誤ったコードになる*前*に気づけることです。

## 実際の流れ

ループを順にたどります。各ステップが次のステップの前提になり、Claude は承認の*後*にはじめて編集に移ります。

<Steps items={[{title: "プランモードに入り、目標を伝える", body: "ステータスバーに 'plan mode on' と表示されるまで Shift+Tab で権限モードを切り替えるか、1回のプロンプトの先頭に /plan を付けます。最初からプランモードで始めるには claude --permission-mode plan で起動します。その後、達成したいことを説明します。"}, {title: "Claude が調査する", body: "関連ファイルを読み、調査用のコマンドを実行し、必要に応じて確認の質問をします。"}, {title: "Claude が段階的な計画を返す", body: "変更するファイル、アプローチ、結果の検証方法が示されます。Ctrl+G を押すと、提案された計画をエディタで開いて直接修正できます。"}, {title: "承認または修正する", body: "'Yes, and use auto mode'、'Yes, manually approve edits'、'No, keep planning' のいずれかを選びます。承認するとプランモードを抜け、そのオプションが示す権限モードに移行して、Claude が編集を始めます。"}]} />

計画を承認せずにプランモードを抜けるには、もう一度 `Shift+Tab` を押します。プロジェクトのターミナルセッションでデフォルトにするには、`.claude/settings.json` で `defaultMode` を `plan` に設定します。詳しくは[設定](/docs/claude-code/settings)を参照してください。

### 試してみよう

実際の計画セッションにこれをコピーして、ループが進む様子を確かめてみましょう。

:::tip CLAUDE.md と組み合わせる
優れた [CLAUDE.md](/docs/claude-code/claude-md) があると計画が鋭くなります。Claude があなたの規約やガードレールを踏まえて計画を立てるからです。
:::

## プランモードと権限の違い

よくある取り違えです。この二つは解決する問題が違い、組み合わせて使います。

- **プランモード** = 「まだ編集せず、調査して提案する」。（このページ）
- **[権限（Permissions）](/docs/claude-code/permissions)** = 実際に動く段階で、*どの*操作を確認なしで許可するか。

**いま動くかどうか**（プランモード）と、**動くときにどの操作が許されるか**（権限）の違いだと考えてください。
