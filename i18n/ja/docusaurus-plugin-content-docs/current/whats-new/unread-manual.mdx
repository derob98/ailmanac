学習カットオフは、Claude Platform ドキュメントの各モデルのページから取得しています。Claude Code ドキュメントの履歴は、公式ページを 1 日に数回コピーしているコミュニティミラーから取得しました。数値は 2026 年 10 月 15 日時点のスナップショットです。算出に使ったスクリプトは下にリンクしてあるので、誰でも再実行できます。
</VerifyNote>

すべての Claude モデルは、学習カットオフ時点のドキュメントから Claude Code を学びました。その後もドキュメントは動き続けています。その履歴を 1 週間ずつ再生し、両者がどれだけ離れたかを測りました。

<UnreadHeadline />

最新のモデル、Fable 5.1、Opus 5.5、Sonnet 5.5、Haiku 5.5 の信頼できる知識カットオフは 2026 年 6 月です。6 月末から 10 月 15 日までの間に、ドキュメントは 107 ページから 164 ページに増え、現在の記述の大半はこの 3 か月半に書かれました。事実ではなく正確な文言で数えるとさらに厳しく、割合は 72% に上がります。コード例を除くと 70% です。どう数えても、Claude は自分のマニュアルの大半を一度も見ていません。

## 各モデルが見ていないもの

カットオフが古いほど、モデルが読めた現在のドキュメントは少なくなります。これらのモデルはいずれも Claude API で引き続き利用できます。

<ModelBars />

Claude Haiku 4.5 はカットオフが 2025 年 2 月で、ほぼすべてより前です。Claude Code はその月にリサーチプレビューとして公開され、現在のドキュメントのほとんどはそれ以降に書かれました。

## Claude Code を学んだ週を選ぶ

同じ計算は人にも当てはまります。スライダーを、ドキュメントを読んだ週、または手順に従っているチュートリアルの日付に動かしてください。

<LearnedSlider />

## ドキュメントは増えるだけでなく、書き直される

ギャップの大部分は成長で説明できますが、すべてではありません。ページは書き直されもします。下の各帯は 1 四半期に書かれたテキストで、文が削除・変更されるにつれて帯は細くなります。

<CohortChart />

2025 年 7 月、ドキュメントは 29 ページでした。現在は 164 ページで、文とコード行は 21 倍です。2025 年 7 月時点のドキュメントのうち、今も残っているのは 30.5% で、残りは削除されたか、数値・フラグ・名前が変わる形で書き直されました。最新モデルが見た 2026 年 6 月のドキュメントでさえ、4 か月足らずで事実の 26.9% が失われています。

## 1 つの文はどれくらい持つか

すべての文を、現れた週から消えた週まで追うと、半数は 196 日以内に消えるか言い換えられます。言い換えを、数値・フラグ・パス・名前が変わる場合だけに限ると、事実の半数が消えるまで 266 日、つまり約 9 か月です。

<SurvivalChart />

## あなたのモデルが聞いたことのないもの

現在のリファレンス表にあって、モデルのカットオフ時点にはなかった識別子です。CLI フラグ、スラッシュコマンド、hook イベント、環境変数が含まれます。これらについて Claude に尋ねても、推測するしかありません。

<NewIdentifiers />

「ドキュメント化された時期」は「リリースされた時期」ではありません。ここには、以前から存在していて後からドキュメントに載ったものもあります。いずれにせよ、モデルには学べるページがありませんでした。

## Claude にリストを渡す

[since-cutoff プラグイン](https://github.com/derob98/ailmanac/tree/main/plugins/since-cutoff)は、こうしたリストを Claude の前に差し出します。セッションの開始時に hook がどのモデルが動いているかを読み取り、そのモデルのカットオフ以降にドキュメント化されたフラグ、コマンド、hook イベントの短いメモをコンテキストに追加します。あわせて、記憶に頼ったり機能が存在しないと言ったりする前にドキュメントを確認するよう指示します。

```bash
claude plugin marketplace add derob98/ailmanac --sparse .claude-plugin plugins
claude plugin install since-cutoff@ailmanac
```

hook は数行の POSIX シェルです。Node もネットワークも不要で、1 セッションあたり約 400〜750 トークンです。Claude Code が hook にモデルを渡さない場合、たとえばヘッドレスの `-p` テストでは、メモには 2026 年 6 月以降の変更点が並び、これはどの Claude モデルにも当てはまります。そのテストでは、セッションがメモを受け取り、Claude はそれを一言一句そのまま引用しました。

## これをどう使うか

- **Claude Code についての Claude の記憶を信用しない。** フラグ、設定、hook、コマンドについては、ページを読ませてください。Claude Code には自分自身についての質問に答えるガイドエージェントがあり、ドキュメントは [code.claude.com/docs/llms.txt](https://code.claude.com/docs/llms.txt) にインデックスを公開しています。
- **チュートリアルの日付を確認する。** 6 か月前のガイドは、事実の 3 分の 1 以上を失っています。それより古いものは、コマンドをコピーする前にドキュメントと照合してください。
- **確認日が書いてあるページを選ぶ。** このサイトのすべてのページには最終検証日が載っています。[鮮度ダッシュボード](/docs/whats-new/freshness)にすべて一覧されており、[Deprecation & Migration Watch](/docs/whats-new/deprecations)では削除されたものを追跡しています。

## 測定方法

- **履歴。** [web3dev1337/claude-code-docs](https://github.com/web3dev1337/claude-code-docs) は、同期履歴を完全に保持している有名なドキュメントミラーのフォークで、2025 年 7 月から 2026 年 10 月までに 3,604 回の同期があります。各週の最後の同期を取り、合計 67 のスナップショットを使いました。
- **範囲。** 変更履歴と週次ダイジェスト(履歴を記録するのが役割)、および 2026 年に別のドキュメントサイトから移ってきたために新規として数えられてしまう Agent SDK ページを除く、すべての Claude Code ページ。
- **単位。** 各ページを、リンクとマークアップを除いた文、表の行、コード行に分割します。バナーや一般的なコード行のように、5 ページ以上に同時に現れる行は除外しました。その結果、追跡対象は 90,674 の個別単位になりました。
- **消滅。** 単位は、連続する 2 つの週次スナップショットから、または最新のスナップショットから欠けた時点で消えたとみなします。1 回の同期に失敗したページは数えません。
- **事実。** 同じ週に削除された文を置き換える新しい文は、単語の 60% 以上が一致し、かつすべての数値・フラグ・パス・識別子が同一であれば、同じ事実として扱います。この方法で 7,965 件の言い換えを対応付けました。
- **カットオフ。** 各モデルは、カットオフ月の末日以前の最後の週次スナップショットと比較します。最も寛大な解釈です。2025 年 7 月より前のカットオフには最初のスナップショットを使いますが、これはそれらのモデルが見られたはずのものより多くを含んでいるため、その割合は下限値です。
- **生存。** 最初のスナップショット以降に生まれたすべての単位に対する Kaplan–Meier 推定で、現在も残っている単位は打ち切りとして扱います。

このミラーは非公式です。ページを取りこぼしたり文字化けさせたりしていれば、数値もその影響を受けます。カットオフの週について、同期で消えたページがないか確認しましたが、見つかりませんでした。この分析が比較するのはテキストであり、製品の動作ではありません。

## 再現する

スクリプトとその出力は、このサイトのリポジトリにあります。[scripts/research/docs-decay.mjs](https://github.com/derob98/ailmanac/blob/main/scripts/research/docs-decay.mjs) と [data/research/claude-code-docs-decay.json](https://github.com/derob98/ailmanac/blob/main/data/research/claude-code-docs-decay.json) です。Node と git が必要で、約 15 秒で実行できます。

```bash
git clone https://github.com/web3dev1337/claude-code-docs
git clone https://github.com/derob98/ailmanac
node ailmanac/scripts/research/docs-decay.mjs claude-code-docs
```
