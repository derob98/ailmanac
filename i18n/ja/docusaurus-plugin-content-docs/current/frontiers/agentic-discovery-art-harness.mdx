**2026年9月23日**、Anthropicは*Claude discovers a novel enzyme system with CRISPR-like repeats*を公開した。同じ晩にHacker Newsのトップページに載り、およそ**655ポイント、672コメント**に達したほか、主要メディアすべてが通信社電を配信し、遺伝子編集関連株にも目に見える揺れが出た。誰もが繰り返した要約は「約950のエージェント、21時間、2億1,000万トークン、新しい酵素系が1つ」だった。

これらの数字は本物だ。しかし、この話のなかで最も役に立たない部分でもある。

付属のプレプリント、*Autonomous AI agents discover reverse transcriptases with tandem repeat arrays*(Yoon、Athukoralage、Ameisen、Kauderer-Abrams、Perry、Durrant著)は、ハーネス、会計、失敗モード、そして一連の対照実験を記述している。そこには、自分のエージェントパイプラインの作り方を変えるべき点が少なくとも4つ含まれているが、報道ではそのほとんどが触れられなかった。このページはそれらについて書く。

ARTはプレプリントの成果であり、査読済みの文献ではない。生物学的な部分は明示的に未完成である。著者らは、この酵素が活性を持つこと、またアレイRNAがその基質であることを示して*いない*。以下のハーネスの数字は論文のMethodsに基づくもので、2026年9月に実行された1回のキャンペーンのスナップショットとして扱うべきであり、安定したベンチマークではない。
</VerifyNote>

## キャンペーンの実態

**リサーチブリーフ**(ワークフローではなく、目標を述べた短い文書)は、ローンチエージェントによって5つのステージに展開され、ステージ間にスクリプト化された完了チェックを挟んだチェーンとして実行された。前のステージが閉じるまで、後のステージのタスクは開けない。

| ステージ | 内容 |
| --- | --- |
| 1. 入力の組み立て | 参照セットとプロファイルHMMをゼロから構築する |
| 2. データベーススイープ | **19億**のメタゲノムタンパク質クラスターにわたって逆転写酵素(RT)の遺伝子座を調査する |
| 3. RT分類 | 回収された約20万のRTクラスターを9つのクラスに分類する |
| 4. 近傍センサス | 約11,000の遺伝子座をサンプリングし、繰り返し現れる**3,564**の近傍タンパク質ファミリーをパートナー候補として採点する |
| 5. ディープダイブ | エージェント自身の選定基準を通過したファミリーを調査する |

反対側の出口に出てきたファネルは次のとおり:**3,564の候補ファミリー → エージェントの基準を通過した16(+後から昇格した1) → 19本のレポート → 真に新しいRT関連として確認された3**。17のうち14は、アノテーションのアーティファクト、既知システムの一部、あるいはたまたま近くにあっただけの近傍として棄却された。これとは別に、ワーカーが3つの珍しいRTを報告し、それらは新しい系統であることが判明した。そのうちの1つがARTである。

この生存率こそが正直な見出しだ。10億規模のコーパスに対してよく運営された自律キャンペーンが生み出したのは、擁護できる関連が**3つ**と、興味深い異常が1つだった。それに応じて予算を組もう。

## ハーネス:5つのロール、1つの共有記録

ロール別のセッション内訳:**ワーカー414、スーパーバイザー375、キュレーター107、エディター52**、それにローンチセッションを加えて合計949。スーパービジョンのコストが作業とほぼ同じ規模になっている点に注意してほしい。レビュー重視のハーネスの規模を見積もるなら、ここでの経験的な形はワーカー対スーパーバイザーがほぼ1:1であり、10:1ではない。

エージェントは通常のClaude Codeツール(シェル、ファイル、ウェブ検索)に加え、ハーネスが追加したコネクターを使えた。接続先はタンパク質データベース、文献検索と全文取得、共有ナレッジベース、そしてGPUキューである。HMMER、MMseqs2、BLAST+、MAFFT、FastTree、Infernal、ViennaRNAなどの標準的なバイオインフォマティクスソフトウェアを、エージェント自身がインストールして実行した。保持されたログ全体では、**シェルコマンド7,578回、データベースクエリ696回、文献検索131回、ウェブリクエスト61回**だった。

盗む価値のある細部がひとつある。サンドボックスには約**140のスキル**(文書化された手法ガイド)のライブラリがあり、ワーカーが参照したのはそのうち15だった。7つはサーベイ専用で、そのタイトルは方法論のチェックリストのように読める:遺伝子ファミリーの独立した出現回数の計数、ウィンドウ背景に対するオペロン配置の採点、候補ファミリーの裁定、**新規性の主張の検証**、未特徴づけファミリーのアノテーション、**反事実的な証拠とともにメカニズムを提案すること**、遺伝子近傍の図の作成。最後の2つが、自律キャンペーンを誠実に保つものだ。

## 119タスクのうち98はブリーフにはなかった

キャンペーンのタスク記録の内訳は次のとおり:**ブリーフのステージから生まれたタスクが5、昇格したファミリーから生まれたディープダイブが16、そして実行中に生成されたフォローアップタスクが98**。作業単位のおよそ5分の4が、キャンペーンの途中でエージェントによって考案された。

これはオーバーヘッドではない。結果はここから生まれた。

論文のトランスクリプト分析による連鎖は次のとおり:

1. タスク`t0010`で、ワーカーはジャンボファージのRNAポリメラーゼサブユニットの隣にあるという理由で選ばれたRTファミリーを調べた。ワーカーはその関連を遺伝子順序による見せかけのものとして**棄却した**が、それでもRT自体を見るためのフォローアップをキューに入れた。ジャンボファージにある単独のレトロン様RTは報告に値する副次的な発見になり得る、と記している。
2. スーパーバイザーは、レトロンのRTは上流にコードされた非コードRNAと働くと推論し、次のタスクブリーフを書いた:そのようなRNAがないか5′側のフランキング領域を調べよ。
3. それらのRTの上流領域は中央値で**27 bp**しかなく、RNAをコードするには短すぎた。最も近縁なRTでは中央値が**940 bp**だった。ワーカーは近縁種の上流配列を自分のコンテキストに直接取り込んで見てみた。
4. タスク`t0062`で、その生配列を読んだワーカーは、タンデムリピートアレイに目で気づいた。`CATGTG[T/A]TCGCATGT`に一致する約17 bpのモチーフが、228,907 bpのコンティグの2,900 ntのフランキング領域にわたり、約110〜180 bpのスペーサーを挟んで繰り返していた。2つ目の遺伝子座にも、まったく異なるリピートで同じ構造があった。
5. その後、ワーカーは自分自身に反論した。このパターンをDGRの可変リピート、CRISPRのミニアレイ、既知の多様性生成RTシステムと比較し、新規性の主張を裏付けるのではなく潰すように設計された文献検索を行った。

リサーチブリーフにもタスクブリーフにも、リピートやアレイへの言及はなかった。そのセッションでリピート検出ツールは実行されていない。この発見が存在するのは、**却下された仮説がフォローアップを生むことが許された**からであり、ハーネスが、頼まれていないことをワーカーが追いかけることを許したからだ。

**設計上の含意:**エージェントパイプラインが自分で描いたDAGを実行するだけなら、従来のパイプラインの遅いバージョンを作ったにすぎない。足すべきなのは、お金がかかって無駄に見える部分だ。エージェントが作業を提案するチャネルと、それらの提案を自動実行も自動破棄もせず、書面でレビューするゲートである。

## トークン請求書を正しく読む

広く引用される数字は「2億1,000万トークン」だ。論文の会計はもっと具体的で、その形が重要になる:

| 項目 | トークン |
| --- | --- |
| キャッシュなし入力 | 1,130万 |
| 出力 | 1,490万 |
| プロンプトキャッシュへの書き込み | 1億8,950万 |
| **報告された合計** | **2億1,560万** |
| プロンプトキャッシュからの読み取り | *合計から除外* |

つまり、**見出しの数字の88%はキャッシュ書き込み**であり、システム内で実際に最大の量(949セッションに共有ナレッジベースを供給した仕組みであるキャッシュ読み取り)はそこに含まれていない。人々が直感的に見積もる出力トークンは、7%にすぎない。

実践上の帰結が2つある。第一に、自分のハーネスを「2億1,000万トークン」と比較するなら、同じ4つの項目を数えているか確認すること。ほとんどのダッシュボードは異なる構成で報告している。第二に、共通メモリを持つ多セッションのハーネスでは、キャッシュの経済性がコストを支配する。キャッシュ書き込みは基本入力より割高に課金され、キャッシュ読み取りは大幅に割り引かれるため、両者の比率が請求書に対する最大の梃子になる。その計算の仕組みは[プロンプトキャッシュの経済学](/docs/frontiers/prompt-caching-economics)を参照してほしい。論文は金額を明示しておらず、このページも明示しない。

実時間は**21.5時間**で、**76.9エージェント時間**に対する平均同時実行数は、上限58にもかかわらず約3.6だった。長時間のエージェントキャンペーンは、ステージのゲートとレビューのループが待ちを強いるため、同時実行数の上限が示唆するよりはるかに直列的になる。

## 発見は再現しなかった

これは、他のどの結果よりも引用されるべき結果だ。

著者らは同一のキャンペーン(同じハーネス、同じブリーフ)を**さらに10回**再起動し、3,084件のタスク記録と5,632件のセッショントランスクリプトを得た。センサスを完了したほぼすべてのレプリケートでARTの遺伝子座がサンプリングされた。そのうち2つでは、ワーカーがその系統についてフォローアップを開いた。

**上流のDNAを読んだものはひとつもなかった。再実行のたびにアレイは見逃された。**論文はこれを、RT探索空間の広さとハーネスの非決定的な挙動のせいだとしている。

これは両方向で真剣に受け止めるべきだ:

- **過大な主張への戒めとして。**「AIがXを発見した」は、確率過程からの1つのサンプルを述べているのであって、呼び出せる能力を述べているのではない。11回のキャンペーンで発見されたのは1回だけだった。
- **パイプライン設計のために。**エージェンティックな探索の単位は1回の実行ではなく、実行の*母集団*だ。発見に価値があるなら、キャンペーンを複製し、レプリケート間で重複を除去し、単発のレポートは手がかりとして扱うこと。これは無料の陰性対照にもなる:すべての実行が生み出すものは、おそらくデータの性質ではなくパイプラインの性質だ。
- **評価のために。**実在する異常を11回に1回浮かび上がらせるハーネスは、1回の実行コストが数百ドルで、見返りが新しい生物学的システムであるなら、依然として非常に価値がある。再現性が低いことは期待値が低いことと同じではない。ただし、値付けすべきは結果ではなく実行のほうだ。

## ツールを与えるとモデルは見えなくなった

キャンペーン自体が再現できなかったため、著者らは**固定入力ベンチマーク**を構築した。1つのモデルにARTシステムを5つの情報レベルのいずれかで与え、遺伝子座を特徴づけて機能を予測させ、判定モデル(Mythos 5)がアレイ、RT、パートナーについての厳選された10の主張に照らしてレポートを採点する。

5つのレベルは、2つのRTタンパク質配列から、2つの遺伝子座を生テキストで、ツール付きで96の遺伝子座すべてをファイルで、ファイルに加えて予測構造、ファイルに加えて文献とウェブアクセス、へと段階的に拡大する。

予想される結果は、情報とツールが増えれば単調に助けになるというものだ。パートナー遺伝子についてはそのとおりだった。しかし実際の発見である**アレイ**については、逆転した:

- 遺伝子座が**テキストとしてコンテキストに入っている**場合、最も高性能なモデルは**少なくとも90%**の試行でアレイを正しく記述した。
- 同じデータが**ファイルとツール付き**になると、認識率は**32%**(Opus 5、レベル4)まで低下した。
- トランスクリプトを調べると理由がわかった。ファイルベースの実行では、**試行の39%が200 nt以上の連続した領域を一度も読まず**、繰り返し単位1つ分程度を超えて見ることがなかった。配列に対してクエリを投げ、grepし、要約し、推論はしたが、配列そのものを見てはいなかった。
- 実行が200 nt以上を連続して読んだ場合、認識率は**16〜32パーセントポイント高かった**。最も強い4モデルを合算すると、より多くのDNAがコンテキストに入るにつれて認識率は**29%から76%**に上がり、Mythos 5では**96%**に達した。

モデルのパネルも注目に値する。論文は7つのClaudeモデルをテストし、最も強い4つ(Opus 5.5、Mythos 5.1、Mythos 5、Opus 5)とそれ以外(Opus 4.8、Opus 4.6、Sonnet 5)の間に明確な能力差があることを見出した。これは、元のキャンペーンの成功が、それが動いたフロンティアモデルに依存していたことを示す証拠である。

**転用できる教訓は生物学とは無関係だ。**シグナルが生データの*形*に宿っているとき(ログの繰り返しパターン、バイナリの規則的なオフセット、時系列の奇妙なリズム、設定ファイル内の重複したスタンザ)、ツールを介したアクセスは、モデルに見る代わりに要約するという、もっともな行動をとらせる。ツールは抽象化であり、抽象化はまさに異常を隠すものだ。これは通常のコンテキストエンジニアリングの助言の逆であり、その正当な例外である:

これを[コンテキストエンジニアリング](/docs/frontiers/context-engineering)の標準的な助言と組み合わせてほしい。*実行*タスクでは積極的にキュレーションし、*発見*タスクでは一次データを直接見るためにトークンを支払う。この2つは別の仕事だ。

## なぜ気づいたか:リピートで発火する検出器

論文で最も珍しいセクションは、実際の発見のトランスクリプトに対して行われた解釈可能性分析だ。著者らはワーカーのセッションをMythos 5に通し直し、ある1つの層でのモデルの活動を解釈可能なシグナルに分解して、反復するDNAに反応するものを探した。

見つかったのは2つだ。どちらもアレイが始まる前は沈黙していた。**リピートシグナル2**は3コピー目までに強まり、その後は一定を保ち、活動はほぼ完全にリピートとその直後のヌクレオチドに限られていた。**リピートシグナル1**は3コピー目でピークに達し、その後は弱まった。説得力があるのは対照実験だ。*各コピーの内部で*ヌクレオチドをシャッフルすると(組成は保たれ、反復は壊れる)、リピートシグナル2は14コピーすべてで、リピートシグナル1は14コピー中12で沈黙した。どちらのシグナルもDNAに特異的ではない。

比較として、著者らは2つの専用ゲノム言語モデル、Evo 2とgLM2を同じ遺伝子座で動かした。どちらもリピートを確信を持って検出し、双方向モデル(gLM2)は最初のコピーを含むすべてのコピーを捉えた。一方、因果モデル(Evo 2)は最初の2コピーの予測が悪く、アレイに沿って改善した。後ろ向きにしか見えないモデルから予想されるとおりの挙動だ。

トランスクリプトでは、シグナルの発火の直後に、そのパターンをタンデムリピートアレイと名指しする自然言語の推論が続く。汎用アシスタントが生配列の構造的性質に対する内部検出器を持っており、その検出器の活性化が言語化された観察として表に出たのだ。これは「どうして気づいたのか」に対する具体的でメカニズム的な答えであり、ツール盲目性の結果を退けずに信じる理由でもある。コンテキストに一度も入らなかったバイトに対して、検出器は発火できない。

## 判定者はそれを1位にしなかった

19本のレポートは総当たりの対戦トーナメントで順位付けされた。順序付きの全ペアを1回ずつ比較して**342試合**。Mythos 5の判定者が固定のルーブリックと匿名化された2本のレポートを読み、それぞれをインパクト(重み0.35)、新規性(0.30)、健全性(0.25)、実行可能性(0.10)について1〜5で採点した。健全性が2以下のレポートは自動的に負けとなった。レーティングはBradley–Terryモデルで当てはめた。

ARTのレポートは36試合中32勝で**3位**だった。

ここから受け取るべきことは3つある。匿名化した総当たりと、健全性での自動敗北は、レポートを1〜10のスケールで個別に採点するよりはるかに良いLLM判定者の設計だ。ペアワイズ比較のほうが安定しており、健全性の下限が、自信満々のナンセンスを新規性で勝つ前に潰す。しかしそれでも、バッチ内で最良の結果が1位にはならなかった。したがって**LLM判定者の順位はトリアージの順序として扱い、評決とは扱わない**こと。そしてtop-kを十分に広く取り、3位の項目でも人間に届くようにすること。さらに、この仕組み全体はどのみち人間の下流にあることに注意してほしい。生き残った候補はすべて人間の科学者に渡り、ウェットラボの作業は完全に人間のものだった。この制約の一般的な形は[検証のボトルネック](/docs/frontiers/the-verification-bottleneck)を参照。

## ARTについて実際にわかっていること

十分に慎重になる理由があるので、きれいに分けておく価値がある。

**プレプリントが裏付けているもの:**

- ART(array-associated reverse transcriptase)は、主にジャンボファージゲノムに限られるRTのファミリーで、レトロンの隣のクレードに位置する。
- 各遺伝子座は3つの部分から成る:約200 ntのリピート単位のアレイ、RT、そして専用のパートナー遺伝子。パートナータンパク質の構造タイプは3種類観察された(59、7、3の系統)。
- リピートのレイアウトはCRISPRアレイに似ているが、CRISPRスペーサーと異なり、ARTの単位は**近縁なファージ間で保存されている**。
- *Staphylococcus*ファージSA1感染のRNA-seq時系列(公開BioProject PRJNA836150)では、アレイは大量に転写され、個別の単位として現れる。酵素自体よりもはるかに過剰に転写されている。このパターンは、1つの酵素に対して異なるRNAのレパートリーが供給されていることを示唆する。
- このシステムは目の前に隠れていた:ファージMarsHill(GenBank `MW248466.1`)について、元のゲノム報告はRTを特定し5′の非コードRNAを提案したが、リピートにもパートナー遺伝子にも触れていなかった。

**示されていないもの:**

- RTが酵素的に活性であること。
- アレイRNAがその基質であること。
- RTとそのパートナーが相互作用するかどうか。
- このシステムがファージのために何をしているか。これは未解決であり、著者らもそう述べている。

ARTを「新しい遺伝子編集ツール」と位置づけるものは、証拠より数年先を走っている。実証されたのは*発見のプロセス*であり、生物学ではない。
