Un **Projet** est un espace de travail dédié dans Claude.ai qui regroupe **ses propres fichiers, connaissances et instructions**. Au lieu de re-téléverser les mêmes documents et de réexpliquer le contexte à chaque conversation, vous le configurez une fois — et chaque conversation dans le Projet démarre déjà informée.

## Pourquoi utiliser un Projet

- **Réponses ancrées.** Ajoutez vos documents (un manuel, des spécifications, des notes) et Claude répond *à partir d'eux* — une variante intégrée et sans code du [RAG](/docs/foundations/rag).
- **Contexte persistant.** Les instructions du projet agissent comme un [prompt système](/docs/foundations/roles) à portée limitée pour tout ce qui s'y trouve.
- **Organisé.** Toutes les conversations sur un même sujet / client / initiative vivent ensemble.

## D'excellents cas d'usage

- Un espace de travail **client / compte** (leurs documents + vos notes).
- Une base de connaissances sur une **base de code ou un produit** pour les questions-réponses.
- Un **projet de rédaction** avec votre guide de style et vos écrits passés (pour que les brouillons correspondent à votre voix).
- Les **études** pour un cours, avec le programme et les supports chargés.

## Conseils

- **Sélectionnez les connaissances** — des fichiers pertinents et à jour valent mieux que de tout déverser (le bruit nuit à la récupération).
- **Gardez les instructions concises et justes** (même règle que pour les [instructions personnalisées](/docs/claude-app/custom-instructions)).
- **Élaguez quand les choses changent.** Une spécification dépassée laissée dans la base de connaissances est pire que pas de spécification du tout, parce que Claude n'a aucun moyen de savoir qu'elle a perdu un arbitrage face à la nouvelle.
- **N'ajoutez pas de données sensibles** que vous ne seriez pas à l'aise de stocker — voir [Confidentialité](/docs/foundations/privacy).

## Deux choses appelées « Projets »

Ce sont réellement deux produits différents, et les noms se chevauchent pendant le déploiement :

| | Ce Projet (Claude.ai) | [Projets Claude Code](/docs/claude-code/projects-coordinator-threads) |
|---|---|---|
| Ce que c'est | Un espace de travail avec connaissances + instructions | Un coordinateur qui délègue à des threads parallèles |
| Ce que ça fait | Ancre *vos* conversations dans *vos* fichiers | Cadre, découpe et exécute le travail pour vous |
| Exécute du code ? | Non | Oui — chaque thread est une session cloud sur sa propre branche |
| Qui l'a | Largement disponible | Bêta, utilisateurs Claude Code Pro/Max sélectionnés au lancement |

Si vous lisez des choses sur les coordinateurs, les threads et les pull requests, c'est de celui de Claude Code qu'il s'agit.
