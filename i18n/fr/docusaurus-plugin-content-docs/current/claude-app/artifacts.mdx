Les artifacts sont disponibles sur les offres **Free, Pro, Max, Team et Enterprise**. Les trois *templates* — **Claude Docs**, **Claude Slides** et **Claude Design** — sont **en bêta sur les offres payantes uniquement** : activés par défaut sur Pro, Max et Team, et désactivés sur Enterprise jusqu'à ce qu'un propriétaire les active un par un. Les capacités évoluent vite ici — confirmez le comportement actuel dans le Centre d'aide.
</VerifyNote>

Les **artifacts** sont des sorties que Claude affiche dans un **panneau latéral** à côté de la conversation — un document, une présentation, un graphique, une application fonctionnelle — que vous pouvez voir, utiliser et faire évoluer, séparément du texte de la conversation.

Depuis la [fusion de septembre 2026](/docs/claude-app/one-claude-docs-and-slides), le panneau est aussi l'endroit où vivent les trois **templates**. Cela fait de l'« artifact » le conteneur et du « template » la forme de départ.

## Ce que vous pouvez créer

| Sortie | Ce que c'est | Offre |
| --- | --- | --- |
| **Mini-applications et outils web** | Une calculatrice, un quiz, un formulaire, une petite démo interactive | Toutes les offres |
| **Graphiques et schémas** | Des visuels et de simples tableaux de bord de données | Toutes les offres |
| **Code** | Quelque chose que vous pouvez lire et exécuter | Toutes les offres |
| **Claude Docs** | Un document vivant, multi-onglets, que vous co-éditez avec Claude et votre équipe | Payant, bêta |
| **Claude Slides** | Une présentation construite depuis vos notes ou la conversation, projetable sur place | Payant, bêta |
| **Claude Design** | Visuels, maquettes, prototypes et landing pages conformes à votre design system | Payant, bêta |

Les exports diffèrent selon le type : les Docs partent vers **Word, PDF, Markdown et Google Docs** ; les Slides vers **PowerPoint et PDF** ; les Designs en **.zip, PDF, PowerPoint ou HTML autonome**.

## Pourquoi c'est puissant pour les non-développeurs

Vous pouvez créer quelque chose d'*utilisable* — « fais-moi une calculatrice de pourboire pour un dîner de groupe », « un tableau de bord à partir de ce CSV » — en le décrivant, puis l'affiner par la conversation (« ajoute un champ frais de service », « agrandis les boutons »). C'est l'exemple le plus clair de **construire avec l'IA sans écrire de code soi-même**.

## Conseils

- **Soyez concret** sur les entrées / sorties et le public — comme pour un bon [prompting](/docs/prompting/basics).
- **Itérez petit.** Un changement à la fois est plus facile à réussir.
- **Vérifiez toute logique / tout chiffre** qu'un artifact calcule pour les usages importants ([Hallucinations](/docs/foundations/hallucinations)).
- **Les graphiques à l'intérieur d'un Doc ne se rafraîchissent pas tout seuls.** Changez les données et le graphique garde les anciennes valeurs jusqu'à ce que vous demandiez à Claude de le reconstruire.
