Cowork는 **2026년 7월 7일**부로 더 이상 데스크톱 전용 워크스페이스가 아닙니다. 이제 **웹 (claude.ai)**, **iOS 및 Android**에서 실행되며 — 대부분의 리뷰가 잘 다루지 않는 부분은 — 세션이 **Anthropic의 서버**에서 실행된다는 점입니다. 여러분의 기기가 아닙니다. 이 하나의 아키텍처 변화가 헤드라인 기능을 가능하게 만듭니다: **노트북이 닫혀 있고, 휴대폰이 주머니에 있고, 어떤 기기도 온라인이 아닌 상태에서 실행되는 예약 작업**.

## 중요한 단 하나의 변화: 세션이 Anthropic의 서버로 이동했다

2026년 7월 이전에는 Cowork 세션이 Mac 또는 PC의 Claude Desktop 앱 내부의 프로세스였습니다. 노트북을 닫으면 세션이 죽습니다. 앱을 종료하면 세션이 죽습니다. 이것이 7월 이전 Cowork 루프가 항상 "데스크톱을 열고 깨어있게 유지하라"로 시작한 이유입니다.

7월 출시는 **원격 세션**을 도입합니다: Cowork 루프는 Anthropic의 클라우드에서 살고, 세션 상태와 파일은 여러분의 Claude 계정에 대해 유지되며, 어떤 서피스(웹, 모바일, 데스크톱)든 동일한 근본 세션에 대한 뷰어 + 입력 장치일 뿐입니다.

두 가지 직접적인 결과:

1. **예약 작업이 가능해집니다.** 반복 작업이 월요일 06:00에 깨어나 45분간 작업하고 계정에 초안을 남길 수 있습니다 — 어떤 기기도 온라인이 아닌 상태로, 루프에 기기가 없기 때문입니다.
2. **크로스 디바이스 핸드오프는 무료입니다.** 책상에서 작업을 시작하고, 노트북을 닫고, 실행 중인 같은 세션을 휴대폰에서 볼 수 있습니다. 동기화할 것이 없습니다 — 세션은 애초에 노트북에 있었던 적이 없습니다.

트레이드오프는 아래의 역량 매트릭스입니다: **로컬 머신**에 접근해야 하는 모든 것(디스크의 파일, 브라우저, OS)은 데스크톱에서만 실행할 수 있습니다. 그것이 두 세계에 발을 걸친 유일한 서피스이기 때문입니다.

## 대신 API로 넘어가야 할 때

예약 Cowork 작업은 제품 기능입니다 — 여러분의 Claude 계정에서 볼 수 있고, 루프에 인간 승인이 있는 개인 / 소규모 팀 반복 작업에 훌륭합니다. 다음이 필요할 때는 잘못된 도구입니다:

- **시간 미만의 주기** — 가장 작은 예약 작업 간격은 시간별입니다.
- **프로그래밍 방식의 오케스트레이션** — 수십 개의 병렬 실행, 동적 스케줄링 또는 인프라와의 긴밀한 통합. [Managed Agents](/docs/api/managed-agents)로 넘어가거나, [Agent SDK](/docs/claude-code/headless-and-agent-sdk) + 이미 실행 중인 cron/큐로 직접 구축하세요.
- **실행 간 서버 사이드 메모리** — Cowork 작업은 계정의 파일을 통해 상태를 전달하는데, 이는 문서에는 괜찮지만 구조화된 상태에는 조잡합니다. 구조화된 실행 간 메모리에는 [Managed Agents Memory Stores](/docs/api/managed-agents-memory-stores)를 사용하세요.
- **깊은 멀티 에이전트 조정** — 많은 에이전트가 협업하는 경우, [Cowork & Agent Teams](/docs/api/cowork-and-agent-teams)와 [Native Multi-Agent APIs](/docs/models/native-multi-agent-apis)를 참조하세요.
