## 핵심 아이디어

야심 찬 대규모 변경을 Claude에게 맡길 때 가장 무서운 질문은 "편집을 세 번쯤 하다가 잘못되면 어떡하지?"입니다. **체크포인트(Checkpointing)**가 그 답입니다. Claude Code는 매 편집 전에 코드를 자동으로 스냅샷으로 저장하므로, 반쯤 끝난 리팩터링을 손으로 풀어내는 대신 이전 상태로 되감을 수 있습니다.

**세션 전체에 대한 로컬 실행 취소**라고 생각하세요. "좋아, 과감한 방법을 시도해 봐"라고 두려움 없이 말할 수 있게 해 주는 안전망입니다.

## 체크포인트가 만들어지는 방식

체크포인트를 직접 만들 필요는 없습니다. 자동으로 생깁니다.

## 되감기 메뉴 열기

들어가는 방법은 두 가지입니다.

<Steps items={[{title: "/rewind 실행 — 또는 별칭 /checkpoint, /undo", body: "프롬프트에서 슬래시 명령을 입력합니다. 항상 동작합니다. /checkpoint와 /undo는 같은 명령의 별칭이므로, 떠오르는 이름을 쓰면 됩니다."}, {title: "Esc 두 번 누르기 — 단, 입력창이 비어 있을 때만", body: "프롬프트 입력창이 비어 있을 때 Esc를 두 번 누르면 되감기 메뉴가 열립니다. 텍스트가 들어 있으면 Esc 두 번은 대신 그 텍스트를 지웁니다(지워진 텍스트는 입력 기록에 저장되므로 위쪽 화살표로 되살릴 수 있습니다)."}]} />

<PromptCard title="되감기 메뉴 열기">{`/rewind`}</PromptCard>

<Callout type="warning" items={["별칭 이름은 글자 그대로의 뜻보다 친숙하게 지은 이름입니다. /checkpoint는 요청 시 스냅샷을 찍지 않으며(스냅샷은 자동입니다), /undo는 마지막 편집을 혼자서 취소하지 않습니다. 세 이름 모두 같은 메뉴를 열고, 그 안에서 시점과 동작을 직접 고릅니다."]} />

메뉴에는 **이 세션에서 보낸 모든 프롬프트**가 나열됩니다. 작업할 시점을 고른 다음, 동작 하나를 선택하세요.

## Restore와 Summarize: 핵심 구분

여기서 사람들이 헷갈립니다. 메뉴는 두 *종류*의 동작을 제공합니다.

- **Restore** 동작은 디스크 및/또는 대화의 상태를 바꿉니다 — 되돌리는 동작입니다.
- **Summarize** 동작은 파일을 절대 건드리지 않습니다 — 컨텍스트 창의 공간을 확보하기 위해 대화를 압축합니다.

<Callout type="warning" items={["Restore = 실행 취소(코드, 대화 또는 둘 다 되돌림). Summarize = 컨텍스트 압축(디스크의 파일은 그대로).", "편집이 무언가를 망가뜨렸다면 restore를 쓰세요. 세션은 비대해졌지만 코드는 괜찮다면 summarize를 쓰세요."]} />

### Restore 동작

<Steps items={[{title: "Restore code and conversation", body: "파일과 채팅 기록을 모두 선택한 시점으로 되돌립니다 — 그 순간으로 깔끔하게 '시간을 되감는' 동작입니다."}, {title: "Restore conversation", body: "채팅을 해당 메시지까지 되감되 현재 코드는 유지합니다. 남기고 싶은 편집을 잃지 않고 질문을 다시 할 때 유용합니다."}, {title: "Restore code", body: "파일 변경은 되돌리되 대화는 유지합니다. 편집은 취소하고, 그에 대한 논의는 남깁니다."}]} />

두 가지 **코드** restore 옵션은 선택한 체크포인트에 되돌릴 추적된 파일 변경이 실제로 있을 때만 나타납니다. 그 시점 이후에 캡처된 파일 편집이 없다면 메뉴에는 **Restore conversation**, 두 summarize 옵션, 그리고 **Never mind**(아무것도 바꾸지 않고 메시지 목록으로 돌아감)만 표시됩니다.

대화를 복원한 뒤(또는 "Summarize from here"를 선택한 뒤)에는 선택한 메시지의 원래 프롬프트가 입력창에 다시 채워져, 다시 보내거나 수정할 수 있습니다.

### Summarize 동작

둘 다 대화의 일부를 AI가 생성한 요약으로 압축합니다 — 선택한 메시지의 어느 쪽을 압축할지 고를 수 있는 **표적형 `/compact`**와 같습니다.

<Steps items={[{title: "Summarize from here", body: "선택한 메시지 이전의 메시지는 그대로 유지됩니다. 선택한 메시지와 그 이후는 요약이 됩니다. 곁가지 논의는 버리면서 초반 컨텍스트는 자세히 유지하고 싶을 때 쓰세요."}, {title: "Summarize up to here", body: "선택한 메시지 이전의 메시지가 요약이 되고, 선택한 메시지와 그 이후는 그대로 유지됩니다. 대화의 끝에 머뭅니다. 초반의 준비 대화는 압축하면서 최근 작업은 원문 그대로 유지하고 싶을 때 쓰세요."}]} />

어느 쪽이든 원래 메시지는 세션 기록에 남으므로 Claude가 여전히 세부 내용을 참조할 수 있고, 압축된 메시지가 있던 자리에 **Summarized conversation** 표시가 나타납니다. 요약이 무엇에 초점을 둘지 조정하려면, 화살표 키로 **Summarize** 옵션을 강조하고 줄에 **add context (optional)**이라고 표시된 곳에 지침을 입력한 뒤 Enter를 누르세요 — 숫자 키로 옵션을 고르면 지침 없이 즉시 요약됩니다.

전체 흐름은 [컨텍스트 관리](/docs/claude-code/context-management)를 참고하세요 — `/compact`가 굵은 붓이라면 `/rewind`의 summarize 동작은 메스입니다.

<Callout type="note" items={["Summarize는 같은 세션에 머뭅니다. 원래 세션은 그대로 둔 채 가지를 쳐서 다른 접근을 시도하려면 /branch 또는 claude --continue --fork-session을 대신 사용하세요."]} />

## `/clear` 이전으로 되감기

같은 Claude Code 프로세스에서 앞서 `/clear`를 실행했다면, 되감기 메뉴 맨 위에 항목이 하나 더 나타납니다: `/resume <session-id> (previous session)`. 이를 선택하면 `/clear` 이전에 활성 상태였던 대화로 돌아갑니다.

<VerifyNote lastVerified="2026-10-20" source="https://code.claude.com/docs/en/checkpointing">
이 항목은 Claude Code를 종료하거나 다른 세션을 재개하기 전까지만 사용할 수 있습니다. 사라진 뒤에는 `/resume`을 실행하고 목록에서 이전 세션을 고르세요.
</VerifyNote>

## 체크포인트가 멈추는 곳 — 아프게 다가오는 한계

체크포인트는 마법처럼 느껴지다가 그렇지 않게 되는 순간이 있습니다. 다음 빈틈이 중요합니다.

```mermaid
flowchart TD
    A[Claude does work] --> B{How was the file changed?}
    B -->|Edit / Write file tool| C[Tracked — rewindable]
    B -->|Bash command: rm / mv / cp| D[NOT tracked]
    B -->|Manual edit or other session| E[NOT tracked]
    B -->|Background subagent| E
    C --> H{Is the path a symlink<br/>or hard link?}
    H -->|No| F[/rewind can restore it/]
    H -->|Yes| G[Only Git can recover it]
    D --> G
    E --> G
```

## 체크포인트 vs. Git: 둘 다 쓰세요

해결하는 문제가 다르니 함께 쓰세요.

| | 체크포인트 (`/rewind`) | Git |
|---|---|---|
| 범위 | 하나의 세션 | 프로젝트 전체 히스토리 |
| 세분성 | 턴을 시작하는 프롬프트마다, 자동 | 커밋마다, 의도적 |
| bash로 한 변경을 추적? | 아니요 | 예 (스테이징/커밋한 뒤) |
| 수명 | 최근 100개 체크포인트, 세션 후 약 30일 뒤 정리 | 영구 |
| 공유 / 협업 | 불가 | 가능 |
| 멘탈 모델 | "로컬 실행 취소" | "영구 히스토리" |

<Callout type="tip" items={["위험하고 대규모인 작업 전에 동작하는 상태를 Git으로 커밋하세요 — 그것이 내구성 있는 바닥선입니다.", "커밋 사이의 빠른 세션 내 복구에는 /rewind를 사용해 Git 히스토리를 어지럽히지 마세요.", "Claude가 파괴적인 bash(rm/mv), 생성기, 백그라운드 서브에이전트를 실행할 거라면 Git에 의존하세요 — 되감기는 그 파일들을 구하지 못합니다."]} />
