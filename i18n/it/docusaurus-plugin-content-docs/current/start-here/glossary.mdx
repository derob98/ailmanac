### Agent
Un'AI configurata per **compiere azioni in un loop** — legge un obiettivo, chiama tool, osserva i risultati e ripete finché non ha finito. Claude Code è un agent per la tua codebase.

### Anthropic
L'azienda che crea Claude.

### API (Application Programming Interface)
Un modo per far comunicare il *tuo* software con Claude in modo programmatico, anziché scrivere in una finestra di chat. Vedi [La tua prima chiamata API](/docs/api/first-call).

### Artifact
Un output vivo ed eseguibile (un'app, un grafico o un documento) che Claude visualizza in un pannello laterale su claude.ai, separato dalla chat.

### Chain-of-thought (CoT)
Chiedere al modello di **ragionare passo dopo passo** prima di rispondere, il che migliora l'accuratezza sui problemi difficili.

### Claude
La famiglia di modelli AI (e di app) realizzata da Anthropic. "Claude" può indicare l'app di chat, i modelli o il marchio, a seconda del contesto.

### Claude Code
Lo **strumento agentico da riga di comando/IDE** di Anthropic, capace di leggere e modificare la tua codebase, eseguire comandi e usare tool. Vedi [Che cos'è Claude Code](/docs/claude-code/what-is-claude-code).

### CLAUDE.md
Un file di testo semplice in cui dai a Claude Code istruzioni persistenti sul tuo progetto: la sua personalizzazione a più alto impatto.

### Compaction
Condensare automaticamente i turni più vecchi della conversazione in un breve riassunto quando la [context window](/docs/foundations/tokens-and-context) si riempie, così una sessione lunga può proseguire senza perdere il filo. Vedi [Gestione del contesto](/docs/claude-code/context-management).

### Context engineering
Decidere deliberatamente cosa entra nella [context window](/docs/foundations/tokens-and-context) del modello — istruzioni, esempi, dati recuperati — per ottenere il risultato migliore. La disciplina dietro prompting, RAG e memoria.

### Context window
La quantità massima di testo (misurata in **token**) che un modello può considerare in una sola volta — il tuo prompt *più* la sua risposta. Superala e i contenuti più vecchi vengono scartati.

### Effort
Un controllo, sui modelli Claude più recenti, su quanto all'incirca **il modello pensa** prima di rispondere. Adatta il livello al task invece di portarlo al massimo — il pensiero lo paghi in latenza e costo. Vedi [Extended Thinking ed Effort](/docs/api/thinking-and-effort).

### Embedding
Una lista di numeri che rappresenta il *significato* di un brano di testo, così il software può trovare cose simili per significato (non solo per corrispondenza di parole chiave). Alla base della ricerca semantica e del RAG.

### Eval (evaluation)
Un test ripetibile della qualità dell'output dell'AI, così puoi capire se una modifica ha migliorato o peggiorato le cose.

### Few-shot
Includere **alcuni esempi svolti** nel prompt per mostrare al modello lo schema che desideri.

### Fine-tuning
Addestrare ulteriormente un modello sui tuoi esempi per specializzarlo. Di solito è l'ultima risorsa — prima prova [prompting e RAG](/docs/foundations).

### Grounding
Istruire il modello a rispondere **solo a partire dal contesto che fornisci** — e a dire "Non lo so" quando la risposta non c'è. La principale difesa, a livello di prompt, contro l'allucinazione. Vedi [la Pattern Library](/docs/prompting/pattern-library).

### Guardrails
Regole e limiti che mantengono il comportamento di un'AI sicuro e in linea con l'obiettivo — es. regole di permesso, "esegui i test prima di concludere", o approvazione umana per le azioni rischiose. Vedi [Mettere in sicurezza gli agent](/docs/security/securing-agents).

### Hallucination
Quando un modello afferma qualcosa di **falso ma con sicurezza**. L'abilità fondamentale è la verifica. Vedi [Allucinazioni](/docs/foundations).

### Hook
In Claude Code, un comando che si esegue **automaticamente** a un evento del ciclo di vita (es. dopo ogni modifica di un file) per imporre formattazione, controlli o sicurezza.

### Inference
L'atto di eseguire un modello per ottenere un output (a differenza del suo addestramento).

### Knowledge cutoff
La data oltre la quale un modello **non ha dati di addestramento**: davvero non sa cosa è accaduto dopo, a meno che tu non gli fornisca i fatti nel prompt. Il cutoff di Claude è pubblicato nelle release notes di ciascun modello. È per questo che chiedere di eventi molto recenti senza contesto può produrre risposte obsolete o inventate; il rimedio è incollare i fatti rilevanti oppure usare un tool che recupera informazioni aggiornate.

### Latency
Quanto tempo aspetti per una risposta. I modelli più grandi sono di solito più lenti; lo [streaming](/docs/api/streaming) migliora la latenza *percepita* mostrando l'output man mano che viene generato.

### LLM (Large Language Model)
Il tipo di AI dietro Claude: addestrata a **predire il prossimo blocco di testo**, cosa che si rivela sufficiente per scrivere, programmare, riassumere e ragionare. Vedi [Cos'è un LLM?](/docs/foundations).

### MCP (Model Context Protocol)
Uno **standard aperto** per collegare l'AI a tool e dati esterni (database, GitHub, browser). Un "server MCP" espone un tool; Claude può chiamarlo. Vedi [MCP](/docs/claude-code).

### Multimodal
Un modello che gestisce **più del solo testo** — ad esempio immagini e PDF come input.

### Output style
In Claude Code, un preset che cambia **il modo in cui Claude comunica** (es. conciso, esplicativo, didattico) senza cambiare ciò che può fare. Vedi [Output Style](/docs/claude-code/output-styles).

### Permission mode
In Claude Code, quanto può fare **senza chiedere** — dal chiedere conferma a ogni azione fino all'accettare automaticamente le modifiche. La principale manopola velocità-vs-sicurezza. Vedi [Permessi](/docs/claude-code/permissions).

### Plan mode
Una modalità di Claude Code in sola lettura che indaga e propone un piano **prima** di toccare qualsiasi file — tu approvi prima che agisca. Vedi [Plan Mode](/docs/claude-code/plan-mode).

### Prompt
Ciò che invii al modello: le tue istruzioni, la domanda e qualsiasi contesto.

### Prompt caching
Riutilizzare la parte iniziale invariata di un prompt tra una chiamata e l'altra per ridurre costo e latenza. Vedi [Prompt Caching](/docs/api).

### Prompt injection
Un attacco in cui **istruzioni malevole nascoste nel contenuto** che l'AI legge (una pagina web, un documento) cercano di dirottarla. Vedi [Prompt Injection](/docs/security).

### RAG (Retrieval-Augmented Generation)
Recuperare frammenti rilevanti dai *tuoi* dati e aggiungerli al prompt, così il modello risponde basandosi su di essi. Vedi [RAG](/docs/foundations).

### Reasoning / extended thinking
Una modalità in cui il modello dedica risorse di calcolo extra a "pensare" prima di rispondere, per i task più difficili. Sui modelli più recenti la regoli con l'[effort](/docs/api/thinking-and-effort).

### Skill
Una capacità impacchettata (istruzioni + script opzionali) che Claude carica **su richiesta** quando è rilevante. Vedi [Skill](/docs/claude-code).

### Slash command
Una scorciatoia con prefisso `/` in Claude Code — integrata (come `/clear`) o un tuo prompt riutilizzabile — che innesca un'azione definita. Vedi [Slash Command](/docs/claude-code/slash-commands).

### Streaming
Inviare l'output del modello **token per token** mentre viene generato, invece di attendere l'intera risposta. Per l'utente sembra che il modello stia scrivendo in tempo reale; per chi sviluppa significa elaborare uno stream di chunk anziché un singolo oggetto risposta. Migliora drasticamente la latenza *percepita* sugli output lunghi e ti permette di iniziare il rendering prima che il modello finisca. Vedi [Streaming](/docs/api/streaming).

### Structured output
Ottenere risultati in una forma rigida e leggibile dalle macchine (es. JSON conforme a uno schema) anziché testo libero — così altri software possono farci affidamento. Vedi [Output strutturato](/docs/api/structured-output).

### Subagent
Un'istanza separata di Claude con il proprio contesto e i propri tool, usata per **delegare** parte di un task (es. la ricerca) così che la sessione principale resti concentrata.

### System prompt
Le istruzioni di alto livello che definiscono il ruolo e le regole del modello per un'intera conversazione — la tua leva di orientamento più potente.

### Temperature
Un'impostazione (su alcuni modelli) che controlla la casualità: bassa = focalizzata e ripetibile, alta = varia e creativa.

### Token
L'unità che i modelli leggono e contano — circa ¾ di una parola in inglese. Prezzi e limiti di contesto sono misurati in token. Vedi [Token e contesto](/docs/foundations).

### Tool use / function calling
Permettere al modello di chiamare funzioni che definisci tu (ricerca, calcolatrice, la tua API) e di usarne i risultati. Vedi [Tool Use](/docs/api).

### Zero-shot
Chiedere al modello di svolgere un task **senza esempi** — solo istruzioni. La maggior parte dei prompt di ogni giorno è zero-shot. In contrasto con il [few-shot](#few-shot), in cui includi esempi svolti per guidare formato o stile. Lo zero-shot va benissimo per i task lineari; aggiungi esempi quando il modello continua a sbagliare la forma dell'output che vuoi.
