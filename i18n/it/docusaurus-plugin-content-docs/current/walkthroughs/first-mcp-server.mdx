Esponiamo uno strumento personalizzato a Claude costruendo un piccolissimo server [MCP](/docs/claude-code/mcp) e collegandolo. Lo teniamo minimo perché il *collegamento* sia chiaro — poi inserisci la tua logica reale.

## Cosa stiamo costruendo

Un server stdio con uno strumento, `word_count`, che Claude può chiamare. Lo stesso schema vale per "interroga il mio DB", "apri un ticket" e così via.

```mermaid
flowchart LR
  CC[Claude Code] -- call word_count --> S[Your MCP server]
  S -- result --> CC
```

## Passo 1 — Il server

`server.py` (Python; una versione TypeScript è negli [scaffold MCP](/docs/templates/mcp-config)):

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("text-tools")

@mcp.tool()
def word_count(text: str) -> int:
    """Count the words in a piece of text."""
    return len(text.split())

if __name__ == "__main__":
    mcp.run()  # stdio transport
```

La docstring non è decorazione — è la descrizione dello strumento che il modello legge per decidere se chiamarlo. Docstring vaga, strumento inutilizzato.

## Passo 2 — Dichiaralo

Aggiungi a `.mcp.json` nella radice del repository:

```json
{ "mcpServers": {
  "text-tools": { "command": "python", "args": ["server.py"] }
} }
```

## Passo 4 — Rendilo reale

Sostituisci `word_count` con la tua capacità effettiva — una query a un DB, una chiamata a un'API interna, un'operazione su file. Aggiungi la validazione degli input e restituisci gli errori come risultati.

Restituire gli errori *come risultati* invece di sollevarli è ciò che permette al modello di riprendersi: un messaggio come `"no such project: foo"` porta a un nuovo tentativo con un argomento corretto, mentre un server andato in crash semplicemente sparisce dalla sessione.

## Lista di controllo per la sicurezza

:::warning[Un server è codice + accesso]
- **Privilegio minimo** — solo i dati e le azioni che gli servono ([Proteggere gli agenti](/docs/security/securing-agents)).
- **Valida gli input** che invia il modello.
- I dati non affidabili che restituisce possono veicolare [prompt injection](/docs/security/prompt-injection).
- **Esamina** qualsiasi server di terze parti prima di collegarlo.
:::
