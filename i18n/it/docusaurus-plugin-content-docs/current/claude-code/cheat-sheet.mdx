## La scheda in forma di testo

### Avviare e riprendere le sessioni

| Comando o flag | Cosa fa |
| --- | --- |
| `claude` | Avvia una sessione interattiva |
| `claude "query"` | Avvia con un prompt iniziale |
| `claude -c` | Continua la conversazione più recente in questa cartella |
| `claude -r "<session>"` | Riprende per ID o nome, oppure ne fa scegliere una |
| `claude -n "<name>"` | Dà un nome alla sessione per riprenderla in seguito |
| `--fork-session` | Con `-c` o `-r`: nuovo ID di sessione |
| `claude -w <name>` | Lavora in un git worktree isolato |
| `--model <alias\|name>` | Imposta il modello, per esempio `sonnet` |
| `--permission-mode <mode>` | Parte in una determinata modalità di permesso |
| `claude --bg "<task>"` | Avvia una sessione in background; monitorala con `claude agents` |

Per approfondire: [La CLI claude: i flag che cambiano i risultati](/docs/claude-code/cli-flags) e [Git worktree e flussi di lavoro paralleli](/docs/claude-code/worktrees).

### Headless e scripting

| Comando o flag | Cosa fa |
| --- | --- |
| `claude -p "query"` | Esegue una volta, stampa la risposta, termina |
| `cat file \| claude -p "…"` | Passa il contenuto da stdin (limite 10MB) |
| `--output-format <format>` | `text` (predefinito), `json`, `stream-json` |
| `--json-schema '<schema>'` | JSON validato rispetto al tuo schema |
| `--allowedTools "<rule>" …` | Strumenti che girano senza richiesta, per esempio `"Bash(git diff *)"` |
| `--max-turns <n>` | Limita il numero di turni agentici |
| `--max-budget-usd <n>` | Si ferma a una spesa stimata |
| `--bare` | Salta hook, skill, plugin, server MCP, auto memory e CLAUDE.md |
| `claude -c -p "query"` | Continua l'ultima conversazione |

L'output JSON contiene `result`, `session_id` e `total_cost_usd`. Il codice di uscita 0 indica successo.

Per approfondire: [Modalità headless e Agent SDK](/docs/claude-code/headless-and-agent-sdk).

### File di impostazioni

Elencati dalla precedenza più alta: quando due di essi impostano la stessa chiave, vince quello più in alto nella tabella.

| File o flag | Ambito |
| --- | --- |
| `managed-settings.json` | Gestito: impostato dalla tua organizzazione |
| `--settings <file-or-json>` | Riga di comando: solo questa sessione |
| `.claude/settings.local.json` | Locale al progetto: solo tu, fuori da git |
| `.claude/settings.json` | Progetto condiviso: committalo per il team |
| `~/.claude/settings.json` | Utente: tu, in ogni progetto |

Le chiavi di tipo elenco come `permissions.allow` vengono unite tra i file. `/status` mostra quali file sono stati caricati; `claude doctor` segnala le voci non valide.

| File | Cosa contiene |
| --- | --- |
| `.mcp.json` | Server MCP a livello di progetto; gestiscili con `/mcp` |

Per approfondire: [settings.json: il sistema di configurazione](/docs/claude-code/settings) e [Server MCP in Claude Code](/docs/claude-code/mcp).

### Comandi in sessione

| Comando | Cosa fa |
| --- | --- |
| `/init` | Genera un CLAUDE.md di partenza |
| `/clear` | Nuova conversazione con contesto vuoto |
| `/compact` | Riassume la conversazione per liberare contesto |
| `/context` | Visualizza l'uso attuale del contesto |
| `/resume` | Riprende una conversazione o apre il selettore |
| `/branch` | Crea una ramificazione della conversazione da questo punto |
| `/rewind` | Riporta indietro codice, conversazione o entrambi |
| `/model` | Cambia modello; viene salvato come predefinito |
| `/plan` | Entra in plan mode dal prompt |
| `/permissions` | Gestisce le regole allow, ask e deny |
| `/memory` | Modifica i file CLAUDE.md, attiva/disattiva l'auto memory |
| `/config` | Apre le impostazioni, o imposta direttamente `key=value` |
| `/usage` | Costo della sessione e limiti d'uso del piano |
| `/diff` | Rivede le modifiche nella tua working tree |
| `/btw` | Domanda a margine che resta fuori dalla cronologia |
| `/code-review` | Rivede il diff corrente alla ricerca di bug |

Per approfondire: [Gestione del contesto](/docs/claude-code/context-management).

### Tastiera e input

| Tasto | Cosa fa |
| --- | --- |
| `Esc` | Interrompe Claude; il lavoro fatto finora viene conservato |
| `Esc Esc` | Apre il menu di rewind (su un prompt vuoto) |
| `Shift+Tab` | Passa ciclicamente tra le modalità di permesso |
| `Ctrl+C` | Interrompe, oppure svuota l'input quando è inattivo |
| `Ctrl+O` | Attiva/disattiva il visualizzatore della trascrizione |
| `Ctrl+R` | Ricerca inversa nella cronologia dei comandi |
| `Ctrl+B` | Manda in background il comando in esecuzione |
| `Ctrl+G` | Modifica il prompt nel tuo editor di testo |
| `Ctrl+V` | Incolla un'immagine dagli appunti |
| `Ctrl+J` | A capo, in qualsiasi terminale |
| `!` | Modalità shell: esegue direttamente un comando |
| `@` | Menziona il percorso di un file, con completamento automatico |

### Checkpoint e rewind

| Aspetto | Dettaglio |
| --- | --- |
| Creazione | A ogni prompt che avvia un turno; vengono conservati i 100 più recenti |
| Ripristino | Codice e conversazione, oppure uno solo dei due |
| Riassunto | Da qui o fino a qui; i file non vengono toccati |
| Non tracciato | Modifiche ai file via Bash, la maggior parte delle modifiche dei subagent, modifiche fatte fuori dalla sessione |

Per approfondire: [Checkpoint e Rewind](/docs/claude-code/checkpoints-and-rewind).

### Modalità di permesso

| Modalità | Cosa gira senza chiedere |
| --- | --- |
| `default` | Solo letture. Mostrata come Manual |
| `acceptEdits` | Letture, modifiche ai file, comuni comandi sul filesystem |
| `plan` | Letture, più i comandi approvati dal classificatore |
| `auto` | Tutto, con controlli di sicurezza in background |
| `dontAsk` | Letture e strumenti pre-approvati; il resto è negato |
| `bypassPermissions` | Tutto. Solo container e VM isolati |

`Shift+Tab` scorre `default`, `acceptEdits` e `plan`, poi `bypassPermissions` e `auto` quando sono abilitate. Le regole deny bloccano in ogni modalità. Dalla v2.1.283 la modalità iniziale integrata per le sessioni interattive da terminale è `auto`; imposta `permissions.defaultMode` per cambiarla.

Per approfondire: [Permessi e modalità di permesso](/docs/claude-code/permissions).

### Plan mode

| Aspetto | Dettaglio |
| --- | --- |
| Consente | Letture, comandi di shell per esplorare, un piano scritto |
| Blocca | Modifiche al tuo sorgente finché non approvi il piano |
| Comandi | Valutati dal classificatore, o richiesti all'utente se fuori dall'insieme di sola lettura |
| Non applicato | In una sessione interattiva da terminale con i permessi bypass disponibili |

Per approfondire: [Plan Mode](/docs/claude-code/plan-mode).

### Hook

| Evento o aspetto | Dettaglio |
| --- | --- |
| Si configurano in | `hooks` in un file di impostazioni; `/hooks` li elenca |
| `SessionStart` | Una sessione inizia o riprende |
| `UserPromptSubmit` | Viene inviato un prompt, prima dell'elaborazione |
| `PreToolUse` | Prima dell'esecuzione di una chiamata a uno strumento; può bloccarla |
| `PostToolUse` | Dopo che una chiamata a uno strumento riesce |
| `Stop` | Claude finisce di rispondere |
| Input | Dati dell'evento come JSON su stdin |
| Codici di uscita | 0: nessuna obiezione. 2: blocca l'azione dove l'evento lo consente; stderr è il motivo |

Per approfondire: [Hook: automazione deterministica](/docs/claude-code/hooks).

### Memoria e CLAUDE.md

| File o sintassi | Cosa fa |
| --- | --- |
| `./CLAUDE.md` | Istruzioni di progetto, condivise tramite git |
| `./CLAUDE.local.md` | Note personali di progetto; aggiungilo a `.gitignore` |
| `~/.claude/CLAUDE.md` | Le tue preferenze, in ogni progetto |
| `.claude/rules/*.md` | Regole per argomento, opzionalmente limitate da `paths:` |
| `@path/to/file` | Importa in CLAUDE.md, fino a quattro livelli di profondità |
| `MEMORY.md` | Indice dell'auto memory scritto da Claude; si caricano le prime 200 righe o 25KB |

Per approfondire: [CLAUDE.md e file di memoria](/docs/claude-code/claude-md).
