Ein **Project** ist ein dedizierter Arbeitsbereich in Claude.ai, der **seine eigenen Dateien, sein eigenes Wissen und seine eigenen Anweisungen** bündelt. Statt in jedem Chat dieselben Dokumente erneut hochzuladen und den Kontext erneut zu erklären, richtest du es einmal ein — und jede Konversation im Project startet bereits informiert.

## Warum ein Project nutzen

- **Fundierte Antworten.** Füge deine Dokumente hinzu (ein Handbuch, Spezifikationen, Notizen), und Claude antwortet *aus ihnen* — eine eingebaute, codefreie Variante von [RAG](/docs/foundations/rag).
- **Dauerhafter Kontext.** Project-Anweisungen wirken wie ein bereichsbezogener [System-Prompt](/docs/foundations/roles) für alles darin.
- **Organisiert.** Alle Chats zu einem Thema, einem Kunden oder einem Vorhaben liegen zusammen.

## Großartige Anwendungsfälle

- Ein Arbeitsbereich für **Kunde/Account** (deren Dokumente + deine Notizen).
- Eine Wissensdatenbank für eine **Codebasis oder ein Produkt** für Q&A.
- Ein **Schreibprojekt** mit deinem Styleguide und früheren Texten (damit Entwürfe deiner Stimme entsprechen).
- **Lernen** für einen Kurs, mit geladenem Lehrplan und Materialien.

## Tipps

- **Kuratiere das Wissen** — relevante, aktuelle Dateien schlagen das Abladen von allem (Rauschen schadet dem Retrieval).
- **Halte die Anweisungen knapp und wahr** (dieselbe Regel wie bei [Custom Instructions](/docs/claude-app/custom-instructions)).
- **Räume auf, wenn sich Dinge ändern.** Eine überholte Spezifikation, die in der Wissensdatenbank liegen bleibt, ist schlimmer als keine Spezifikation, denn Claude hat keine Möglichkeit zu wissen, dass sie gegen die neue verloren hat.
- **Füge keine sensiblen Daten hinzu**, deren Speicherung dir unangenehm ist — siehe [Datenschutz](/docs/foundations/privacy).

## Zwei Dinge, die "Projects" heißen

Sie sind wirklich verschiedene Produkte, und die Namen überlappen sich während des Rollouts:

| | Dieses Project (Claude.ai) | [Claude Code Projects](/docs/claude-code/projects-coordinator-threads) |
|---|---|---|
| Was es ist | Ein Arbeitsbereich mit Wissen + Anweisungen | Ein Koordinator, der an parallele Threads delegiert |
| Was es tut | Fundiert *deine* Chats in *deinen* Dateien | Umreißt, zerlegt und erledigt Arbeit für dich |
| Führt Code aus? | Nein | Ja — jeder Thread ist eine Cloud-Session auf einem eigenen Branch |
| Wer hat es | Breit verfügbar | Beta, zum Start ausgewählte Pro-/Max-Nutzer von Claude Code |

Wenn du über Koordinatoren, Threads und Pull Requests liest, ist das das Claude-Code-Produkt.
