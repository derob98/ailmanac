[MCP](/docs/claude-code/mcp) подключает Claude к внешним инструментам и данным. Выберите нужные серверы и скопируйте (или скачайте) стартовый `.mcp.json`. Замените заполнители `${...}` переменными окружения — никогда не прописывайте секреты прямо в файле.

<McpConfigBuilder />

:::warning[В двух строках имя пакета нужно указать самостоятельно]
Для PostgreSQL и Slack намеренно выводится заполнитель `REPLACE-WITH-A-MAINTAINED-…` вместо пакета. Пакеты `@modelcontextprotocol/server-*`, которыми все пользовались для этих двух сервисов, [заархивированы и не поддерживаются](/docs/templates/mcp-config), гарантий безопасности у них нет, а официальной замены ни для одного из них не существует — поэтому выберите поддерживаемый серверный пакет от сообщества, изучите его и вставьте его имя. Все остальные строки — это либо поддерживаемые эталонные серверы, либо собственная конечная точка вендора.
:::

:::warning[Доверяй, но проверяй]
MCP-сервер выполняет код и может получать доступ к данным. Подключайте только те серверы, которым доверяете, выдавайте им минимально необходимые права и проверяйте каждый пакет на [modelcontextprotocol.io](https://modelcontextprotocol.io). См. [Проверка стороннего кода](/docs/security/reviewing-third-party-code).
:::
