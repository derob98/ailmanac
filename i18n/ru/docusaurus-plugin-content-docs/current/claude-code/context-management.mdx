Названия команд, окно авто-уплотнения и таблица того, что переживает уплотнение, меняются от релиза к релизу — сверяйтесь с официальной документацией.

## Главная идея

У каждой сессии конечное [окно контекста](/docs/foundations/tokens-and-context). По мере заполнения старое содержимое сжимается, и Claude может начать «дрейфовать». Осознанное управление контекстом сохраняет точность длинных сессий.

## Две основные команды

Две команды покрывают почти любую ситуацию. Секрет в том, чтобы подбирать команду под свою цель.

<Flashcards cards={[{front: "/clear", back: "Стирает беседу и начинает с чистого листа. Используйте при переходе к НЕСВЯЗАННОЙ задаче. Самый дешёвый способ вернуть чистый, сфокусированный контекст. Псевдонимы: /reset и /new."}, {front: "/compact", back: "Сжимает беседу до этого момента в компактную форму — сохраняет суть и освобождает место. Используйте, когда хотите ПРОДОЛЖИТЬ ту же задачу, но окно заполняется. Принимает необязательные инструкции по фокусу."}]} />

Решайте одним вопросом: это новая задача или та же?

```mermaid
flowchart TD
  A{New task or same task?} -->|New / unrelated| B[/clear]
  A -->|Same task, context full| C[/compact]
```

Две детали, которые легко упустить:

- **`/compact` принимает инструкции.** `/compact focus on the auth bug fix` сохраняет то, что выбрали *вы*, а не то, что автоматический проход счёл важным. Запускайте его осознанно перед началом длинной новой задачи, а не ждите, пока окно вынудит это сделать.
- **`/clear` — не точка невозврата.** Передайте имя (`/clear auth refactor`), чтобы подписать уходящую беседу в списке `/resume`; а в рамках того же процесса Claude Code меню отката по-прежнему предлагает пункт `/resume <session-id> (previous session)` — см. [Чекпойнты и откат](/docs/claude-code/checkpoints-and-rewind).

## Авто-уплотнение — и как сдвинуть порог

Когда контекст приближается к пределу, Claude Code **уплотняет автоматически**, чтобы работа продолжалась без резкой остановки. На моделях с окном контекста 1M это происходит по умолчанию примерно на 967K токенов; более ранние модели уплотняют у границы своего окна контекста. Claude Code может также уплотнить беседу, которую вы оставили без активности.

Порог можно сдвигать. `/autocompact 500k` уплотняет раньше — полезно, когда вы предпочитаете подвести итог на своих условиях, а не при заполнении на 96 %, — а `/autocompact auto` возвращает окно, подобранное для вашей модели.

<PromptCard title="Уплотнять раньше, чем по умолчанию">{`/autocompact 500k`}</PromptCard>

Запустите /autocompact без аргумента, чтобы увидеть текущее окно."}, {title: "Где это можно задать", body: "Команда /autocompact сохраняет значение в пользовательских настройках для текущей модели в modelSettings. ## Что переживает уплотнение

Уплотнение сворачивает *беседу*. Всё, что ваша конфигурация загружает с диска, обрабатывается отдельно — поэтому уплотнённая сессия по-прежнему знает соглашения вашего проекта.

Описания скиллов пересобираются из ваших текущих скиллов (Claude Code v2.1.304 или новее). Если сессия началась со снимка git status, Claude Code читает свежий."}, {title: "Подгружается по требованию", body: "Правила с frontmatter paths: и вложенные файлы CLAUDE.md в подкаталогах сворачиваются и теряются, а перезагружаются только когда Claude в следующий раз обращается к подходящему файлу. Если правило должно сохраняться при уплотнении, уберите frontmatter paths: или перенесите его в CLAUDE.md в корне проекта."}, {title: "Восстанавливается частично", body: "Claude Code перечитывает до пяти файлов, которые Claude читал или правил, начиная с последних изменённых, — но файл больше 5 000 токенов возвращается как ссылка на путь ('Referenced file') без содержимого. Тела вызванных скиллов подставляются заново с лимитом 5 000 токенов на скилл и 25 000 всего, старейшие отбрасываются первыми, а начало файла сохраняется: самое важное размещайте в начале SKILL.md."}, {title: "Сворачивается и теряется", body: "Сама беседа, включая контекст, который ранее добавили хуки. Хуки SessionStart, подходящие к источнику 'compact', запускаются снова, и их вывод попадает в уплотнённый контекст — это хук для всего, что должно вернуться."}, {title: "Не затрагивается", body: "Фоновые команды и фоновые субагенты продолжают работать, а Claude Code напоминает Claude, какие из них ещё активны, чтобы он не запускал дубликат."}]} />

## Приёмы для сохранения эффективности

Помимо двух команд, четыре привычки держат контекст лёгким с самого начала.

Передайте 'all', чтобы развернуть список по элементам в полноэкранном режиме. Строка статуса с показом использования контекста даёт тот же сигнал пассивно. См. /docs/claude-code/statusline."}]} />

<PromptCard title="Посмотреть, куда на самом деле ушёл контекст">{`/context`}</PromptCard>

Они ведут на актуальную документацию: [субагенты](/docs/claude-code/subagents), [CLAUDE.md](/docs/claude-code/claude-md) и [строка статуса](/docs/claude-code/statusline).

:::tip[Симптом → решение]
Если Claude начинает забывать прежнюю инструкцию или повторяться, окно, вероятно, заполнено. `/compact` (та же задача) или `/clear` (новая задача) обычно решает это мгновенно. Запустите `/context`, чтобы убедиться, — когда беседа действительно вышла за пределы окна, в выводе указано, насколько вы превысили его и какая команда освободит место. Подробнее — в разделе [Почему Claude так поступил?](/docs/contribute/troubleshooting).

Если же вы видите `Autocompact is thrashing`, уплотнение работает, но что-то слишком объёмное снова и снова заполняет окно — см. [Устранение неполадок Claude Code](/docs/claude-code/troubleshooting).
:::
