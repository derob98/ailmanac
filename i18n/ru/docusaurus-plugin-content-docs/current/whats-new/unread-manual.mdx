<VerifyNote lastVerified="2026-10-15" source="https://platform.claude.com/docs/en/about-claude/models/overview">
Даты отсечения обучения взяты со страницы каждой модели в документации Claude Platform. История документации Claude Code взята из зеркала сообщества, которое копирует официальные страницы несколько раз в день. Цифры — снимок на 15 октября 2026 года; скрипт, который их выдаёт, приведён по ссылке ниже, так что любой может запустить его заново.
</VerifyNote>

Каждая модель Claude училась Claude Code по документации в том виде, какой она была на дату отсечения обучения. Потом документация продолжала меняться. Мы воспроизвели её историю неделя за неделей, чтобы измерить, насколько они разошлись.

<UnreadHeadline />

У новейших моделей — Fable 5.1, Opus 5.5, Sonnet 5.5 и Haiku 5.5 — надёжная дата отсечения знаний приходится на июнь 2026 года. С конца июня по 15 октября документация выросла со 107 до 164 страниц, и большая часть того, что в ней сказано сегодня, написана за эти три с половиной месяца. Если считать строже — по точной формулировке, а не по фактам, — доля поднимается до 72 %. Без примеров кода она составляет 70 %. Как ни считай, Claude никогда не видел большей части собственного руководства.

## Что не видела каждая модель

Чем старше дата отсечения, тем меньше сегодняшней документации модель могла прочитать. Все эти модели по-прежнему доступны через Claude API.

<ModelBars />

Claude Haiku 4.5 с датой отсечения в феврале 2025 года предшествует почти всему: Claude Code вышел как research preview именно в том месяце, а почти вся сегодняшняя документация появилась позже.

## Выберите неделю, когда вы выучили Claude Code

Та же арифметика работает и для людей. Передвиньте ползунок на неделю, когда вы читали документацию, или на дату туториала, по которому вы работаете.

<LearnedSlider />

## Документацию не только дополняют, но и переписывают

Рост объясняет большую часть разрыва, но не весь. Страницы ещё и переписываются. Каждая полоса ниже — текст, написанный за один квартал; полоса истончается по мере того, как её предложения удаляют или меняют.

<CohortChart />

В июле 2025 года в документации было 29 страниц. Сегодня их 164, а предложений и строк кода — в 21 раз больше. От документации июля 2025 года до сих пор держится 30,5 %; остальное удалено или переписано с другим числом, флагом или названием. Даже документация июня 2026 года, которую видели новейшие модели, потеряла 26,9 % своих фактов меньше чем за четыре месяца.

## Сколько живёт предложение

Если проследить каждое предложение от недели появления до недели исчезновения, половина пропадает или переформулируется в течение 196 дней. Если считать переформулировку только тогда, когда она меняет число, флаг, путь или имя, половина фактов исчезает за 266 дней — примерно девять месяцев.

## О чём ваша модель никогда не слышала

Это идентификаторы из сегодняшних справочных таблиц, которых не было на дату отсечения модели: флаги CLI, слэш-команды, события hook и переменные окружения. Спросите Claude о любом из них — он сможет только гадать.

<NewIdentifiers />

«Задокументировано с» — не то же самое, что «выпущено с»: часть этого существовала раньше и попала в документацию лишь позже. Так или иначе, у модели не было страницы, по которой это можно было выучить.

## Дайте Claude список

[Плагин since-cutoff](https://github.com/derob98/ailmanac/tree/main/plugins/since-cutoff) кладёт эти списки перед Claude. При запуске сессии hook определяет, какая модель работает, и добавляет в её контекст короткую заметку: флаги, команды и события hook, задокументированные после даты отсечения этой модели, и указание проверять документацию, прежде чем полагаться на память или говорить, что функции не существует.

```bash
claude plugin marketplace add derob98/ailmanac --sparse .claude-plugin plugins
claude plugin install since-cutoff@ailmanac
```

Hook — это несколько строк POSIX-шелла: без Node, без сети, около 400–750 токенов на сессию. Когда Claude Code не передаёт hook модель, как в нашем headless-тесте с `-p`, заметка перечисляет то, что изменилось с июня 2026 года, а это верно для любой модели Claude. В том тесте сессия получила заметку, и Claude процитировал её слово в слово.

## Что с этим делать

- **Не доверяйте памяти Claude о Claude Code.** Для флагов, настроек, hook и команд пусть он читает страницу. В Claude Code есть агент-гид для вопросов о нём самом, а документация публикует индекс по адресу [code.claude.com/docs/llms.txt](https://code.claude.com/docs/llms.txt).
- **Датируйте свои туториалы.** Руководство полугодовой давности потеряло больше трети фактов. Всё, что старше, сверяйте с документацией, прежде чем копировать оттуда команды.
- **Предпочитайте страницы, где указано, когда их проверяли.** На каждой странице этого сайта есть дата последней проверки; [панель актуальности](/docs/whats-new/freshness) перечисляет их все, а [Deprecation & Migration Watch](/docs/whats-new/deprecations) отслеживает то, что было удалено.

## Как мы это измеряли

- **История.** [web3dev1337/claude-code-docs](https://github.com/web3dev1337/claude-code-docs) — форк известного зеркала документации, сохранивший полную историю синхронизаций: 3 604 синхронизации с июля 2025 по октябрь 2026 года. Мы брали последнюю синхронизацию каждой недели — всего 67 снимков.
- **Охват.** Все страницы Claude Code, кроме журнала изменений и еженедельных дайджестов, которые по замыслу фиксируют историю, и страниц Agent SDK, которые в 2026 году переехали с другого сайта документации и иначе считались бы новыми.
- **Единицы.** Каждая страница делится на предложения, строки таблиц и строки кода, без ссылок и разметки. Строка, которая встречается сразу на пяти и более страницах, например баннер или типовая строка кода, отбрасывается. В итоге осталось 90 674 различных единицы для отслеживания.
- **Исчезновения.** Единица считается исчезнувшей, когда её нет в двух недельных снимках подряд или в последнем, так что страница, не прошедшая одну синхронизацию, не учитывается.
- **Факты.** Новое предложение, заменяющее удалённое на той же неделе, считается тем же фактом, если совпадает не менее 60 % слов и каждое число, флаг, путь и идентификатор идентичны. Так связано 7 965 переформулировок.
- **Даты отсечения.** Каждая модель сравнивается с последним недельным снимком на последний день месяца её отсечения или раньше — это самое щедрое прочтение. Для дат отсечения до июля 2025 года берётся первый снимок, который уже содержит больше, чем эти модели могли видеть, поэтому их доли — нижние оценки.
- **Выживаемость.** Оценки Каплана — Мейера по всем единицам, появившимся после первого снимка; единицы, существующие сегодня, считаются цензурированными.

Зеркало неофициальное: если оно пропустило или исказило страницу, цифры наследуют ошибку. Мы проверили недели отсечения на предмет страниц, пропавших на одну синхронизацию, и не нашли таких. Анализ сравнивает текст, а не поведение продукта.

## Воспроизведите

Скрипт и его вывод лежат в репозитории этого сайта: [scripts/research/docs-decay.mjs](https://github.com/derob98/ailmanac/blob/main/scripts/research/docs-decay.mjs) и [data/research/claude-code-docs-decay.json](https://github.com/derob98/ailmanac/blob/main/data/research/claude-code-docs-decay.json). Нужны Node и git, выполняется примерно за 15 секунд:

```bash
git clone https://github.com/web3dev1337/claude-code-docs
git clone https://github.com/derob98/ailmanac
node ailmanac/scripts/research/docs-decay.mjs claude-code-docs
```
