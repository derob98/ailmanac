Пользовательская слэш-команда упаковывает промпт, который вы постоянно вводите заново, в одно `/слово`. Определите её один раз — и пользуйтесь постоянно (а также делитесь ею с командой).

## Как они работают

Команда — это просто Markdown-файл. Положите его в каталог команд, и имя файла станет командой. Тело файла — это промпт, который Claude выполняет при вызове.

*Расположение* файла определяет область действия:

## Минимальный пример

Вот полный файл команды. Во frontmatter лежит `description`; всё, что ниже, — это промпт.

<PromptCard title="commit.md — составить Conventional Commit">{`---
description: Draft a Conventional Commit message from the staged diff
---

Look at the staged changes with \`git diff --cached\` and write a single
Conventional Commit message (feat/fix/docs/refactor/chore). Output only the
message, no preamble.`}</PromptCard>

Сохраните это как `commit.md`, и `/commit` будет делать это каждый раз. (Имя определяется именем файла — то же тело, сохранённое как `changelog.md`, станет `/changelog`.)

## Полезные строительные блоки

Четыре ингредиента превращают статичный промпт в гибкую команду:

| Строительный блок | Что он делает |
| --- | --- |
| **`$ARGUMENTS`** | Подставляет всё, что пользователь ввёл после команды. `/review src/auth.ts` → путь попадает в ваш промпт. |
| **`$ARGUMENTS[N]` / `$N`** | Один аргумент по индексу, **начинающемуся с 0**. `$ARGUMENTS[0]`, сокращённо `$0`, — это *первый* аргумент, поэтому `$1` — это **второй**, а не первый, как в shell-скрипте. |
| **Запуск bash и вставка вывода** | Команды могут включать вывод оболочки (например, текущий diff), чтобы Claude действовал по актуальному состоянию. |
| **Ссылки на файлы** | Укажите файлы, чтобы включить их содержимое. |
| **Frontmatter** | `description` (показывается в меню), `argument-hint`, `allowed-tools`, `disallowed-tools`, `disable-model-invocation`. |

Точный синтаксис аргументов, bash и ссылок на файлы смотрите в [официальной документации](https://code.claude.com/docs/en/skills).

## Команда против навыка против субагента

Три способа упаковать работу — разница в том, *кто запускает* и *насколько изолированно она выполняется*:

- **Слэш-команда** — *вы* запускаете известный рабочий процесс по требованию.
- **[Навык](/docs/claude-code/skills)** — Claude загружает экспертизу *автоматически*, когда она уместна.
- **[Субагент](/docs/claude-code/subagents)** — передайте часть работы изолированному агенту.
