## ये कैसे काम करते हैं

कमांड बस एक Markdown फ़ाइल है। इसे अपनी commands डायरेक्टरी में रखें और फ़ाइल का नाम ही कमांड बन जाता है। फ़ाइल की बॉडी वह प्रॉम्प्ट है जिसे आप इनवोक करते समय Claude चलाता है।

फ़ाइल की *जगह* उसका दायरा तय करती है:

## एक न्यूनतम उदाहरण

यह एक पूरी कमांड फ़ाइल है। frontmatter में `description` रहता है; उसके नीचे का सब कुछ प्रॉम्प्ट है।

<PromptCard title="commit.md — Conventional Commit का ड्राफ़्ट बनाएँ">{`---
description: Draft a Conventional Commit message from the staged diff
---

Look at the staged changes with \`git diff --cached\` and write a single
Conventional Commit message (feat/fix/docs/refactor/chore). Output only the
message, no preamble.`}</PromptCard>

इसे `commit.md` के रूप में सेव करें और `/commit` हर बार यही करेगा। (नाम वही है जो फ़ाइल का नाम है — यही बॉडी `changelog.md` के रूप में सेव हो तो `/changelog` बन जाएगी।)

## उपयोगी बिल्डिंग ब्लॉक्स

चार चीज़ें एक स्थिर प्रॉम्प्ट को लचीले कमांड में बदल देती हैं:

| बिल्डिंग ब्लॉक | यह क्या करता है |
| --- | --- |
| **`$ARGUMENTS`** | कमांड के बाद यूज़र ने जो कुछ भी टाइप किया, वह सब डालता है। `/review src/auth.ts` → पाथ आपके प्रॉम्प्ट में आ जाता है। |
| **`$ARGUMENTS[N]` / `$N`** | **0 से शुरू होने वाले** इंडेक्स से एक आर्ग्युमेंट। `$ARGUMENTS[0]`, संक्षेप में `$0`, *पहला* आर्ग्युमेंट है — इसलिए `$1` **दूसरा** है, शेल स्क्रिप्ट की तरह पहला नहीं। |
| **bash चलाएँ और आउटपुट एम्बेड करें** | कमांड में शेल आउटपुट (जैसे मौजूदा diff) शामिल हो सकता है ताकि Claude लाइव स्थिति पर काम करे। |
| **फ़ाइलें रेफ़र करें** | फ़ाइलों की ओर इशारा करें ताकि उनकी सामग्री शामिल हो जाए। |
| **Frontmatter** | `description` (मेन्यू में दिखता है), `argument-hint`, `allowed-tools`, `disallowed-tools`, `disable-model-invocation`। |

आर्ग्युमेंट्स, bash और फ़ाइल रेफरेंस के सटीक सिंटैक्स के लिए [आधिकारिक डॉक्स](https://code.claude.com/docs/en/skills) देखें।

## चुराने लायक कमांड्स

एक स्टार्टर सेट हमारी [स्लैश कमांड लाइब्रेरी](/docs/templates/slash-commands) में मौजूद है: commit message, PR description, code review, changelog, scaffold-a-component।

## कमांड बनाम स्किल बनाम सबएजेंट

काम को पैकेज करने के तीन तरीके — फ़र्क इसमें है कि *इसे कौन ट्रिगर करता है* और *यह कितना अलग-थलग चलता है*:

- **स्लैश कमांड** — *आप* किसी जाने-पहचाने वर्कफ़्लो को ज़रूरत पर ट्रिगर करते हैं।
- **[स्किल](/docs/claude-code/skills)** — प्रासंगिक होने पर Claude विशेषज्ञता *अपने-आप* लोड करता है।
- **[सबएजेंट](/docs/claude-code/subagents)** — काम का एक हिस्सा किसी अलग-थलग एजेंट को सौंप दें।
