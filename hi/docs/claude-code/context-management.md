## मुख्य विचार

हर सत्र की एक सीमित [संदर्भ विंडो](/docs/foundations/tokens-and-context) होती है। जैसे-जैसे यह भरती है, पुरानी सामग्री दब जाती है और Claude "भटकने" लग सकता है। संदर्भ को सोच-समझकर सँभालना ही लंबे सत्रों को तेज़ बनाए रखता है।

## दो आवश्यक कमांड

लगभग हर स्थिति दो कमांड से सँभल जाती है। तरकीब यह है कि कमांड को अपने इरादे से मिलाएँ।

<Flashcards cards={[{front: "/clear", back: "बातचीत मिटाकर नए सिरे से शुरू करें। इसे तब इस्तेमाल करें जब आप किसी असंबंधित कार्य पर जाएँ। साफ़, केंद्रित संदर्भ वापस पाने का सबसे सस्ता तरीक़ा। उपनाम: /reset और /new।"}, {front: "/compact", back: "अब तक की बातचीत का संक्षिप्त सारांश बनाता है — सार बचाए रखकर जगह खाली करता है। इसे तब इस्तेमाल करें जब आप उसी कार्य को जारी रखना चाहें लेकिन विंडो भर रही हो। वैकल्पिक फ़ोकस निर्देश स्वीकार करता है।"}]} />

एक सवाल से तय करें: यह नया कार्य है या वही कार्य?

```mermaid
flowchart TD
  A{New task or same task?} -->|New / unrelated| B[/clear]
  A -->|Same task, context full| C[/compact]
```

दो बातें जो आसानी से छूट जाती हैं:

- **`/compact` निर्देश लेता है।** `/compact focus on the auth bug fix` वही रखता है जो *आप* चुनते हैं, उसकी जगह नहीं जिसे स्वचालित पास महत्वपूर्ण मानता है। विंडो के मजबूर करने का इंतज़ार करने के बजाय, कोई लंबा नया कार्य शुरू करने से पहले इसे जानबूझकर चलाएँ।
- **`/clear` वापसी-रहित बिंदु नहीं है।** नाम दें (`/clear auth refactor`) ताकि जाने वाली बातचीत `/resume` पिकर में उस लेबल से दिखे, और उसी Claude Code प्रक्रिया के भीतर rewind मेनू अब भी `/resume <session-id> (previous session)` प्रविष्टि देता है — देखें [चेकपॉइंट और रिवाइंड](/docs/claude-code/checkpoints-and-rewind)।

## ऑटो-कॉम्पैक्शन — और उसकी सीमा कैसे खिसकाएँ

जब संदर्भ सीमा के क़रीब पहुँचता है, तो Claude Code **स्वतः कॉम्पैक्ट** करता है ताकि काम बिना अचानक रुके चलता रहे। 1M संदर्भ विंडो वाले मॉडलों पर यह डिफ़ॉल्ट रूप से लगभग 967K टोकन पर होता है; पुराने मॉडल अपनी संदर्भ विंडो की सीमा पर कॉम्पैक्ट करते हैं। Claude Code ऐसी बातचीत भी कॉम्पैक्ट कर सकता है जिसे आपने निष्क्रिय छोड़ दिया हो।

सीमा आप खिसका सकते हैं। `/autocompact 500k` पहले कॉम्पैक्ट करता है — तब उपयोगी जब आप 96% भरने पर नहीं, अपनी शर्तों पर सारांश बनाना चाहें — और `/autocompact auto` आपके मॉडल के लिए ट्यून की गई विंडो पर लौटा देता है।

:::tip[लक्षण → समाधान]
यदि Claude पहले का कोई निर्देश भूलने या खुद को दोहराने लगे, तो संभव है कि विंडो भर गई है। `/compact` (वही कार्य) या `/clear` (नया कार्य) आम तौर पर इसे तुरंत ठीक कर देता है। पुष्टि के लिए `/context` चलाएँ — जब बातचीत सचमुच विंडो से आगे निकल चुकी हो, तो उसका आउटपुट बताता है कि आप कितना आगे हैं और कौन-सा कमांड जगह खाली करेगा। अधिक जानकारी [Claude ने ऐसा क्यों किया?](/docs/contribute/troubleshooting) में।

यदि इसके बजाय आपको `Autocompact is thrashing` दिखे, तो कॉम्पैक्शन काम कर रहा है लेकिन कोई अत्यधिक बड़ी चीज़ विंडो को बार-बार भर रही है — देखें [Claude Code समस्या-निवारण](/docs/claude-code/troubleshooting)।
