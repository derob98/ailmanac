规划模式

入门
What you'll learn
  • 说明规划模式会阻止什么，以及它仍允许 Claude 运行什么
  • 用三种不同方式进入和退出规划模式
  • 走一遍“调查—提出方案—批准—执行”的循环
  • 区分规划模式与权限（Permissions），并配合使用
最后验证时间：2026-10-09。

进入规划模式的方式（快捷键/标志），以及它在规划期间究竟允许 Claude 运行哪些 shell 命令，会随版本变化——请查阅 Claude Code 官方文档。

请对照以下来源核实： 官方来源.

核心思路​

想象一下：是直接把家门钥匙交给装修师傅，还是先请他走一遍现场，写下他打算改什么。规划模式就是那次现场勘查。

规划模式让 Claude 只研究并提出改动方案，而不实际改动：它会读取文件、运行 shell 命令来探查、撰写方案——但不会编辑你的源代码。在你批准方案之前，编辑一直处于被阻止的状态。

Pro tip
  • 规划模式意味着 Claude 只“调查”而不“改动”你的源代码——它产出一份方案，然后等你点头。

它并非严格只读​

探查有时需要执行命令，所以规划模式的重点是不编辑，而不是不执行。规划期间 shell 命令会被如何处理取决于会话——以第一个匹配的情形为准：

Guided walkthrough1 of 3
  1. 规划模式的限制不会被强制执行。Claude 仍被指示在不编辑的前提下做规划，但它在规划期间尝试的编辑或命令会不经询问直接运行。在其他场景下规划模式仍保持其限制——无头 -p 运行、Agent SDK，以及 VS Code 扩展的聊天面板。
  2. 除关键路径的删除外，shell 命令由分类器审查，而不是向你询问。获批的命令会运行，被拒绝的会被阻止。
  3. 超出内置只读集合的命令会提示你批准。
Watch out
  • 如果你是用 --allow-dangerously-skip-permissions 启动的，规划模式只是一条强指令，而不是硬性护栏。请把它当作规划约定，而不是沙箱。

为什么这是最安全的起点​

对于任何大型、有风险或不熟悉的工作，你都希望在 Claude 碰你的仓库之前，先看到它打算做什么。规划模式把思考与动手分开：

好处是：你能在错误的假设变成错误的代码之前就发现它们。

何时使用​

Pro tip
  • 大型或涉及多个文件的改动、迁移、重构时，一律使用
  • 在你还不完全了解的代码库中工作时
  • 当你想要一份可供评审、能分享给同事的方案时

对于微小、显而易见的编辑可以跳过——但拿不准时，先做规划。

实际如何运作​

跟着这个循环走。每一步都为下一步铺路——只有在你批准之后，Claude 才会切换到编辑。

Guided walkthrough1 of 4
  1. 按 Shift+Tab 循环切换权限模式，直到状态栏显示 'plan mode on'；或在单条提示前加上 /plan 前缀。若想一开始就处于该模式，用 claude --permission-mode plan 启动。然后描述你想达成的目标。
  2. 它会读取相关文件、运行探查命令，并提出澄清问题。
  3. 包括要改动的文件、做法，以及如何验证结果。按 Ctrl+G 可在编辑器中打开提议的方案并直接修改。
  4. 选择 'Yes, and use auto mode'、'Yes, manually approve edits' 或 'No, keep planning'。批准会退出规划模式，进入该选项所描述的权限模式，Claude 随即开始编辑。

若想不批准方案就退出规划模式，再按一次 Shift+Tab。若想让它成为项目终端会话的默认模式，请在 .claude/settings.json 中把 defaultMode 设为 plan——参见设置。

规划模式与权限​

一个经典的混淆点。它们解决的是不同的问题，而且可以配合使用：

  • 规划模式 = “先调查并提出方案，暂不编辑。”（本页内容。）
  • 权限（Permissions） = 一旦开始行动，哪些操作无需询问即可执行。

可以这样理解：现在要不要行动（规划模式）与行动时允许哪些操作（权限）。

Key takeaways
  • 规划模式是“研究并提出方案”：Claude 会读取并运行探查命令，但在你批准方案之前不会编辑你的源代码
  • 它并非严格只读——规划期间的命令要么由分类器审查，要么需要你确认，要么（在交互式终端且可使用 bypass permissions 时）完全不受阻止
  • 用 Shift+Tab、/plan 前缀或 --permission-mode plan 进入；批准后，会话会切换到所选批准选项所指明的模式
  • 对大型、有风险或不熟悉的工作默认使用；只跳过微小、显而易见的编辑
  • 规划模式决定是否现在就行动；权限决定行动时允许哪些操作
