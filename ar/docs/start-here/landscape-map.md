# خريطة المشهد

> Source: https://derob98.github.io/ailmanac/ar/docs/start-here/landscape-map · AILmanac (CC BY 4.0)

فهرس مشروح للموارد الرسمية ومواد المجتمع في الذكاء الاصطناعي — ومتى تستخدم كلًّا منها.

<LevelBadge level="all" />

AILmanac لا يعيش في فراغ، ولن ندّعي أننا نحلّ محلّ كل شيء. هذا الدرس هو خريطتك الصادقة لأفضل الموارد في المنظومة — والأهم من ذلك، متى تستخدمها **بدلًا منّا**.

<Callout type="objectives" items={["تحديد المصدر الوحيد للحقيقة، ولماذا تفوز الوثائق دائمًا عندما تختلف معنا", "التعرّف على موارد Anthropic الرسمية وما الغاية من كل واحد منها", "معرفة أفضل موارد كتابة الأوامر (prompting) من المجتمع والمحايدة تجاه الجهات المزوّدة", "مطابقة أي حاجة مع الوجهة المناسبة باستخدام جدول قرار بسيط", "وضع AILmanac في المشهد بوصفه الدليل الميداني صاحب الرأي"]} />

## موارد Anthropic الرسمية

هذه موارد من الجهة نفسها. ارجع إليها عندما تريد أمثلة معتمدة أو شيفرة قابلة للتشغيل أو تعلّمًا موجَّهًا مباشرة من المصدر.

- **[أفضل ممارسات الـ prompting](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)** — مرجع Anthropic في كتابة الأوامر، مع إرشادات لكل نموذج. (حلّ هذا محل Prompt Library القديمة التي كانت تضم أوامر نموذجية جاهزة، وصار رابطها يعيد التوجيه إلى هنا.)
- **[Anthropic Cookbook](https://github.com/anthropics/anthropic-cookbook)** — وصفات API قابلة للتشغيل (استخدام الأدوات، وRAG، والرؤية).
- **[وثائق Claude Code](https://code.claude.com/docs/en/overview)** — مرجع سطر الأوامر وبيئات التطوير.
- **[Anthropic Academy / Learn](https://www.anthropic.com/learn)** — دورات موجَّهة مجانية.
- **[Model Context Protocol](https://modelcontextprotocol.io)** — معيار MCP المفتوح + دليل الخوادم.

## المجتمع والموارد العامة

عندما تريد عمقًا محايدًا تجاه الجهات المزوّدة أو مسارات عمل منتقاة جرّبها المجتمع، فهذه هي الأبرز.

- **[awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code)** — أوامر وخطّافات (hooks) ومسارات عمل منتقاة.
- **[Prompt Engineering Guide](https://www.promptingguide.ai)** — مرجع عميق ومحايد في كتابة الأوامر.
- **[Learn Prompting](https://learnprompting.org)** — دورة منظَّمة في كتابة الأوامر مناسبة للمبتدئين.

## أين يندرج AILmanac

نحن **الدليل الميداني صاحب الرأي**: طريقة واحدة موصى بها أولًا، مصنَّفة بالمستويات، غنية بالقوالب، صادقة بشأن حداثة المعلومات، وتغطي Claude **ومفاهيم** الذكاء الاصطناعي العامة. فكّر فينا كخريطة تدلّك على المورد العميق المناسب في الوقت المناسب — وتعلّمك الأساسيات كي يصبح كل ذلك مفهومًا.
