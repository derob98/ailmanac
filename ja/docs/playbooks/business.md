## 効果の高い使い方

- **ポジショニングとメッセージング** — 価値提案を固め、そこからコピーを導く。
- **マーケティングコンテンツ** — ランディングページ、メール、広告、SNS、FAQ([ライティング](/docs/playbooks/writing)を参照)。
- **顧客対応** — 返信の下書き、クレームへの対応、お知らせの作成。
- **リサーチ** — 市場や競合の調査(必ず検証を!)、顧客インタビューの質問セット。
- **計画** — 目標を、優先順位と時間枠のある計画に変える。
- **ドキュメントと運用** — SOP、求人票、会議の要約。

## まずポジショニングから

コピーを書く前に、一文を正しく決めます。

<PromptCard title="Three value propositions, each critiqued in one line">
{`Write 3 versions of a value proposition using: for [audience] who [need],
[product] is a [category] that [key benefit], unlike [alternative].
Then critique each in one line.`}
</PromptCard>

これが鋭くなれば、以降のすべて(広告、メール、ランディングページ)が楽になります。その理由は文体ではなく仕組みです。曖昧な一文から書いたランディングページには、整合させるべき基準がないので、セクションごとにずれていきます。文を直せば、見出し、サブ見出し、3 つの特長の紹介文は、すべて同じことを言うようになります。

## 繰り返し使えるようにする

最良のプロンプトを再利用できる資産にしましょう。ブランドの声とドキュメントを入れた[プロジェクト](/docs/claude-app/projects)や、基準が自動的に適用される [ビジネスとマーケティングのスキルパック](/docs/templates/skills)です。

この違いは、書く人が 1 人より多くなると効いてきます。メモにある良いプロンプトは、使うのを思い出す必要があるものですが、同じプロンプトがプロジェクトの指示やスキルになっていれば、誰かが思い出すかどうかにかかわらず適用されます — 上の「指標を捏造しない」というルールも含めて。
