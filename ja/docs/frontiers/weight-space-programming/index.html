重み空間プログラミング: あるモデルが別のモデルの重みをデバッグするとき

上級

2026年11月2日、MIT CSAIL の研究者 4 人が、意図的に挑発的な切り口のブログ記事と論文を公開しました。最先端の LLM は、生のニューラルネットワークの重みを読めて編集できるコードとして扱える、というものです。勾配降下も、学習ループも、訓練済みの補助ネットワークもありません。あるのは、モデルと、別のモデルのパラメータのテキストダンプと、Python サンドボックスと、予算だけです。

広く伝わったのは、一番大きな結果でした。Qwen3.5-0.8B の数学を良くするよう求められた GPT-6 Astra は、約 8 億個の重みのうち 131,072 個、つまり 0.016% を変更し、MATH-500 を 7.9% から 48.1% へ引き上げました。1 日のうちにこの記事は Hacker News のトップに躍り出て 2,693 ポイントを集め、このアイデアを再現または製品化しようとする GitHub リポジトリが少なくとも 5 つ新たに現れました。

議論は 「AI はもう AI を改良できる」 という読みに落ち着きましたが、これこそ論文自身の対照実験が否定している唯一の読みです。実際に起きたことは、もっと限定的で、裏づけがしっかりしていて、はるかに有用です。Astra はデプロイ済みのモデルをデバッグしたのです。重みがすでに持っていた能力を隠していた病理をただ一つ見つけ出し、それを削除しました。このページはその違いについてのものです。実用上の価値はすべてその違いにあるからです。

What you'll learn
  • Qwen の結果が何を示しているのかを正確に述べ、それが能力の向上ではなくブロックの解除だったことを証明する 3 つの数字を読み解く
  • 誰も引用しない対照実験を引用できる: 同じ手法、同じ予算を Gemma 3 270M に適用しても、MATH-500 は 6.8% から 7.0% にしか動かなかった
  • 「重みの 0.016%」が編集の規模を過小に伝える理由を説明する — 131,072 個の重みは、選ばれた深さへの的を絞った構造的変更であり、ばらまかれたノイズではない
  • この手法を本来の系譜（ROME、MEMIT、方向性アブレーション、abliteration）の中に位置づけ、本当に新しい点を一つ挙げる
  • 重み空間に関するあらゆる主張に潜む隠れた通貨、つまり forward pass の予算を見抜く。これがなければ見出しの数字は再現できない
  • 可読性の天井を知る — 重みだけでは足りず、アテンションパターンなら足りた実験
  • 重みを一切編集せずに、今日から転用できる教訓を実践する: 小さなモデルにはそのタスクが「できない」と結論づける前に、打ち切り率を確認する
最終検証: 2026-11-03。

このページの実験の数値はすべて、著者自身による 「Sparks of Weight-Space Programming」（Rikiya Takehi、Jayden Teoh、Alex Zhang、Omar Khattab、MIT CSAIL）の解説記事から取ったもので、公開の翌日である 2026年11月3日に読んだものです。その前提で扱ってください。これは公開から 1 日のプレプリントで、著者による自己申告であり、独立した再現はまだありません。実験ログの全体が公開されている点は、この規模の主張としては多くの場合より良い状態ですが、ログの公開は再現ではありません。スター数とリポジトリの日付は 2026年11月3日時点の GitHub API によるもので、今後変わります。「エージェント時間で約 20 時間」という数字は、実験表ではなく著者の告知スレッドによるものなので、おおよその値として扱ってください。

次の情報源で確認してください: 公式情報源.

実際に何が行われたのか​

Qwen の実験は、記事の 8 つ目で最後のもので、次のように進みました。Astra に渡されたのは、Qwen3.5-0.8B（24 層、thinking モード有効）、Python カーネル、GSM8K と MATH の練習問題セット（7,469 問と 7,275 問）へのアクセス、そしてモデルを通す forward pass の予算です。勾配降下、学習ループ、木探索、Web の利用は明示的に禁止されていました。重みを読むことと、モデルを実行して何が起きるか見ることはできました。

Astra は、Qwen3.5-0.8B が推論ループに陥っていると報告しました。これはモデルカード自身が警告している不具合です。そしてその挙動を第 15 層と第 19 層の MLP ブロックに特定し、原因と見なした方向を 64 本の出力列から差し引きました。介入はこれがすべてです。64 本の列、個々の数値にして 131,072 個です。

ベンチマーク前後（forward pass 50 回）変化
MATH-5007.9%48.1%6.1 倍
GSM8K13.8%67.1%4.9 倍
IFEval（指示追従）21.0%62.3%3.0 倍
出力トークン上限に到達93.0%33.1%−59.9 ポイント

捉え直し: これは学習ではなくデバッグ​

この表を、見出しを書く人ではなく診断する人の目でもう一度見てください。無関係な 3 つのベンチマークが同時に動いており、そのうちの IFEval は数学とまったく関係がありません。本物の数学の向上が、副作用として指示追従を 3 倍にすることはありません。

次に、本当の説明をしてくれる 4 行目を読みましょう。編集の前は、試行の 93% が出力トークン上限に達していました。 10 回のうち 9 回は、最終的な答えにそもそもたどり着いていません。MATH-500 の 7.9% は、Qwen3.5-0.8B が数学を解けるかどうかを測っていたのではなく、打ち切られる前に自分のループから抜け出せた頻度を測っていたのです。打ち切りを 33.1% まで下げれば、打ち切りの向こう側にあるすべてのスコアが動きます。そのすべてのスコアが、打ち切りを通して測られていたからです。

覚えておきたいシグネチャ

編集は 1 回、無関係な 3 つのベンチマーク、打ち切りが急減。 このパターンは障害の除去の指紋です。能力の追加の指紋は狭く、対象の指標は動くのに無関係な指標は動きません。ごく小さな介入で複数のベンチマークが劇的に跳ね上がるのを見たら、ブロックの解除を見ているのではないかと疑い、打ち切りやフォーマットの数字を探しに行ってください。

著者の捉え方では、6 倍という数字は賢くなったモデルではなく、やっと答えを最後まで書き切れるようになったモデルです。

これは過小評価ではありません。デプロイ済みモデルの病理を、再学習せず、ファインチューニングにつきものの壊滅的忘却も起こさずに見つけて外科的に取り除けることは、本当に価値のある能力です。ただ、見出しが匂わせる能力とは別の能力であり、両者を混同すると、それを前提に作業を計画したときに高くつきます。

誰も引用しない対照実験​

あらゆる解説に載るべきだったのに、ほとんどに載らなかった数字がこれです。著者らは同じ手法を同じ forward pass の予算で Gemma 3 270M に適用しました。

モデルMATH-500 前MATH-500 後結果
Qwen3.5-0.8B7.9%48.1%成功
Gemma 3 270M6.8%7.0%効果なし

Astra は Gemma を改善できませんでした。著者らの説明は、このページの主張を限界として述べたものです。Gemma 3 270M の数学の失敗は、一か所に局在したブロック要因ではなく、分散した推論エラーでした。削除すべき単一の病理がなかったので、手法がやることがなかったのです。

ここから前提条件が見えてきます。この種の重み空間の編集には、局在した病理が必要です。つまり、すでに存在する特定の能力を抑え込んでいる、特定の見つけられる仕組みです。弱点が拡散していて本当に能力の問題である場合、この手法はこれまでのところ何も提供できません。障害は取り除けますが、スキルは植えつけられません。

なぜ「0.016%」は聞き方として間違っているのか​

「重みの 0.016% しか変えていない」と聞くと、ささやきのように、ちょっとした後押しや丸め誤差のように感じられます。この言い方は、ネットワーク全体にノイズをひとふり撒いた様子を思い浮かべさせます。実際はそうではなく、その誤解はどちらの方向にも害があります。

131,072 個の重みを 64 本の列で割ると、1 列あたり 2,048 個の値です。つまり編集は、選ばれた深さ（24 層のうちの第 15 層と第 19 層。この系統の手法が一貫して挙動の仕組みを見つけるスタックの中ほど）における、完全な 64 本の出力方向を、すべて同じ向きに押すものです。拡散した変更ではなく、構造化され、的を絞った、低ランクの趣のある変更です。

これは二つの意味を持ちます。

  • 聞こえるほど魔法ではありません。 スタック中ほどの MLP 層を 2 つ選び、その出力から一つの方向を差し引くのは、使い古された介入の型です。結果の大きさは、数の少なさではなく的の絞り方の精度から来ています。
  • 聞こえるより侵襲的です。 中ほどの深さで揃った 64 本の方向は、本物の外科的な切開です。「0.016%」は、安心できない操作を描写する安心できる数字であり、公開された成果物には、報告された 4 つのベンチマークの外でほかに何が変わったかの評価がありません。

系譜と、唯一の新しい点​

介入の形に見覚えがあるなら、それはこの手法に確立した家系図があるからです。それを知らずに主張を読むと、既知の操作をブレークスルーと呼んでしまい、さらに悪いことに本当のブレークスルーを見逃します。

Guided walkthrough1 of 5
  1. 特定の事実の関連付けがどこにあるかを突き止め、単一層の MLP の重みにランク 1 の更新を適用して、新しい記憶を直接書き込みます。離散的で的を絞った重みの外科手術が機能すること、そして狙うべきはスタック中ほどの MLP であることを確立しました。
  2. ROME の後継です。1 つの層で足りるという ROME の前提を捨て、更新を重要な層の範囲に広げます。1 件ではなく数千件の編集を挿入できるのはそのためです。構造的な共通点に注目してください。Astra も 1 層ではなく、スタック中ほどの少数の層を選びました。
  3. 対照的なプロンプト群でモデルを実行し、活性化の平均差を取って挙動の方向（古典的には拒否の方向）を得て、どの層もその方向に書き込めないように重みを編集します。学習なし、勾配なし。これは Astra が Qwen に行った操作と機械的に同じです。方向を見つけ、層の出力から差し引きます。
  4. ツールが成熟し、主流になりました。Heretic（「学習不要の言語モデル改変: 検閲の除去、スロップの抑制、迎合の低減」）は 38,427 スターを集め、Blackwell GPU、DGX Spark、Apple Silicon 向けの移植やフォークもあります。自動化された学習不要の重み外科手術は、研究上の珍品ではなく、人気のユーティリティです。
  5. ここに本当の新規性があります。上のどの段階でも、標的を突き止める手順は人間が設計していました。因果トレーシングの手法、対照的活性化のプロトコル、最適化の目的関数などです。Astra にはそのどれも与えられませんでした。生のパラメータを渡され、何がおかしいのか、そしてどこなのかを、重みと少数の forward pass だけから突き止めるよう求められたのです。編集は古く、何を編集するかの探索を汎用モデルに委ねる点が新しいのです。

この捉え直しは、次に何を見るべきかも教えてくれます。興味深い問いは「LLM は重みの編集を適用できるか」ではありません。適用するだけなら ROME が 2022 年にできました。問うべきは、汎用モデルが診断のステップをどれだけうまくこなせるかです。そこは常に研究者を必要としてきた部分です。

隠れた通貨: forward pass​

このページのすべての見出しの数字には、目立たない但し書きが付いています。forward pass 50 回で、という但し書きです。これは脚注ではなく主張の一部です。「勾配なし、学習なし」は「評価なし」に聞こえやすいのですが、それは誤りだからです。

囲碁の実験は、この依存関係を見えるようにします。Astra は、パラメータ数 1,480,274 の囲碁ネットワーク（243 → 512 × 6 → 82、ReLU）の重みを、石の識別、呼吸点、グループの危険度、着手のスコアリングについて推論しながら、層ごとにゼロから書くよう求められました。比較対象は 2,000 万局で学習した PPO のベースラインです。

forward pass の予算結果
0より小さな PPO ネットワークとの対局で過半数に勝つ
50同じサイズの PPO ネットワークに勝つ

つまりこの手法は、純粋な重みの読み取りではありません。重みの読み取りに、ごく小さな閉ループ（書く、確かめる、調整する）を足したものです。50 回の評価は、2,000 万局の PPO と比べれば驚くほど安いループであり、その安さこそ本当の見出しです。しかし forward pass の予算をゼロにした再現の試みは、別の、より弱い実験を行っているのであり、違う、より弱い数字を覚悟すべきです。

可読性の天井​

7 つ目の実験は、全体を誠実に保つものであり、成功と同じくらい目立つ形でこれを公開した著者らは評価に値します。

彼らは Gemma 3 270M（18 層、指示チューニング済み）を取り、埋め込み層と出力層を凍結して 2 つのコピーをファインチューニングしました。一方は誠実なもの、もう一方は迎合的（sycophantic）なものです。そして Astra にどちらがどちらかを当てるよう求めました。

重みだけからでは、できませんでした。ファインチューニングが植えつけた挙動の差は、その規模ではパラメータの中に読み取れる形で現れていなかったのです。

各ヘッドが実際にどこを見ているかを示すアテンションパターンのツールを与えられると、3 組すべてを正解し、仕組みの説明も添えました。迎合的なモデルの中間層のヘッドは、ユーザー自身の提案に含まれるトークンにより多くの重みを割り当てていた、というものです。これはまさに迎合が何であるかを、回路の言葉で述べたものです。

持ち帰る価値のある結論が 2 つあります。

  1. 「LLM は重みを読める」には厳然たる境界があります。 静的なパラメータは、実際の挙動に関する問いには不十分でした。ネットワークが動作している様子を観察することが必要でした。
  2. それでも成果は成果です。 アテンションビューアを与えられた汎用モデルが、挙動の病理について正確で具体的な仕組みの診断を出しました。これは解釈可能性の仕事です。

重みをゼロから書く​

数字が驚くほどなので、記録しておく価値があります。MinAtar のゲームをプレイするネットワーク（600 → 32 → 32 → 6、tanh）の重みを、学習なし、勾配なし、環境でのロールアウトなしで一発で生成するよう求められた Astra は、各層がどんなプログラムを実装すべきかを推論し、それをニューラルの形に変換しました。

ゲームAstra、一発PPO、1 億ステップ
Breakout517.415.8
Seaquest53.15.6
Asterix53.225.8

Breakout では、環境ステップを 1 億回消費したベースラインに対して 32 倍の差です。正直な留保として、これらは完全に仕様化できる小さなゲーム向けの小さなネットワークであり、まさに「プログラムを直接書く」ほうが盲目的な探索に勝つはずの領域です。この結果は一部、おもちゃのタスクにおける PPO のサンプル効率への告発でもあります。それでも天井は動き、誰も示したことのない方向へ動きました。

修復の実験にも同じ趣があります。坂道をジャンプできず、256 エピソードで 0% だった 171,664 パラメータの Kinetix の車の方策が、Astra が重みの 3.5% を一発で編集し、車の位置と速度を読み取る経路を層の間に追加したところ、100% になりました。

次の重み空間の主張をどう読むか​

この分野は、これから多くの論文とスレッドを生み出します。次の 5 つの問いを順に投げれば、自分が何を見ているのかが分かります。

Guided walkthrough1 of 5
  1. 最も価値の高い単一の問いです。Qwen では効き、Gemma では効かなかった。その組み合わせがあるから、Qwen の結果を解釈できます。陰性対照のない主張は、「ブロックを取り除いた」のか「能力を足した」のかを区別できず、この二つはあなたの仕事にとってまったく違う意味を持ちます。
  2. 数学の編集が指示追従も 3 倍にしたなら、見ているのはブロックの解除です。それを説明する打ち切り率、フォーマット、拒否率を探しに行ってください。対象の指標だけが狭く動くほうが、能力についてはより強い主張です。
  3. 「勾配なし」は「評価なし」ではありません。モデルを何回実行したかを尋ねてください。ゼロは 50 よりはるかに強い主張であり、これらの数字の大半を生んだのは 50 です。
  4. 8 億パラメータをレビューするのにエージェント時間で約 20 時間。しかも、民生用 GPU 1 枚でファインチューニングできるモデルに対してです。コンテキスト長が、モデルの目の前に置けるネットワークの量を決めます。ここにあるものは、70B はおろか最先端モデルにも線形には外挿できません。
  5. 改善したのは 4 つのベンチマークです。公開された成果物には、ほかに何が変わったかがほとんど書かれていません。中ほどの深さでの 64 方向の切開は、誰も測っていない挙動を静かに損なうおそれのある、まさにその種の変更です。モデル編集の文献は、大規模な編集による漸進的で壊滅的な忘却を何年も前から記録しています。

今日使えること​

今週、本番モデルのパラメータを LLM に渡すことはないでしょう。しかし、この結果の根底にある診断上の洞察はすぐに使え、費用もかからず、Qwen の数字はほとんどの人がそれを間違えていることを示しています。

小さなモデルやローカルのモデルにそのタスクはできないと結論づける前に、どれくらいの頻度で打ち切られているかを測ってください。 Qwen3.5-0.8B は、数学の理解度が 7.9% のモデルに見えました。実際には、ループを抱えたモデルを、トークン上限を通して測っていたのです。評価が誤りと最後まで終わらなかったを分けていなければ、能力を測っているのではなく、能力に脱出率を掛けたものを測っているのであり、能力とは無関係だった問題を直すために、より大きく高価なモデルに手を伸ばすことになります。

ローカルモデルの評価が必ず最初に行うべき打ち切りのトリアージ

Before judging this model's capability on my task, split the failures by cause.

For each failed case, classify it as exactly one of:
TRUNCATED  - hit the output/token limit before producing a final answer
LOOPED     - repeated substantially similar text or re-derived the same step 3+ times
MALFORMED  - finished, but in a shape my parser or grader could not accept
WRONG      - finished cleanly, in the right shape, and the answer is incorrect

Report: the count and percentage for each class, plus the accuracy
recomputed over only the cases that reached a final answer.

Then tell me which single class to fix first, and whether the headline
accuracy is measuring reasoning quality or escape rate.

推論の証拠になるのは WRONG のバケットだけです。TRUNCATED と LOOPED は、誰かが重みに触れるずっと前に、サンプリングやハーネスの変更（繰り返しペナルティ、出力上限の引き上げ、プロンプト内のステップ予算、ループを断ち切る停止条件）で安く直せることがほとんどです。つまみについてはサンプリング制御を、4 つのバケットを分けて保つハーネスの作り方については評価（Evals）を参照してください。

また、ほとんどの人が 3 択だと思っている判断に、4 つ目の選択肢を加えます。プロンプト、ファインチューニング、RAG と並んで、いまや重みの外科手術があります。学習不要で、的を絞れ、すでに一つの狭い仕事に実用的です。自分が管理するオープンウェイトモデルから、特定の学習済みの挙動（拒否、口癖、迎合、ループ）を削除する仕事です。Heretic の 38,000 スターが表しているのはそれです。モデルが知らないことを知らせる方法ではありません。

Key takeaways
  • Qwen の結果は、学習の結果ではなくデバッグの結果です。Astra は、重みにすでにあった数学の能力を隠していたブロックの病理（推論ループ）を一つ取り除いたのであり、モデルに数学を教えたわけではありません。
  • 証拠はパターンにあります。無関係な 3 つのベンチマークが同時に動き（MATH-500 は 6.1 倍、GSM8K は 4.9 倍、IFEval は 3.0 倍）、出力トークン上限への到達は 93.0% から 33.1% に下がりました。狭い介入がすべてを動かすなら、それはブロックの解除です。
  • 対照は、論文で最も重要で、最も引用されない数字です。同じ手法、同じ予算、Gemma 3 270M で 6.8% から 7.0%。局在した病理がなければ効果もありません。この手法は障害を取り除くもので、スキルを植えつけるものではありません。
  • 「重みの 0.016%」は、安心できない操作を描写する安心できる数字です。131,072 個の重みは、24 層のうちの第 15 層と第 19 層で切り込まれた、完全な 64 本の出力方向です。ばらまかれたものではなく、構造化され的を絞られています。
  • 系譜は本物です。ROME（2022）、MEMIT（2023）、方向性アブレーション、38.4k スターの Heretic。編集の形は何年も前からあるアイデアです。新しいのは、汎用モデルが人間の設計した局在化の手順なしに診断のステップを実行することです。
  • forward pass が隠れた通貨です。見出しの数字は「forward pass 50 回で」の値で、囲碁の実験は 0 から 50 への勾配をはっきり示しています。「勾配なし」は「評価なし」を意味しません。
  • 重みだけには天井があります。Astra はパラメータから迎合的な Gemma を見抜けず、アテンションパターンが必要でした。静的な重みは、挙動に関する問いには不十分でした。
  • この知見は今日、無料で使えます。評価の失敗を TRUNCATED / LOOPED / MALFORMED / WRONG に分けてください。推論の証拠になるのは WRONG だけで、ほかの 3 つはたいていハーネスで直せます。
  • これは公開から 1 日のプレプリントで、自己申告であり、ログは公開されているものの独立した再現はありません。ログが公開されていることは、この規模の主張の多くより良い状態ですが、それでも再現ではありません。
