**2026年11月5日**、Anthropicはあなたの実際のお金を読み取る初めてのClaude機能、**Personal Finance**をリリースしました。`claude.ai/personal-finance`にある専用ハブで、銀行、クレジットカード、ローン、投資口座をPlaid経由で連携し、自分の支出についてClaudeに質問できます。

報道はどれも同じ2つの事実に集中しました — *Plaidを使う*ことと*読み取り専用*であること。どちらも本当です。しかし、この2つはこの機能について最も面白くない事実でもあります。この機能の使い方を実際に変えるのは、ヘルプ記事の奥に埋もれている点です。アプリの**どの部分にいるか**で決まる学習の境界、本当に意外なアーティファクト共有の挙動、そしてClaudeが示す数字があなたに有利な方向に外れる4つの別々の経路です。

このページは、報道が飛ばした部分を扱います。

## 1段落での要約

Personal Financeハブを開き、Plaid経由で銀行を連携します（サインインは**銀行側**で行うので、Claudeがパスワードを受け取ることはありません）。するとClaudeは、最大16行の銀行にわたる残高、与信限度額、最大24か月分の取引に読み取り専用でアクセスできます。**ハブ内**の会話はAnthropicのモデルの学習に使われず、メモリや月次サマリーにも含まれません。**ハブ外**の会話は通常のプライバシー設定に戻ります。Claudeはお金を動かしたり、管理したり、投資したりできず、Anthropicはこの機能が「投資アドバイスを行うよう設計されていない」とはっきり述べています。Claude Code、Coworkのタスク、スケジュールされたタスク、Claude Duetでは動作しません。連携を解除すると以後の読み取りは止まりますが、Claudeがすでに述べたことは取り消され**ません**。

Plaidは、チャットごとに管理できる通常の[コネクタ](/docs/claude-app/connectors)としても表示されます。**+** → **コネクタ** → **Plaid**で、*ブロック*、*常に許可*、*承認が必要*のいずれかに設定します。金融データを意図して頼んだときだけ使えるようにしたいなら、*承認が必要*が適切な設定です。

## Claudeが正確に何を見られるか

決める前にスクリーンショットを撮っておきたい表です。Anthropicがフィールドごとに列挙しています。

| カテゴリ | Claudeが読み取る | Claudeが読み取**らない** |
| --- | --- | --- |
| 金融機関 | 銀行名 | — |
| 口座の識別情報 | 口座名、種別、**下4桁** | 完全な口座番号 |
| 残高 | 現在の残高と**与信限度額** | — |
| 取引 | **最大24か月分**。金額、日付、加盟店、カテゴリ、銀行自身の明細表記を含む | — |
| 投資口座 | 残高と与信限度額のみ | **保有銘柄、売買、金利、条件** |
| 認証情報 | なし | 銀行のユーザー名やパスワード |

この表について2つの補足:

- 発表の**「最大2年」**とヘルプ記事の**「最大24か月」**は同じことです。取引ごとのフィールドを列挙しているのはヘルプ記事なので、そちらを引用してください。
- **下4桁の保証は、Plaidの保証であり、内容の保証ではありません。** Anthropic自身が漏れる経路を指摘しています。銀行が完全な口座番号を*口座名*や*取引の明細表記*に書き込んでいる場合、Claudeはそこでそれを見てしまうことがあります。Plaidが渡すのは4桁ですが、銀行側の自由記述フィールドはその保証に縛られません。

## 構造的にできないこと

- **お金の移動はできない。** 「Personal Financeはあなたの口座を読み取ることしかできません。お金を動かしたり、管理したり、投資したりすることはできません。」アクセスは、プロンプトで抑制されているだけでなく、Plaidの許可のレベルで読み取り専用です。
- **アドバイスの立場を取らない。** 両ページで同一のAnthropic自身の文言: *「Personal Financeはあなたのお金を理解する手助けをするものであり、投資アドバイスを行うよう設計されていません。」* より大きな判断については、Anthropicは、Claude単独ではなく、Claudeと並んで働く有資格の専門家を挙げています。
- **収益化の面がない。** 広告も、スポンサー付きのおすすめも、Anthropicブランドのクレジットカード、ローン、貯蓄口座もありません。
- **金融チャット内ではツールが制限される。** 連携口座を使うチャットでは、Claudeはコードを実行したり、Word、Excel、PowerPoint、PDFファイルを扱ったりできない場合があります。テキスト、表、`.csv`のようなプレーンテキストファイルは引き続き作成できます — そのため、エクスポートはXLSXではなくCSVを前提に計画してください。（通常のチャットでの[実際のファイル生成](/docs/claude-app/generating-files)と比べてみてください。）

## 3つのプライバシーの境界

### 1. 学習の境界は設定ではなく*場所*である

ここは取り違えやすいので、しっかり押さえておく文です:

> **Personal Financeハブ内**の会話は、Anthropicのモデルの学習に使われません。ハブの**外**でClaudeと共有したものには、あなたの[プライバシー設定](/docs/foundations/privacy)が適用されます。

つまり、通常のチャットに銀行明細を貼り付けた場合は、通常のアカウント設定が適用されます。除外はハブに付いてくるのであって、話題に付いてくるのではありません。アカウントでモデルの改善を有効にしているなら、「お金の話をしていた」は例外になりません。

ハブにはさらに2つの控えめな除外があります。チャットが連携口座を使った時点で、**[メモリ](/docs/claude-app/memory)に何も保存せず**、後から検索されず、**月次サマリーから — タイトルも含めて — 除外される**ように設計されています。

### 2. アーティファクトはチャットより長く残り、閲覧者のアカウントを読み取れる

これがヘルプ記事から直接引ける、本当に意外な点です:

> **アーティファクトは、Personal Financeを利用していてPlaidを許可している人であれば、それを開いた人の連携済みアカウントを読み取れます。**

二度読んでください。Personal Financeハブで作って公開した予算ダッシュボードは、*あなたの*数字の静止画ではありません。同じくPersonal Financeを使いPlaidを許可している別の人が開くと、*その人の*アカウントを取得できます。再利用できるツールとしては妥当な挙動ですが、スクリーンショットのようなものだと思っていたなら嫌な驚きです。

同じ系統のアーティファクトの事実がさらに2つあります:

- Claudeは、金融チャットからアーティファクトを**公開する前に確認します** — その確認は、クリックして済ませる邪魔ではなく、制御のポイントです。
- アーティファクトは、**チャットを削除しても、自分で削除するまで残ります。** 会話を削除してもクリーンアップにはなりません。
- **共有されたチャットのリンク**は、他の[共有されたClaudeの会話](/docs/claude-app/artifacts)と同様に、リンクを知っている誰にでも、あなたの口座の数字を見せます。

### 3. 保持は特別なものではなく、通常のコンシューマー向けポリシー

データは「会話に表示され、チャットを削除するまでチャット履歴に残り」、Anthropicの一般的な保持の慣行に従います。Personal Finance専用の保持に関する記事はありません — 適用されるのは、Anthropicの[プライバシーセンター](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)のコンシューマー向けページで、削除された会話は履歴からは即座に、バックエンドのストレージからは30日以内に消えると書かれています。Plaidは銀行データを**自社の**規約とプライバシーポリシーに従って扱い、Anthropicのホスティングプロバイダーもそれを見ます。

<VerifyNote lastVerified="2026-11-09" source="https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data">
30日の削除期間、匿名化されたモデル学習パイプラインの最大5年という数字、利用ポリシー関連の最大2年という保持の数字は、Anthropicの**一般的な**コンシューマー向け保持ページ（2026年7月1日付）に基づくもので、そのページはPersonal Financeや金融データについて特に言及していません。金融専用の約束として引用しないでください。
</VerifyNote>

驚かされる前に知っておきたい、関連するライフサイクルのルールがあります:

- **有料プランが終了した場合。** Personal Financeを開けなくなり、Claudeもチャットであなたの口座を読み取れなくなりますが、**銀行は連携されたまま**で、自分で連携解除するまで残ります。カスタマイズ／プラグイン → コネクタ → Plaid → 連携解除、または`my.plaid.com`で片付けてください。
- **TeamまたはEnterpriseプランに移る場合。** 移行が*始まった*時点で、Claudeは銀行の連携を解除します。空白期間を見込んでおきましょう。
- **Claudeアカウントを削除した場合。** 削除が処理された後、銀行は自動的に連携解除されます。
- **データのエクスポートには、保存したPersonal Financeのダッシュボードがまだ含まれません。** ウィジェットの構成が重要なら、書き留めておきましょう。

| サーフェス | Personal Finance? |
| --- | --- |
| Web版Claude（`claude.ai/personal-finance`） | ✅ はい |
| Claude Desktop | ✅ はい |
| iOS／Android版Claude | ✅ はい |
| Claude Code | ❌ いいえ |
| [Coworkのタスクとスケジュールされたタスク](/docs/claude-app/cowork-scheduled-tasks) | ❌ いいえ |
| Claude Duet | ❌ いいえ |
| プロジェクト | ⚠️ 「動作しない場合がある」— 非対応として扱う |
| Free、Team、Enterpriseプラン | ❌ いいえ |
| 米国外、または別の国を出口にするVPN使用時 | ❌ 戻るまでハブは消えるが、銀行は連携されたまま |

Claude Codeとスケジュールされたタスクの除外は、開発者がつまずく点です。これをベースに無人のエージェントを作る方法はなく、それは、ここでの[プロンプトインジェクション](/docs/security/prompt-injection)の面が本来よりずっと小さい理由でもあります — あらゆるループに人間がいるからです。

## すべてのアシスタントにまたがる1つのコントロール

Claudeは銀行口座を読み取る最初のアシスタントではありません。OpenAIは2026年の初めに、同様にPlaid上に構築した、ChatGPTの同等の個人金融の体験をリリースしており、この共通の仕組みには、知っておく価値のある実用上の帰結があります:

**権限が実際にあるのは、アシスタントではなくPlaidです。** どのAI製品を連携したとしても、許可はPlaidの接続であり、**`my.plaid.com`**で確認・取り消しができます — まだサブスクリプションがあるか、アプリが入っているか、機能にまだ到達できるかとは無関係です。特にClaudeでは、プランが失効しても銀行が連携されたままになるため、Plaidのポータルが最後の砦になります。

<VerifyNote lastVerified="2026-11-09" source="https://plaid.com/blog/chatgpt-personal-finance-plaid/">
Plaidは、**米国のChatGPT Proユーザーが、Plaid経由で金融口座を連携できる**ことを確認しており、このローンチをプレビューと説明しています。業界報道は**2026年5月15日**としており、OpenAIのリリースを引いて**12,000以上の対応金融機関**としています（これはPlaidのネットワーク規模であり、この連携専用の数ではありません）。ここではOpenAI自身のドキュメントを独自には確認して**いません**。`openai.com`と`help.openai.com`は自動取得をブロックするため、ChatGPTについての、比較可能なフィールドごとのデータ一覧、読み取り専用であること、履歴の深さ、モデルの学習ポリシーは、このページで引用している情報源では確認できて**いません**。並べて結論を出す前に、OpenAIの発表とヘルプセンターを読んでください。Googleは、私たちが確認できた範囲では、同等の直接的な銀行連携の発表をしていません。
</VerifyNote>

どのアシスタントでも通用する習慣: 許可はアグリゲーターで与え、アグリゲーターで確認し、アグリゲーターで取り消す — そしてアシスタント自身のトグルは便宜上のものであり、境界線ではないと考えること。請求に同じ「プロバイダーごとに自分で確認する」姿勢を当てはめたものは、[プロバイダー別のAIコスト](/docs/models/what-ai-costs-across-providers)を参照してください。
