Claude ユーザーのための Gemini 3.8 Flash：DeepSWE で Opus 5 と並んだワークホース（2026年9月）

中級

Google は 2026年9月2日、3.7 Flash の20日後に Gemini 3.8 Flash を出荷した。6週間で3つ目の Flash リリースである。同じティア、同じ 1M ウィンドウ、同じ $0.75 / $3.75 の導入価格、同じモデル ID パターン。変わったのはモデルの振る舞いの形だ。Google によれば 3.8 Flash は「より懸命に働く（works harder）」、つまり複雑なタスクで追加の推論ステップを実行し、ツールを反復的に呼び出す。そしてベンチマーク表がそれで何が得られるかを示している。DeepSWE v1.1 は 65.3 から 73.7 へ、Claude Opus 5 との差は 0.3 ポイント以内。Terminal-bench 2.1 は 89.4 に到達し、Opus 5 の 89.1 をわずかに上回った。そして、より難しい後継版である Terminal-bench 4.0 では、3.8 Flash は Opus 5 の 51.8 に対して 19.1 を記録している。

このレッスンは、作業をこのモデルにルーティングするかどうかを判断する Claude ユーザーのためのものだ。判断の要となる数字、「より懸命に働く」ことのトークン使用コスト、3.7 以来変わっていない移行チェックリスト、審査制の Cyber バリアント、そして Claude が依然として正しいデフォルトであるワークロードを扱う。

What you'll learn
  • 2026年9月2日に何が出荷されたか、そしてなぜ3週間ごとの Flash リリースサイクル（3.6 → 3.7 → 3.8）が本当のシグナルなのかを理解する
  • ベンチマーク表を正しいレンズで読む：DeepSWE と Terminal-bench 2.1 では Opus 5 とほぼ同等、Terminal-bench 4.0 では33ポイントの差、ドメインエージェントのベンチマークではリード
  • 「より懸命に働く」振る舞いの価格を見積もる：タスクあたり約30%多い出力トークン、つまり同じ表示価格でも 3.7 Flash よりタスク単価は高くなる
  • 3.7 Flash や Claude の呼び出しを驚きなく gemini-3.8-flash に移行する（3.6 世代の API 削除は引き続き適用される）
  • Gemini 3.8 Flash Cyber とは何か、Fairwind Program が何を制限しているか、そしてなぜあなたがほぼ確実にそれを呼び出せないのかを知る
最終検証: 2026-09-15。

リリース日、価格期間、「works harder」の表現、Cyber のベンチマーク、Fairwind の詳細は Google のローンチ記事より。モデル ID、thinking_level の値とデフォルト、コンテキストと出力の上限、移行リストは Google AI for Developers: latest model より。知識カットオフと DeepSWE / Terminal-bench 2.1 / LVBench の差分は DeepMind のモデルカード より。完全な比較表（Opus 5、Sonnet 5、GPT-5.6 Sol/Terra の列）は Vellum が転載した Google の評価レポート。「タスクあたり約30%多い出力トークン」という数字はそのレポートに対する Emergent の分析。Artificial Analysis の Intelligence Index とタスク単価の数字は9月2日の The Register の報道による。食い違いに注意：Google の 3.8 レポートは GDPval-AA v2 で 3.7 Flash を 1482 としているが、3.7 リリース時の第三者報道では 1525 近辺だった。ここでは Google の数字を示す。

次の情報源で確認してください: 公式情報源.

一文で言うと​

Gemini 3.8 Flash は 3.7 Flash の同ティア後継モデルで、モデル ID は gemini-3.8-flash、1M トークンのコンテキスト、最大出力 64K、thinking_level は low / medium（デフォルト）/ high、価格は 2026年12月31日まで 1M トークンあたり入力 $0.75 / 出力 $3.75、2027年1月1日から $1.50 / $7.50。Gemini API、Google AI Studio、Antigravity、Android Studio、Stitch、Gemini Enterprise、Gemini アプリ（AI Pro および Ultra）、検索の AI Mode、Google Sheets で利用可能。併せて、Gemini 3.8 Flash Cyber が新設の Fairwind Program を通じて審査済みの防御者向けに 3.5 Flash Cyber を置き換える。

今回もリリースサイクルが本題だ。3.6 Flash が7月21日、3.7 が8月13日、3.8 が9月2日：Google はフラッグシップが沈黙している間（The Register は 3.5 Pro が6月の予定を逃したと指摘している）、ワークホースのティアを3週間ごとに更新している。これは、多くのチームが実際に支払っているティアにおける高速な開発者フィードバックループと読むべきだ。Anthropic の今月の回答はスタックの最上位にある Claude Fable 5.1 であり、より安価な Sonnet ではない。OpenAI の回答は GPT-6 Astra だ。

このリリースで人々を驚かせる3つのこと​

1. 2つの主要ベンチマークで Opus 5 と同等、3つ目では33ポイントの差​

Google の評価レポートのうち、Claude を使うチームが気にすべき行（高いほど良い）：

2. 「より懸命に働く」は Google があなたの代わりに下したトークン使用の決定​

この変更に関する Google 自身の説明：複雑なタスクにおいてモデルは「より高い勤勉さを示す — 追加の推論ステップを実行し、ツールを反復的に呼び出す」。ローンチ記事はまた、開発者は「トークンのオーバーヘッドを最小化するために低い effort レベルを利用できる」とも述べているが、これはデフォルトがより多く消費するようになったことの丁寧な言い換えだ。Emergent による評価レポートの読みでは タスクあたり約30%多い出力トークン。Artificial Analysis の計測では Intelligence Index のタスクあたり $0.58 で、3.7 Flash より約40%高い。トークン単価は同じであるにもかかわらず、だ。

Claude ユーザーにとって、これは名前を変えたおなじみの effort トレードオフである。モデルは答える前により多くのツール呼び出しとより多くの思考に手を伸ばす。表示価格は動かなかったが、タスクあたりの請求額は動いた。トークン価格ではなくタスクコストで予算を組むこと。そして 3.7 Flash で設定していたレイテンシ SLO はすべて再測定すること。反復が増えれば、Flash の速度であっても実時間は増える。この物理は なぜエージェントはトークンを燃やすのか で解説している。

3. Claude と比べればまだ安いが、その比率はどの Claude かによる​

Artificial Analysis は 3.8 Flash を Intelligence Index で 59（high 推論時）とし、extra-high の GPT-5.6 Sol および medium の Grok 4.6 と同点、対して Claude Opus 5 は 63、Claude Fable 5.1 は 66（いずれも max）。Fable 5.1 のタスク単価は約 $3.76 で、3.8 Flash の $0.58 のおよそ 6倍。定価ベースで Opus 5 と比べると、Vellum の計算では 入力・出力ともに約 6.7 倍安い。Sonnet 5 との差ははるかに小さく、GDPval-AA v2 では Sonnet 5 が依然としてリードしている（1584 対 1545）。したがって正直な比較はこうだ：3.8 Flash は Sonnet ティアの価格で、DeepSWE とドメインエージェントのスコアは Opus の領域に到達しているが、Terminal-bench 4.0 / OSWorld のスコアはそうではない。Claude の現在の定価は モデルと価格 にある。

3.7 Flash（または Claude）からの移行​

API の表面は 3.7 Flash から変わっていない。Claude からの移植を壊すものの一覧も変わっておらず、相変わらず人々を引っかけ続けている。

Guided walkthrough1 of 7
  1. gemini-3.8-flash を使う。3.7 のエンドポイントは動き続けるが、ベンチマークの差分と「より懸命に働く」振る舞いは新しい ID でしか得られない。
  2. デフォルトは medium。3.8 Flash は難しいタスクでより多くの推論とツール呼び出しに手を伸ばすため、同じレベルでも 3.7 よりタスク単価が高くなる。抽出や分類ではまず low を試し、精度と出力トークンの両方を測定する。
  3. thinking_budget は文字列の enum に取って代わられ非推奨になった。数値の budget をまだ渡している呼び出しはレガシーの挙動で動いている。
  4. これらのサンプリング用パラメータは 3.6 系列以降存在しない。SDK によって失敗するか黙って捨てられるかのどちらかで、いずれにせよ丁寧に調整した temperature は何もしていない。
  5. 空でないモデルターンで終わる会話は拒否される。Anthropic 流のプリフィルによる誘導は、ユーザーターンの指示か構造化出力のスキーマにする必要がある。
  6. generateContent API では必須。Claude の tool_result は id を持っているので、順序に頼らず明示的にマッピングする。
  7. 2027年1月1日から $1.50 / $7.50、それに 3.7 Flash が使っていたタスクあたりトークンのおよそ 1.3 倍を掛ける。それが Q1 の予測に入れるべき数字だ。

最小限の 3.8 Flash 呼び出し（Python SDK）

from google import genai

client = genai.Client()  # reads GOOGLE_API_KEY

resp = client.models.generate_content(
  model="gemini-3.8-flash",
  contents="Review this diff. List the 3 riskiest hunks as file:line with a one-sentence reason each.",
  config={
      "thinking_level": "low",   # start low on 3.8 Flash; it already 'works harder' at medium
      # no temperature / top_p / top_k / candidate_count
      "tools": [{"function_declarations": [...]}],
  },
)
print(resp.text)

Gemini 3.8 Flash Cyber と Fairwind Program​

汎用モデルと並んで、Google は 3.5 Flash Cyber を置き換える Gemini 3.8 Flash Cyber をリリースした。Google の数字：CWE-Bench のパッチ適用で pass@1 47.2%、「ある主要なフロンティアモデル」の 47.8% に対して。20 のプログラミング言語にわたる 70% 超の脆弱性発見成功率。Chrome Security によれば最良の商用モデルと比べて Chrome の脆弱性に対する正しいパッチが 2.6 倍。そして Wiz によれば 2.3〜5.2 倍低いコストで 7.5〜9.7 ポイント高い再現率。

あなたはほぼ確実にこれを呼び出せない。アクセスは Fairwind Program を通じて行われ、「信頼できる政府機関、ならびに重要インフラの運営者とソフトウェアのメンテナー」に限定され、申請制だ。これは OpenAI が GPT-6 Astra のエクスプロイト能力を審査制プログラムの背後に置いたのと同じ形であり（Astra フィールドガイド を参照）、Anthropic の Mythos クラスのモデルに対する扱いとも同じだ。Claude ユーザーにとっての実務的な要点は、フロンティアのサイバー能力が3つのスタックすべてで別の審査制 SKU として出荷されるようになり、汎用モデルは意図的にそれではないということだ。セキュリティのセクション では、それがあなたが呼び出せるエージェントにとって何を意味するかを扱っている。

3.8 Flash を選ぶべきとき、Claude に留まるべきとき​

Pro tip
  • 3.8 Flash を選ぶ：DeepSWE のようなリポジトリ規模のコーディング。Opus 5 の 74.0 に対して 73.7 をタスクコスト 6 分の 1 で得られるのは本物のトレードだ。
  • 3.8 Flash を選ぶ：金融、法務、ライフサイエンスのエージェントワークフロー — Vals Finance Agent v2、Harvey Legal、BioMysteryBench で Opus 5 を含むすべての列をリードしている。
  • 3.8 Flash を選ぶ：長尺動画やチャートの理解（LVBench 87.8、CharXiv 86.2）。Claude には同等の入力経路がない。
  • Claude Opus 5 に留まる：対話的なターミナルエージェントとコンピュータ操作。Terminal-bench 4.0（51.8 対 19.1）と OSWorld-2.0（75.4 対 59.0）は表の中で最も大きな差だ。
  • Claude に留まる：GDPval-AA v2 が重要なナレッジワーク。Opus 5 の 1824、そして Sonnet 5 の 1584 でさえ、3.8 Flash の 1545 を上回っている。
  • Claude に留まる：プリフィルしたターン、temperature 制御、Anthropic のツール使用ループの上に構築されたもの — Gemini API を使うのではなく、それと戦うことになる。
  • 両方を、実際に出荷する effort で相互検証する：3.8 Flash の表はデフォルトまたは high の思考レベルで、3.7 よりタスクあたり約30%多いトークンを消費する。Claude の表は max effort だ。どちらもあなたの本番設定ではない。

Key takeaways
  • DeepSWE +8.4 で 73.7 が判断の要となる数字：Sonnet 価格のモデルがリポジトリ規模のバグ修正で Opus 5 の 0.3 ポイント以内に入った。
  • Terminal-bench 4.0（19.1 対 51.8）と OSWorld-2.0（59.0 対 75.4）は Opus 5 が大きく先行し続けている領域 — 対話的エージェントとコンピュータ操作は Claude に留まる。
  • 「より懸命に働く」とは同じ表示価格でタスクあたり約30%多いトークンを意味する。タスク単位で予算を組み、thinking_level は low から始め、レイテンシ SLO を再確認する。
  • 3.6 世代の API 削除（temperature/top_p/top_k/candidate_count、プリフィル不可、FunctionResponse の call_id + name）は引き続き Claude からの移植を壊す。移行リストは縮んでいない。
  • 3.8 Flash Cyber は Fairwind の審査下にある別の SKU — 今月、フロンティアのサイバー能力を単純には呼び出せないものとして出荷した3つ目のスタックだ。
