MiMo-V2.6:Xiaomi の 1T オープンウェイト・オムニモーダルモデル

中級

2026年9月22日、Xiaomi は MiMo-V2.6 を公開しました — Hugging Face 上に平易な MIT ライセンスで 3 つのチェックポイントが並び、その筆頭は 1.02 兆パラメータのスパース Mixture-of-Experts モデルで、100万トークンのコンテキストを持ち、テキスト・画像・動画・音声を入力として受け取ります。Claude Opus 5.5 と GPT-6 Sol/Luna と同じ日に登場し、そのまま Hacker News のトップに上りました。

見出し記事はどれもほぼ同じことを言っています:フロンティアクラスのオープンウェイトで、クローズドモデルの 20〜60 分の 1 の価格だ、と。その部分は事実であり、確認も簡単です。誰も書いていないのは、実際に使うべきかどうかを決める部分です — どのベンチマークバージョンから勝ちが出たのか、なぜフラッグシップは自分で所有できるマシンではないのか、そして 3 番目の価格ティアは何のためにあるのか。

What you'll learn
  • MiMo-V2.6 のベンチマーク表を、モデルカード自身が報告しているとおりに読む — 報道が引用しなかった Terminal-Bench 4.0 の 14 ポイントの劣勢を含めて
  • エージェンティックベンチマークでの世代間 33 ポイントのジャンプが、たいていは新モデルが賢くなったのではなく旧モデルがハーネスを動かせなかったことを意味する理由を知る
  • 1M コンテキストを支えるアーキテクチャを理解する:384 エキスパートのうち 8 個がアクティブ、スライディングウィンドウ対グローバルアテンションが 6:1 の比率
  • Pro・Flash・9B 蒸留版を、実際に手元にあるハードウェアで選び分ける — Pro のローンチコマンド自体が 2 ノードを要求する
  • 10 倍価格の UltraSpeed ティアが何を売っているのか(同じ重みから得られるレイテンシ)、そしてそれに払う価値がある場面を見極める
最終検証: 2026-09-23。

ここに記載したアーキテクチャ、ライセンス、ベンチマークスコア、サービング用コマンドは、ローンチ時に公開された Hugging Face のモデルカードから読み取ったものです。ホスティング価格は OpenRouter および Xiaomi AI Studio の掲載内容についてのローンチ報道に基づきます。トークン単価はこのページの何よりも速く動きます — 予算を組む前にライブの掲載価格を確認してください。

次の情報源で確認してください: 公式情報源.

一文サマリー​

MiMo-V2.6-Pro は MIT ライセンスの 1.02T 総 / 42B アクティブなスパース MoE で、1M トークンコンテキストとテキスト・画像・動画・音声入力を備え、短ホライズンのエージェンティックおよび自動化ベンチマークで Claude Opus 5 に並ぶか上回り、長ホライズンのターミナル作業では大きく劣り、自前で動かすのではなく借りる場合のトークン単価はおよそ 10 分の 1 です。

見出しからは自明ではない 4 つのこと​

1. Terminal-Bench の勝ちと Terminal-Bench の負けは同じモデルの話​

これは腹に落としておくべき点です。ローンチ報道は MiMo-V2.6-Pro が Terminal Bench 2.1 で 89.9、Claude Opus 5 の 89.1 をわずかに上回ったと広く伝えました。Xiaomi 自身のモデルカードは Terminal Bench 2.1 をまったく報告していません。報告しているのは Terminal Bench 4.0 で、そこでは MiMo-V2.6-Pro が 34.9、Opus 5 の 49.0 に対して 14.1 ポイントの劣勢です。

どちらの数字も本物です。Terminal Bench 2.1 は古く、ほぼ飽和したハーネスで、フロンティアモデルはどれも 90 付近に集まり、0.8 ポイントの差はノイズです。Terminal Bench 4.0 は現行版で、モデル間がまだ広がっています。どこかで「Terminal Bench で Claude を上回った」と読んだら、最初の問いは常にどのバージョンかです — エージェンティックスイートでは、バージョンの変化のほうがモデルの変化より大きな効果を持つのが普通だからです。

同じパターンは AILmanac の DeepSeek-V4.1-Flash と Gemini 3.8 Flash の記事にも現れています:DeepSWE では互角、Terminal-Bench 4.0 では 15〜20 ポイントの穴。これは安価ティアの典型的な形になりつつあります。

2. 世代間 33 ポイントのジャンプはハーネスの話であって知能の話ではない​

モデルカード自身の表には前世代も載っています。MiMo-V2.5-Pro は DeepSWE v1.1 で 19.0、Terminal Bench 4.0 で 1.5 でした。V2.6-Pro は 71.9 と 34.9 です。

モデルが 1 世代でターミナル作業が 23 倍うまくなることはありません。1.5 というスコアは、旧モデルがベンチマークのツールコールプロトコルを事実上こなせなかったことを意味します — 推論ではなくハーネスで失敗していたのです。エージェンティックベンチマークにおける巨大な世代間差分は、まず「ツールコールを直した」と読み、それから初めて能力向上として読んでください。非エージェンティックなベンチマークの差分こそ誠実なものです:ProgramBench は 12.5 → 26.5、おおよそ倍増で、大きいが信じられる世代間ステップです。

3. 1M コンテキストは力技ではなくアテンション配置で買っている​

MiMo-V2.6-Pro の LLM バックボーンは 70 層:スライディングウィンドウアテンション 60 層、グローバルアテンション 10 層 — 6:1 の比率です。スライディングウィンドウ層はローカルな KV ウィンドウしか保持しないため、1M トークン時点のトークンあたり KV フットプリントは、完全グローバルな 70 層スタックが必要とする量のごく一部で済みます。10 層のグローバル層が、情報を端から端まで伝えることを可能にしています。

MoE は 384 のルーテッドエキスパートのうちトークンあたり 8 個がアクティブで、1.02T のうち 42B がアクティブ — つまり任意のトークンでモデルの約 4.1% が動く計算です。Flash は同じ形で総計 309〜311B、アクティブ ~15B。だからこそ 1 兆パラメータのモデルをそもそもサービングできるのです:メモリでは 1T を、計算では 42B を支払います。

その上に、1 パスあたり 7 トークンをドラフトする 5 層のマルチトークン予測投機デコーダが載っています。これはスループットの仕組みであり、次の点に関わってきます。

4. 「オムニモーダル」とは入力側のオムニモーダルであり、UltraSpeed は品質ではなくレイテンシを売っている​

マーケティング的な言い回しがぼかしている 2 点:

モダリティは入力側です。 カードはテキスト・画像・動画・音声をモダリティとして挙げ、681M パラメータの MiMo ViT ビジョンエンコーダ、308M の AudioTokenizer、127M の音声パッチエンコーダを備えます。Hugging Face 上の Pro のパイプラインタグはテキスト生成です。動画を与えて質問することはできますが、答えはテキストで返ります。音声や画像のジェネレータではありません。メディアをまたぐ生成が欲しいなら、それは別のページです: generative media。

UltraSpeed は 10 倍の価格で同じモデルです。 MiMo-V2.6-Pro-UltraSpeed は、Pro と同等の品質で最大 20 倍の出力速度と説明され、Pro のトークン単価のおよそ 10 倍で掲載されています。Hugging Face 上にそれ専用の重みセットは存在しません — 投機デコーダと Xiaomi のインフラの上に構築されたサービングティアです。製品として完全に妥当ですが、実態どおりに値付けを考えてください:買っているのは対話型・リアルタイムワークロード向けの秒間トークン数であって、精度ではありません。バックグラウンドのバッチ処理なら、UltraSpeed は 10 倍の払い過ぎです。

押さえておく価値のある読み方が 3 つ:

集計面では、Artificial Analysis の Intelligence Index v4.3 が MiMo-V2.6-Pro をおよそ 46 に位置づけ、オープンウェイトモデルで首位、Grok 4.7 と同水準と報告しました。クローズドフロンティアは約 53 です。10 分の 1 の価格で 7 ポイントのインデックス差 — これが実際の売り文句です。

レンタルと自前所有、それぞれのコスト​

レンタルの場合、ローンチ時に OpenRouter と Xiaomi の掲載から報じられた 100 万トークンあたりの価格:

モデル入力出力
MiMo-V2.6-Flash$0.14$0.28
MiMo-V2.6-Pro$0.435$0.87
MiMo-V2.6-Pro-UltraSpeed$4.35$8.70

スケール感として、Claude Opus 5.5 は $4 / $20 で掲載されています(Opus 5.5 フィールドガイドを参照)。Pro は入力でおよそ 9 倍、出力で 23 倍安い計算です。UltraSpeed は入力で Opus 5.5 とほぼ同等、出力では半分以下 — これがあのティアについての誠実な考え方です。

自前所有はまったく別の話で、ローンチコマンドがそれを物語っています。モデルカードの Pro 向け SGLang サンプルは --tp 16 --dp 2 ... --nnodes 2 を要求します:16 デバイスにわたるテンソル並列、2 つのデータ並列レプリカ、2 ノード。これはワークステーションではなくラックです。vLLM の経路は --tensor-parallel-size 8 と軽めですが、それでも BF16 の 1.02T チェックポイントに 8 基のアクセラレータが必要です。

Flash は総計 ~309〜311B、アクティブ ~15B で、本格的なシングルノード機がどうにかサービングできる変種です。MiMo-V2.6-Distill-Qwen-9B チェックポイント — 9B の蒸留版で、Hugging Face には image-text-to-text として掲載 — が、ラップトップクラスの GPU に収まるものです。「有能なオープンモデルを自宅で動かす」が目標なら、Pro ではなくそこと Ollama でモデルをローカル実行するから始めてください。

所有についてもう 1 つ注意点があります。公開されているリポジトリは RL 後のチェックポイント(-Pro-RL、-Flash-RL)です。ベースチェックポイントはリリースされていません。サービング、量子化、適応はできますが、RL 前のベースから自前のポストトレーニングを始めることはできません。

自分の仕事のために評価する方法​

Guided walkthrough1 of 5
  1. ワークロードが画像・動画・音声クリップを一度も送らないなら、MiMo-V2.6 を特徴づけるものの大半は無関係であり、より安価なテキスト専用オープンモデルで同等になるかもしれません。オムニモーダルなエンコーダこそ差別化要因です — 使うか、それとも割り引いて評価するかです。
  2. Flash は公開されている全行で Pro の数ポイント以内、1 行では上回っており、価格はおよそ 3 分の 1 です。まず実際のワークロードを Flash で回してください。自分のタスクで差を実測できたときだけ Pro に上げます。
  3. 短く、境界のある、ツールを使うタスク(AutomationBench、Toolathlon)は MiMo が強い領域です。長時間の自律的なターミナルセッション(Terminal Bench 4.0)は 14 ポイント遅れている領域です。実際に出荷している形で 20 タスクの非公開 eval を作り、自分で採点してください。
  4. 70 層のうち 60 層はスライディングウィンドウです。長距離の検索は 10 層のグローバル層に乗っています。上限を信頼する前に、実際に使うコンテキスト長で needle-in-a-haystack とマルチホップ検索を実行してください。
  5. Flash、Pro、Pro-UltraSpeed は同じファミリー上の 1x / 3x / 31x の価格はしごです。買っているのが精度(Flash → Pro)なのかレイテンシ(Pro → UltraSpeed)なのかを判断してください — まったく別の買い物です。

vLLM で MiMo-V2.6-Pro をサービングする(モデルカード自身のローンチ行)

vllm serve XiaomiMiMo/MiMo-V2.6-Pro-RL \
--tensor-parallel-size 8 \
--trust-remote-code \
--gpu-memory-utilization 0.95 \
--max-model-len auto \
--reasoning-parser mimo \
--tool-call-parser mimo \
--enable-auto-tool-choice \
--generation-config vllm
Pro tip
  • 2 つのパーサフラグに注意してください:--reasoning-parser mimo と --tool-call-parser mimo。MiMo は推論とツールコールをファミリー固有の形式で出力します。これらを省くと、サービングスタックは生のマーカーを通常のテキストとしてアプリケーションに返します — モデルがツールを無視しているように見える、静かな失敗です。
  • --trust-remote-code が必要なのは、モデリングコードがチェックポイントに同梱されているためです。大事なものの上で実行する前に中身を読んでください。あのフラグはベンダー製 Python をサービングプロセス内で実行します。
  • SGLang の経路には EAGLE 投機デコーディングのフラグが加わります。スループットの優位はそこにあります — 素のまま起動するとマルチトークン予測器は使われないままです。

手を伸ばすべき場面、そうでない場面​

適合する用途

  • 混在メディアに対する大量の分類・抽出・自動化。入力 100 万トークンあたり $0.14 という価格が、そもそも経済的に可能なことの範囲を変える領域。
  • プライバシーや管轄権の理由で自前のハードウェアで動かさねばならず、かつ視覚や音声の理解が必要なもの — MIT ライセンスでこの組み合わせを提供するモデルはほとんどありません。 プライベートなローカル AI スタックを参照。
  • ツールがきちんと仕様化された、短く境界のあるエージェンティックタスク。AutomationBench と Toolathlon のスコアが、真に競争力があると示している領域です。

適合しない用途

  • 長時間の自律的なコーディングセッション。Terminal Bench 4.0 の差は Opus 5 に対して 14 ポイント、GPT-5.6 Sol に対して 5 ポイントで、しかもベンダー自身の数値です。
  • ポストトレーニングの出発点となるベースチェックポイントが必要な場合。出荷されたのは RL チェックポイントだけです。
  • Pro の 1 台構成でのセルフホスト。Flash か 9B 蒸留版を見込むか、Pro を借りてください。

Xiaomi が開示した、多くのラボが開示しないこと​

異例に具体的なので記しておく価値があります:Xiaomi は RL トレーニング実行の形とコストを公開しました — おおよそ 6 日間の実行、30 RL ステップ、約 75 万トラジェクトリ、1,568 プロンプト × ステップあたり 16 ロールアウト、報告されたコストは Pro が ~$2.62M、Flash が ~$850K、RL 中は MoE ルータを凍結した非同期 GRPO を使用。

ここから読み取るべきことが 2 つ。第一に、強化学習中にルータを凍結するのは安定性のための選択です:エキスパート割り当てを固定しておくことで、ポリシー更新がどのエキスパートを発火させるかを静かに作り変えてしまうことを防ぎます。第二に、そしてより有用な点として、フロンティアに隣接するポストトレーニング実行のコストは今や数百万ドル台であって、数億ドルではありません。4 つのラボが同じ週に出荷した理由を説明するのは、この数字です。

Key takeaways
  • ベンチマークのスコアより先にバージョンを確認すること。MiMo-V2.6-Pro は Terminal Bench 2.1 では Opus 5 に勝ち、4.0 では 14 ポイント負けます — 同じモデル、同じベンダー、正反対の見出し。
  • デフォルトは Pro ではなく Flash。公開されている全行で数ポイント以内、CyberGym では上回り、価格はおよそ 3 分の 1、しかも 1 ノードで実際にサービングできます。
  • オムニモーダルは入力側の話。動画と音声が入り、テキストが出ます。メディアを一度も送らないなら、より安価なテキスト専用オープンモデルで同じ仕事ができるかもしれません。
  • UltraSpeed は同一品質を 10 倍の価格で売るレイテンシ製品です。対話型の用途には買ってよく、バッチには決して買わないこと。
  • 1M コンテキストは 70 層中 10 層のグローバルアテンション層に乗っています。上限を信頼する前に、実際のコンテキスト長で長距離検索をテストしてください。
  • 出荷されたのは RL チェックポイントのみで、ベンチマークはすべてベンダー実行です。コミットする前に、自分の仕事の形で 20 タスクの非公開 eval を作ってください。
