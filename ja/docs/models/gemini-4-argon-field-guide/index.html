Gemini 4 Argon: Claude ユーザーのためのフィールドガイド（2026年9月30日）

中級

Google は 2026年9月30日、Gemini 4 世代を Argon という単一のモデルで開始しました。そして他社にはない数字がひとつ——出力上限 100万トークン、従来の 64K から引き上げです。コンテキストウィンドウではありません。そちらは 1M のまま。上がったのは 出力 の天井で、16倍になりました。

これは Hacker News のトップに立ち、そのまま居座りました。商業的には奇妙な場所にも着地しました: Google 自身の投稿は Argon が「GPT-6 Astra や Claude Opus 5.5 よりも多くのカテゴリで首位または同率首位」だと述べる一方、同じ週に公開された独立系の Artificial Analysis Intelligence Index は Argon を 53、Claude Opus 5.5 の 58 に対して と置いています。どちらの記述も正確です。測っているものが違うのであり、その差こそがこのページで最も役に立つものです。

このレッスンは、Argon が自分のルーティングを変えるものかどうかを判断しようとしている Claude ユーザーのためのものです。1M の出力上限が実際に何を買うのか、矛盾する2つのベンチマーク物語をどう読むか、「40% 安い」という見出しが逆さまにしているタスクあたりの経済性、そしてあなたのアクセス申請がおそらく却下される理由を扱います。

What you'll learn
  • 1M の出力上限と 1M のコンテキストウィンドウを切り分ける——別々の天井であり、動いたのは一方だけ
  • Google の「18カテゴリ中13」という主張と、Argon を Claude Opus 5.5 より 5ポイント下に置く独立系インデックスを両立させて読む
  • タスクの値付けを正しく行う: Astra の 27K に対して 62K の出力トークンということは、Argon の優位は料金表であって効率ではない理由
  • ハルシネーション率 15% をそのまま読む——知識の勝利ではなく、棄権（アブステンション）という振る舞いであること
  • Fairwind Program が何をゲートし、組織に何を要求し、なぜ Argon が大半の読者にとって実質的に呼び出せないのかを理解する
最終検証: 2026-10-01。

ローンチ日、「1M トークン、従来の 64K から引き上げ」という出力の数値、導入価格と標準価格、社内ユースケースの数値（量子 40%、300+ TiB、Fuchsia Zircon 80万行、libgav1 3万2千行 / 2.7倍）、Wiz との提携は Google のローンチ投稿が出典です。Fairwind の参加資格とアクセス条件は Fairwind Program のページ、サイバー専用のベンチマークは DeepMind の Gemini サイバーページ から。Intelligence Index のスコア、1タスクあたり 62K 対 27K の出力トークン、AA-Omniscience のハルシネーション率、タスクあたりコストは、The Decoder と Trending Topics が報じた Artificial Analysis の数値です。18ベンチマークの比較表は、VentureBeat が転載した Google 自身の評価レポートです。

食い違いは2つ、どちらも未解決でどちらも重要です。 (1) Artificial Analysis のインデックスは The Decoder が 53、Trending Topics が 52.6 と引用し、Opus 5.5 はそれぞれ 58 と 57.6 です——同じ数字を丸めたものとそうでないもの。精度が問題になる箇所では丸めていない方の組を使います。(2) Google の枠組みと独立系インデックスは、Argon がフロンティアを率いているかどうかで一致していません。本稿はどちらかを選ばず両方を提示します。API のモデル ID は未公開です——Google のドキュメントは Argon の識別子をまだ掲載していないので、それを見せてくる人は推測しています。価格は導入価格であり、倍額になることが明言されています。予算を組む前に再確認してください。

次の情報源で確認してください: 公式情報源.

一文で言うと​

Gemini 4 Argon は Google の新しいフロンティアモデルで、入力コンテキスト 1M トークンと出力上限 1M トークン（64K から引き上げ）を持ち、導入価格は 100万トークンあたり入力 2ドル / 出力 10ドル、キャッシュ済み入力は 95% 割引、導入期間後は 4ドル / 20ドル に上がります。一般提供ではありません: Fairwind Program を通じて審査済みのサイバー防御者に先行提供され、その後に API の有料顧客と Google AI Ultra 加入者へ展開されます。Google 自身の 18ベンチマークのセットでは 13カテゴリで首位または同率首位。独立系の Artificial Analysis Intelligence Index では 53 で、GPT-6 Astra と Claude Fable 5.1 と同点、Claude Opus 5.5 より 5ポイント下です。

見た目どおりではない数字​

このローンチの要約はほぼすべて「100万トークン」と書き、読者にコンテキストウィンドウだと思わせたままにしています。コンテキストウィンドウは変わっていません。Gemini は 3.x 系から入力 1M トークンのままで——Gemini 3.8 Flash も同じ 1M ウィンドウと 64K の出力上限を持っています。

動いたのは 出力 の天井で、64K から 1M へ。この2つは別々の上限であり、壊れ方も別々です:

上限何を支配するかGemini 3.8 FlashGemini 4 Argon
入力コンテキスト送れる 量——ファイル、文字起こし、リポジトリ1M1M
最大出力モデルが 1回の応答で出せる 量、推論トークンを含む64K1M

実務上の帰結は 長いタスクがどこで壊れるか です。出力上限が 64K だと、本当に長期的な仕事——このサブシステムをリファクタする、この申請書を起草する、このコードベースをトリアージする——はあなたの側で分割するしかなく、分割の境目はすべてモデルが自分の作業状態を失う場所になります。Google の売り込みは、Argon なら仕事全体を通して1本の途切れない推論と実行の鎖を保持できる、というものです。

それを無料だと思う前に、頭に入れておくべきことが3つ:

  • 推論トークンは同じ予算から出ます。 Gemini では thinking トークンは出力トークンです。1M の出力枠は 1M トークンの成果物ではなく、思考 プラス 成果物で 1M トークンです。
  • 高いのは出力側です。 導入価格で、出力は入力の 5倍 のコストです（10ドル対 2ドル）。出力 100万トークンを本当に使い切った応答は、それだけで 10ドル、標準価格になれば 20ドルかかります。
  • モデルがそれを使う義務はありません。 天井が上がって変わるのは 可能なこと であって、典型的なこと ではありません。Argon は Intelligence Index のタスクで平均 62K の出力トークン——天井の約 6% です。

どちらの出典も嘘をついていません。食い違う理由は名指しできます:

  1. ベンチマークの選定は選択です。 Google は、Argon の差が巨大な3つのドメインエージェント評価（法務、金融、オートメーション）を含む 18 のベンチマークを選びました。集約インデックスは別の組み合わせに重みを置きます。かごを変えれば、勝者が変わります。
  2. 負けは固まっています。 Argon の明確な4敗——FrontierSWE v2、Terminal-Bench Science、Terminal-bench 4.0、PostTrainBench——はすべて 対話的でマルチターンの、ツールを駆動するエージェント作業 です。勝ちは単発のドメイン推論と長文コンテキスト検索に固まっています。これはノイズではなく形であり、ルーティングの判断にきれいに対応します。
  3. 比率より絶対値が大事です。 Harvey Legal Agent はこのローンチで最も引用された行です: 5.4% に対して 19.6%、3.6倍のリード。同時にそれは 19.6% というスコアでもあります——Argon はそのベンチマークで5タスクのうち4つほど失敗します。「入手できる中で最良」と「無監督で運用できるほど良い」は別の主張です。
  4. ベンダーのベンチマークは本番の振る舞いではありません。 Trending Topics は、Google の従業員によればこのモデルは実際のコーディング利用でスコアが示すより性能が落ちるという Bloomberg の報道を引いています。単一の未検証の報告として扱ってください——ただし モデルは劣化したのか？ のプロトコルが存在する理由は、まさにこの種のギャップを測るためです。
Pro tip
  • ローンチ投稿が「M カテゴリ中 N で首位または同率」と言っているとき、重要なのは誰が M を選んだかという問いです。招待されなくても見られる集約インデックスを探し、何かを再ルーティングする前に2つのかごを比べてください。

経済性は見出しの逆​

いくつかのメディアは、Argon が GPT-6 Astra より約 40% 安いという話を先頭に置きました。料金表はそれを裏づけます。タスクあたりのコストはもっと面白い話をします。Argon はトークンを大量に使うモデルだからです。

Artificial Analysis は Intelligence Index のタスクあたり平均出力を測定しました:

  • Gemini 4 Argon: 約 62,000 出力トークン
  • GPT-6 Astra: 約 27,000 出力トークン

Argon は同じインデックススコアに達するのに約 2.3倍 のトークンを吐き出します。請求額が安いのは価格設定の産物であって、効率の勝利ではありません。測定されたタスクあたりコスト:

モデルIntelligence Index タスクあたりコストインデックススコア
GPT-6.1 Sol (max)0.74ドル52
Gemini 4 Argon（導入価格）1.99ドル53
GPT-6 Astra (max)3.26ドル53
Gemini 4 Argon（標準価格）3.98ドル53
Claude Opus 5.5 (max)5.98ドル58

この表は2回読んでください。別々の結論が3つ出てきます:

  • Argon の Astra に対する優位には期限が設定されています。 2ドル/10ドルではタスクあたり 1.99ドルで、Astra の 3.26ドルに対して 39% の節約。価格が 4ドル/20ドルに倍増すると 3.98ドル になり、これは Astra より高い。コストの論拠はすべて導入期間の中にしかなく、Google はその期間の長さを言っていません。
  • GPT-6.1 Sol がこの表で実際のお買い得枠です。 Argon よりインデックスで1ポイント下なのに、Argon の導入価格の 37%、Opus 5.5 の 19% です。自分の仕事が Argon の得意ドメインにないなら、比率が効いてくるのは安いティアです——毎月の他の教訓とまったく同じです。
  • Opus 5.5 は Argon の導入価格の3倍で5ポイント上。 それに見合うかは完全にワークロード依存で、それが正直な答えであり、モデルの選び方 がリーダーボードではなくフレームワークである理由でもあります。

タスクあたりコストの主張を信じる前に、自分でトークン数を測る

For the same 20 representative tasks from my own workload, I want to compare two models on cost, not on benchmark score.

For each model, log per task:
- input tokens, output tokens (split reasoning vs final answer if the API reports it)
- wall-clock latency
- a 0-5 quality score I assign blind, without knowing which model produced it

Then compute, per model:
- mean output tokens per task
- mean cost per task at CURRENT list price
- mean cost per task at the post-introductory price, if one is announced
- cost per quality point

Flag any model whose cost advantage disappears at post-introductory pricing.
Do not quote vendor benchmark scores back to me — I only want my own 20 tasks.

ハルシネーション率 15% を正しく読む​

モデルが偽のことを断言するかどうかを測るインデックスの構成要素 AA-Omniscience で、Argon は ハルシネーション率 15% を記録しました。GPT-6 Astra は 51%、GPT-6.1 Sol は 54% です。これは漸進的な改善ではなく別の体制であり、このローンチで最も報じられていない数字です。

仕組みが重要です。Artificial Analysis の特徴づけは、Argon は自信を持って間違った答えを出すよりも 知らないと認める 可能性がはるかに高い、というものです。つまり勝っているのは キャリブレーションと棄権 であって、より多く知っていることではありません。実務上の帰結:

  • 検索・リサーチ・コンプライアンスの仕事では、これがどのコーディングの数字よりも先に来る看板機能です。 「提供された文書にはありません」と言うモデルは、2ポイント上のスコアを出して引用を捏造するモデルより価値があります。
  • カジュアルな利用では役に立たないと感じられます。 棄権するように調整されたモデルは当て推量を拒み、ユーザーは推量の拒否を「ごまかし」として体験します。信頼できるものにしているまさに同じ能力から、「知らないと言い続ける」という不満が出てくると見込んでください。
  • あなたのプロンプトに自動的に引き継がれるわけではありません。 棄権は、あなたの指示と相互作用する訓練された傾向です。よくキャリブレートされたモデルに「必ず断定的な答えを出せ」と言えば、その優位を使い切ったことになります。

おそらくあなたは呼び出せない​

実務上、ほとんどの読者の関心はここで終わります。Argon は公開エンドポイントではありません。Fairwind Program の背後にゲートされています——Google が Gemini 3.8 Flash Cyber で導入したのと同じ仕組みですが、今回ゲートされているのはサイバー専用の SKU ではなく フラッグシップ です。

Fairwind は政府と国家サイバー当局、重要インフラ事業者（医療、通信、エネルギー、金融）、そして中核的なテクノロジープラットフォームを優先し、申請者を「倫理的な運用と研究の実績が証明されていること」で審査します。受け入れられた組織は、以下に同意しなければなりません:

Guided walkthrough1 of 6
  1. 組織単位の API キーではありません。Argon を使う人間はそれぞれ、フィッシング耐性のある MFA と適用されるアクセス制御の背後で個別に認証される必要があります。チームで1つのサービス資格情報を共有したり、デプロイに埋め込んだりする通常のパターンは、これで排除されます。
  2. アクセスを付与できるのは社内のサイバーセキュリティ、インシデント対応、ペネトレーションテストのチームのみ。プラットフォームチームでも、プロダクト組織でも、汎用の社内アシスタントでもありません。
  3. 組織は誰が Argon にアクセスし何のために使ったかの記録を維持しなければなりません。監査証跡は後付けではなく成果物として計画してください。
  4. Argon をプロダクトに包んでアクセスを売ることや、子会社や顧客に渡すことはできません。これが、どのゲートウェイやプロキシも正当にはこれを提供していない理由です——グレーマーケットの AI プロキシについての本稿の注記も参照してください。
  5. 承認された脅威シミュレーション、リバースエンジニアリング、マルウェア解析は、防御目的と学術研究目的に限ります。マルウェアの作成と攻撃的利用は禁止です。
  6. Google は、Fairwind の次は API の有料顧客と Google AI Ultra 加入者が先で、その後に開発者、企業、消費者が「できるだけ早く」続くと述べています。日付は示されていません。

信頼された防御者に対して、Fairwind は Argon を CodeMender（脆弱性修正を自動化する Google のコードセキュリティエージェント）と組み合わせられるようにし、将来の公開モデルが備えることになる サイバーのガードレールなし のビルドを付与します。サイバー用途の論拠はその数字だけでも強い: 実世界の脆弱性発見が 85.8%（Gemini 3.8 Flash Cyber の 71.0% に対して）、Wiz のペネトレーションテストベンチマークが 70.9%（58.2% から）、CWE-bench v1 が 68%、そして Gray Swan の間接プロンプトインジェクションスイートで、フロンティアモデルとして測定された中で最高のプロンプトインジェクション耐性——k=15 で攻撃成功率 0.7%、Claude Opus 5.5 と Fable の 1.0%、GPT-6 Astra の 8.5% に対して。

最後の数字はそれ自体で一文に値します。攻撃成功率 8.5% は間接インジェクションの試行12回に約1回が通ることを意味し、0.7% は約143回に1回です。信頼できない Web コンテンツを読むエージェントを作るなら、それは露出の12倍の差であり、しかも k=15、つまり標的あたり1回ではなく15回の試行での測定です。プロンプトインジェクション と 攻撃下のコーディングエージェント と併せて読む価値があります。

Watch out
  • Fairwind は共有、再配布、再販を禁じているため、これを提供すると主張するゲートウェイ、プロキシ、「アンロック版 Argon」の再販業者は、別のモデルを偽って表示しているか、プログラム規約に違反しているかのどちらかです。Google から入手したのではない Argon エンドポイントは、既定で信頼できないものとして扱ってください。

Google が社内でこれを使って何をしたと言っているか​

ローンチ投稿の社内ケーススタディは、ベンチマーク表よりも有益です。検証可能な結果を伴う長期的な仕事を記述しているからです:

  • 量子アルゴリズムの最適化 — 時空リソースコストで公開されていたベースラインを 40% 上回った。
  • フリート全体のメモリプロファイリング — 300 TiB 超 を解放する最適化を発見、適用後の合計は 500 TiB から 1 PiB と推定。
  • C/C++ から Rust への移行 — Fuchsia Zircon カーネルの 80万行以上 を含む。
  • libgav1 ビデオデコーダ — 手書き SIMD 3万2千行 を置き換え、ビット単位で同一の出力を出しながら Rust 移植版より 2.7倍高速 なコードを生成。

このリストで最も示唆的なのは libgav1 の結果です。「ビット単位で同一の出力」という細部がそれを信用できるものにしています: 正しさを判定する機械的なオラクルがあったので、モデルの仕事はレビューされるのではなく検証できたのです。1M の出力予算が本当に報われるのはその形のタスク——大きく、機械的で、機械がチェックできるもの——です。同時に、それはほとんどのチームが持っていない形のタスクでもあり、これらの数字から自分のバックログに外挿する前に正直に認めておく価値があります。

ルーティングを変えるべきか？​

Key takeaways
  • 1M は OUTPUT の上限（64K から引き上げ）であって、1M のままのコンテキストウィンドウではない。推論トークンがその予算を消費し、出力は入力の 5倍のコストがかかる。
  • Google の「18カテゴリ中13」と Artificial Analysis の 53 対 58 は、別々のかごについてどちらも真。Argon の負けは対話的なマルチターンのエージェント作業に固まり、勝ちは単発のドメイン推論と長文コンテキスト検索に固まっている。
  • Argon はタスクあたり約 62K の出力トークンを燃やし、Astra は約 27K。請求額が安いのは料金表であって効率ではない——そして標準価格ではタスクあたりコストが 1.99ドルから 3.98ドルへ、Astra の 3.26ドルを上回る。
  • 51〜54% に対するハルシネーション率 15% はここで最も報じられていない数字であり、それは棄権から来ている。リサーチとコンプライアンスの仕事を Argon に回す最強の論拠であり、「常に断定的に答えよ」という指示が最初に壊すものでもある。
  • あなたはほぼ確実に呼び出せない: Fairwind はこれを、ユーザーごとのフィッシング耐性 MFA を備えた社内のサイバー / IR / ペンテストチームに、再配布なしでゲートしている。API のモデル ID は未公開。サードパーティの「Argon」エンドポイントはすべて疑わしい。
